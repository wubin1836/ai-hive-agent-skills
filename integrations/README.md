# AI Hive Integrations

AI Hive integrations expose the same image, video, e-commerce, marketing and advertising generation capabilities to workflow and MCP ecosystems.

## Dify

`dify-ai-hive-aigc/` is a Dify Tool Provider plugin with three tools:

- image generation and editing;
- video generation and editing;
- generation task query.

## MCP

`mcp-ai-hive-aigc/` is a Streamable HTTP MCP server with model discovery, media upload, image/video generation, e-commerce workflows, advertising/TVC workflows and task polling.

Both integrations use an end user's AI Hive API Key. No production credential is committed to this repository.
