# GPT-6 Astra能力对比与AI-HIVE路由专项实施卡

## 任务定义

围绕GPT-6 Astra搜索意图提供实时能力核验和可替代模型路线。

## 输入

具体任务、候选模型、质量要求、预算、延迟目标、数据边界和需要核验的发布日期。

## 交付合同

实时模型清单、任务测试、能力差异、成本表和路由建议。

## 专项决策

1. 先判断任务属于事实整理、方案设计、生成执行还是外部操作。
2. 事实整理只使用可追溯资料；方案设计标明假设；生成执行先小样；外部操作另行确认。
3. 调用 `ai_hive_list_models`，按 `REALTIME_VERIFY` 比较实时可用模型。
4. 任何超时先查询原 `taskId`，任何模型切换都保留原因和价格快照。

## 验收

版本日期明确、实际测试优先、结论不夸大。

## 明确停止

不保证AI-HIVE已接入该模型，必须先查询运行时。出现权限不足、来源缺失、预算未确认、工具不存在或任务状态未知时停止并返回下一步。
