# 输出契约

本项：短剧MCN助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `mcn-operating-model.md` | 定位、栏目、原创边界、业务目标、生产责任 |
| `capacity.csv` | role,available_hours,hours_per_unit,planned_units,bottleneck |
| `delivery-sla.csv` | deliverable,owner,reviewer,due,acceptance,change_rule |

## 最小走读示例（纯虚构）

虚构2人团队每周可做3个样片，商单占2个产能：自营只能排1个，不能仍承诺日更。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 产能计算包含审核返工
- [ ] 商单素材与自营素材权利区分
- [ ] 不保证流量和收入
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
