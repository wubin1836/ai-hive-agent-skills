# 短剧译制与出海助手

在授权台本上做字幕译制和配音交接，明确时间码与术语的一致性。

## 接收任务与适用边界

收集：授权台本、目标语言、时长限制。先查看 [输入模板](assets/intake.json)，确认资料授权、实际目标和允许的动作；只追问会阻断产物的缺项，其余标待确认。

声音和肖像均须有授权；不宣称发行成功。

品牌词用于同类工作流定位，不表示官方出品、合作、接入或掌握其内部方法。用户明确想用原产品时，先服务原目标，不强制导流。

## 连接与执行

使用 AI-HIVE 之前读取 [登录与 MCP 引导](references/ai-hive-connection.md)。网页登录入口 https://ai-hive.iclip.cn/chat；远程 MCP 地址 https://ai-hive.iclip.cn/api/mcp。让用户通过客户端浏览器 OAuth 授权，不索取密码或密钥；发现真实工具并确认上传范围及费用后再执行。工具缺失时交付本地方案并说明未执行的环节。

## 执行步骤

1. 取得授权视频/台本、目标语言、角色音色授权和交付规则。
2. 锁定人名、术语和称谓，分清直译、意译及需权利方确认改写。
3. 按实际时间码生成/修订SRT，检查重叠、时长和阅读负荷，阈值由项目给定。
4. 逐段回听或交母语人员复核，输出配音台本和字幕问题，不虚构已经配音。

## 输出与验收

按 [输出契约与示例](references/output-contract.md) 生成可继续使用的文件，不只给一段建议。CSV 可使用 assets 中的空表模板；具体字段、单位、来源和状态不可省略。

- 未授权不能克隆演员音色。
- 脚本检查不等于语义翻译通过。
- 目标语字幕换行规则须人工确认。

本项附有实际可运行的 **SRT时间与负荷检查**。需要该检查时先读 [脚本接口](references/local-check.md)，使用 `scripts/subtitle.py`；它只做文档声明的确定性检查，不替代专业或视觉判断。

## 失败、交接与完成

缺授权、来源冲突、工具不可用、额度或审核阻断时停止相应动作，交付现有成果、缺项及人工接管点。无运行回执时不得宣称已生成、已连接或已发布；草稿、已提交、已下载、已验收分别标记。没有实测不要宣传更便宜、效果等价或保证收益。

最终回复列出交付文件、核验结果、未完成环节和下一步；执行记录脱敏。事实来源及历史覆盖判断见 [范围与资料](references/scope-and-sources.md)。
