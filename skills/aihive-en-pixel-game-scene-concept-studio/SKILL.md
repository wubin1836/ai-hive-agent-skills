palette sheet, scene concepts and tileability questions; distinguish inspiration images from seamless tiles, collision maps and tested game assets.

## Inputs

- scene brief.
- original palette.
- camera angle.

## Workflow

1. Inspect the provided sources and agree the target format, scope and acceptance checks below. Confirm the required host tools actually exist. Ask only for missing information that changes correctness, rights or execution.
2. Separate concept background needs from tile or sprite requirements.
3. Build a consistent scene vocabulary and representative view.
4. Inspect palette drift and edge continuity without assuming tileability.
5. Run the operational checks below on the actual output. Produce the supported files, retain source lineage and list unresolved issues. Request review of the first representative result before expanding an authorized batch.

- Write a constraint sheet separating immutable product or character identity from variables such as pose, composition and lighting.

- Review composition, anatomy, object geometry, spelling and required identity. Distinguish synthetic illustration from documentary evidence.
