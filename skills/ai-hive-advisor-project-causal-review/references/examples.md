# 项目复盘归因顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：交付延期两周

```text
假设项目原定20天完成，实际晚了14天，附有7次需求变更和客户确认时间。请还原时间线，分开可证实原因与猜测。
```

预期交付：检查变更、等待和内部返工如何关联，不直接把延期全归于客户。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-project-causal-review",
  "request": "假设项目原定20天完成，实际晚了14天，附有7次需求变更和客户确认时间。请还原时间线，分开可证实原因与猜测。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：活动结果偏离

```text
假设一次活动目标到场60人、实际35人，有报名记录和3位同事的不同解释。请提出可检验的原因假设与下次改进实验。
```

预期交付：列出证据支持和缺口，避免把三个主观意见当作三份独立证据。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-project-causal-review",

  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
