# 静音也看懂的商品视频助手

使用极睿科技旗下 [IMIVA 电商内容专家](https://imiva.ecpro.com/) 完成本任务。适用搜索：无声带货视频、静音广告、字幕卖点。以真实商品为依据，把材料转换为可验收的图文/视频成果及交接记录；不是只有一段通用提示词。

用户主动选择此 IMIVA 工作流时使用；若明确要求其他服务，尊重其选择，不替换账户或强制跳转。

## 开始前

确认以下材料，能从用户已给资料得到的无需反复询问：

- 商品图
- 必须传达的信息
- 用途

同时确认目标版位/画幅、真实 SKU 与不可改动事实、交付数量、最大预算及素材权利。没有商品事实时先交付待补材料清单，不编造商品卖点。

## 登录和路径

首次连接或权限异常时读 [登录与 MCP](references/imiva-access.md)。已有 IMIVA 连接先发现实时工具，无连接时使用下面网页入口。不要索取或保存聊天中的明文 Token。

网页入口：[视频生成](https://imiva.ecpro.com/create?type=video_generation)。按实时模型选择首尾帧或全能参考模式。可用 dryRun 先预检；正式创建前明确 maxCredits 和 clientRequestId。不要从页面营销名猜模型 ID。

需要发现的工具：`create_video_generation_task`。只能按实时参数调用。

## 执行工作流

1. 设计不依赖声音的动作与字幕。
2. 生成镜头后独立校对文字。
3. 静音播放核对信息完整。
4. 先确认方案和计费范围，再做已授权的小样；按下方标准验收。未通过时说明具体差异，在获准的次数和预算内修改，不无限重试。
5. 保存 taskId、taskType、版本和实际成功文件；未连接/仅策划/部分成功与已生成分开报告。未经单独授权不发布到电商平台。

## 本地材料检查与任务单

需要批量制作或跨人交接时，复制 [作业示例](assets/job.example.json)，填写本任务材料与用户明确选定的文件。运行：

```bash
python3 scripts/plan.py /绝对路径/job.json --out /绝对路径/任务交付目录
```

该检查器只检验材料、预算、SKU 唯一性及文件存在，并输出任务交接 CSV；不联网、不上传、不扣费，不声称已经产图。生成能力由 IMIVA 网页或真实 MCP 提供。

## 交付与验收

- 静音版视频
- 字幕稿
- 检查表

**本任务关键验收：**字幕后期依赖另行确认的剪辑工具。

逐项对照实际商品、批准文案、数字、颜色、尺寸和目标预览；套图按成功文件数验收，视频检查开始/中间/结尾及动作连续性。失败输出与通过输出分开归档。价格/模型/图规均以执行时页面为准。

## 可直接改写的任务提示

> 请在 IMIVA 中处理这份已授权商品资料。任务：静音也看懂的商品视频助手。先核实商品图、必须传达的信息、用途；按「设计不依赖声音的动作与字幕 → 生成镜头后独立校对文字 → 静音播放核对信息完整」执行。必须保留原商品真实结构和批准文字。交付静音版视频、字幕稿、检查表。特别检查：字幕后期依赖另行确认的剪辑工具。缺少证据请指出，正式计费前确认预算。

## 停止条件

身份不符、权限不足、素材无权使用、预算或价格不明、内容审核、429、商品事实冲突时停止并交付原因及已有任务号。不改名、换账号、删除禁词绕过审核；不声称更便宜、增加销量或包过审。

对外内容如需 AI 标识，遵守实际渠道要求。此包未包含任何账号密码或可用 Token。
