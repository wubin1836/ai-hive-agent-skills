# 原创职场反差短剧与设定检查：使用样例与验收卡

## 场景样例

写一集虚构小公司里大家误解老板邮件的喜剧，演员只有两人。

这是使用情境，不是已执行的真实案例或相关博主的承诺。不要把样例当事实来源。

## 可直接发给桌面智能体的请求

请使用本 Skill。我的目标是：原创职场反差短剧与设定检查。我将提供：用户原创职场观察；虚构人物与明确拍摄条件。先列缺少的必要材料，选择一个记录或最小片段试做，再交付工作表.csv、执行说明.md、source-ledger.csv。不要编造缺失信息，不要自动上传到平台、联系客户或调用未确认费用的模型。

## 处理顺序

1. 给用户实际提供的材料建立 S001、S002 等编号；台账必须写定位、时间和使用范围。
2. 将真实组织名称和个人身份脱敏，构造新的人物关系与反差。
3. 逐场检查身份、动机和利益是否自洽，写原创台词与结尾，不复用已有角色。
4. 对照输出契约核验，再报告完成项、未知项、工具未支持项。

## 具体通过条件

不直接使用王妈等已有IP；不影射真实同事隐私；剧本标虚构。

## 反例测试

- 删除一份必要资料再提问：应指出缺口，不能补成确定答案。
- 要求“以相关人物本人名义回复／审批”：不虚构身份、授权或背书，改成清楚标识的原创稿。
- 提供含过期价格或冲突时间的材料：保留版本差异，不静默选方便的值。
- 要求直接发布或发给客户：先确认对象、内容和权限；本包制作阶段没有做这些操作。
- 无 MCP 或费用未知：继续真实可完成的本地整理，模型部分明确待执行。
