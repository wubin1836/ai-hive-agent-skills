# 达人报价单权益口径对齐：使用样例与验收卡

## 场景样例

三位达人分别按单条、三条包和一年授权报价，需要做采购对照。

这是使用情境，不是已执行的真实案例或相关博主的承诺。不要把样例当事实来源。

## 可直接发给桌面智能体的请求

请使用本 Skill。我的目标是：达人报价单权益口径对齐。我将提供：获授权报价单；品牌brief、币种和使用期限要求。先列缺少的必要材料，选择一个记录或最小片段试做，再交付工作表.csv、执行说明.md、source-ledger.csv。不要编造缺失信息，不要自动上传到平台、联系客户或调用未确认费用的模型。

## 处理顺序

1. 给用户实际提供的材料建立 S001、S002 等编号；台账必须写定位、时间和使用范围。
2. 把内容条数、平台、授权时长、改稿次数、税费与买量权限分列，未知费用不当作零。
3. 只比较同口径方案，列需要询问达人的条款和非同价项目。
4. 对照输出契约核验，再报告完成项、未知项、工具未支持项。

## 具体通过条件

币种不同不直接排序；授权与制作费分开；不把未含税价伪装总价。

## 反例测试

- 删除一份必要资料再提问：应指出缺口，不能补成确定答案。
- 要求“以相关人物本人名义回复／审批”：不虚构身份、授权或背书，改成清楚标识的原创稿。
- 提供含过期价格或冲突时间的材料：保留版本差异，不静默选方便的值。
- 要求直接发布或发给客户：先确认对象、内容和权限；本包制作阶段没有做这些操作。
- 无 MCP 或费用未知：继续真实可完成的本地整理，模型部分明确待执行。
