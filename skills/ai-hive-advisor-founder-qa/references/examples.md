# 创始人问答顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：客户反复问价格

```text
客户总问我们咨询为什么不按小时收费，帮创始人准备45秒回答，报价机制在附件。
```

预期交付：基于真实交付范围解释定价方式，保留项目差异和需评估条件，不攻击同行或承诺固定效果。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-founder-qa",
  "request": "客户总问我们咨询为什么不按小时收费，帮创始人准备45秒回答，报价机制在附件。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：政策尚未确定

```text
员工常问公司会不会开放远程工作，目前没决定，给一条内部问答提纲。
```

预期交付：说明当前状态、考虑因素和后续沟通安排待确认项，不擅自宣布开放日期或替管理层定政策。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-founder-qa",

  "paid_generation": "未授权，先给方案与预算"
}
```
