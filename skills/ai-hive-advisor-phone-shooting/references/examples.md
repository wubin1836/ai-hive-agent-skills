# 手机拍摄顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：对焦波动

```text
用我的手机拍桌上产品总来回对焦，先用现有支架测试，别推荐新设备。
```

预期交付：按设备能力的对焦和距离测试记录。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-phone-shooting",
  "request": "用我的手机拍桌上产品总来回对焦，先用现有支架测试，别推荐新设备。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：亮度变化

```text
看这段20秒口播，脸一动画面就变亮，帮我设计三次以内的试拍。
```

预期交付：可见现象定位和不超过三次的单变量测试。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：
