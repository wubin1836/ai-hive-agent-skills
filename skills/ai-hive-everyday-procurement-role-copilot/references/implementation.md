# 采购人员AI比价助手：专项实施卡

## 用户与结果

- 目标用户：普通企业的老板、市场、品牌、运营、产品、研发、行政、人力、财务、采购和项目交付岗位。
- 希望结果：统一需求、供应商资料、报价口径和待核实项。
- 交付物：岗位任务清单、输入字段、AI草稿、人工审批点、交付格式和可审计记录。
- 核心指标：口径一致率、未证实项数、采购周期。

## 最小样例

1. 只选一个真实用户或一个真实商品/服务。
2. 使用3—5条已授权资料，不上传不必要的隐私数据。
3. 先查询当前模型与价格，再生成1份内部草稿。
4. 由人工检查事实、品牌、版权、隐私和渠道规则。
5. 记录结果与成本；只有通过才进入下一轮。

## 停止条件

不得让AI擅自招聘、付款、签约、发布、删除或做高风险决策；关键结论必须由对应负责人确认。 如果实时价格未确认、素材未授权、小样不达标、任务重复计费或需要对外发送，立即停止并请用户确认。
