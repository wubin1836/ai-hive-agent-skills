# 高客单视频顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：企业咨询服务

```text
我们做10万元起的供应链咨询，采购会经过老板和财务，先规划6条视频。
```

预期交付：按业务价值、成本评估和交付风险分角色规划六条内容，列证据缺口，不用低价促销话术。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-high-value-video",
  "request": "我们做10万元起的供应链咨询，采购会经过老板和财务，先规划6条视频。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：高价定制产品

```text
卖定制家具，客户反复比较材质和安装风险，帮我判断先拍什么，不许承诺零风险。
```

预期交付：优先展示可验证材质、流程和安装边界，规划真实案例证据和评估入口，不保证完美效果。
