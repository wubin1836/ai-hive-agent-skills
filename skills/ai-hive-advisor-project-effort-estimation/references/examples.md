# 项目工时估算顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：十页演示设计

```text
假设要设计10页演示稿，内容已定但图表需重做2页，允许2轮修改。请基于我提供的旧项目工时估算投入，每天只可做3小时。
```

预期交付：分列整理、设计、图表、沟通与修改工时，并说明日历交期。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-project-effort-estimation",
  "request": "假设要设计10页演示稿，内容已定但图表需重做2页，允许2轮修改。请基于我提供的旧项目工时估算投入，每天只可做3小时。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：口播剪辑素材不齐

```text
假设客户要5条90秒口播视频，只有2条素材到位，其余下周才给。请估算人工工时范围，把等待素材时间单独列出。
```

预期交付：区分已知剪辑工作与未知素材情景，给出素材变化后的重估条件。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-project-effort-estimation",

  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 需要生成素材时

按 [MCP 绑定说明](mcp-binding.md) 查询实际工具、模型与参数，用户批准数量和预算后，再按单次调用代码提交并复用任务 ID 查询结果。纯诊断不执行生成步骤。
