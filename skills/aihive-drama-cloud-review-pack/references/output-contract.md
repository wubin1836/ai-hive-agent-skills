# 输出契约

本项：AI短剧云创平台同类｜从创意到审片任务包。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `production-gates.md` | 阶段、必需输入、审核人、通过条件、阻断原因 |
| `rights-register.csv` | asset_id,owner,license_scope,evidence,expiry |
| `screening-issues.csv` | issue_id,shot_id,version,timecode,severity,owner,retest |

## 最小走读示例（纯虚构）

虚构样片出现未授权商标：阻断该镜头，替换为原创道具后再复验；不声称央视审核。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 审片自查不等于官方审查通过
- [ ] 无授权资产不进入制作
- [ ] 闭环必须有复验结果
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
