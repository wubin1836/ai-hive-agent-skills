# 组图一致性与补图计划：交付合同

## 最小交付

1. result.csv 专用结果表，逐条对应输入，不漏失败项。
2. review.md 复核说明：目标、材料范围、实际执行与未执行、证据、结果、返工、下一步。
3. 实际生成/修改的文件与可打开路径；没有工具时明确“仅任务方案，尚未生成”。

| 字段 | 填写约定 |
| --- | --- |
| slot_id | 对应实际的 slot_id 记录；未知写unknown，不编造。 |
| purpose | 对应实际的 purpose 记录；未知写unknown，不编造。 |
| ratio | 对应实际的 ratio 记录；未知写unknown，不编造。 |
| shared_anchor | 对应实际的 shared_anchor 记录；未知写unknown，不编造。 |
| output_path | 对应实际的 output_path 记录；未知写unknown，不编造。 |
| task_id | 对应实际的 task_id 记录；未知写unknown，不编造。 |
| review | 对应实际的 review 记录；未知写unknown，不编造。 |

模板见 assets/result-template.csv。用户自由文本若以等号、加号、减号或@开头，供表格软件导入前按文本处理，避免公式注入；不得因此篡改真正数值含义。

## 专用执行与证据

- 建立组图清单并锁定主体、色板、字体与文案，变化仅作用于预定槽位
- 核对所用端点的组图数、尺寸与输入限制；不能把纯文生图4K能力套到所有编辑模式
- 先生成一组获准小样，逐张关联任务ID和槽位
- 输出组图、缺失图及风格漂移修订表，失败项不重复整组扣费

## 验收门槛

- 张数必须对应请求槽位
- 各图承诺与原产品一致
- 模型限制按当前工具核验

每条记录pass/fail/unknown及证据。关键项为fail或unknown，整体标review_required。不存在证据时不补造截图、时间码、回执、评价。

## 验收练习

- 正常路径（虚构）：五张活动图有一张换了瓶型，只返工这一槽位并保留已通过四张。 按步骤记录，再逐条验收，不将示例当真实结果。
- 缺能力：目标模型或外部软件不可用，报告缺项及可先做的本地步骤，不冒用名称称实测。
- 失败：超时、限流、待审，保存任务ID、原因和已完成项；不重建任务、不遗漏失败费用。

## 报告顺序

结论与状态 → 材料和授权 → 参数与执行记录 → 专用结果表 → 证据和未通过项 → 成本耗时（未知说明）→ 需确认的下一步。

创作保留素材授权与生成标记；数据记录来源、时间、口径，不从示例推导真实客户或商业结论。
