# 人设信任证据顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：缩小专家称号

```text
我做了3年门店报表，自称数字化专家有点虚，这里是6个作品，帮我重建可信表达。
```

预期交付：把广泛称号拆成已证实能力，选作品与过程证据，给收窄表述，不补造资质。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-persona-evidence",
  "request": "我做了3年门店报表，自称数字化专家有点虚，这里是6个作品，帮我重建可信表达。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：客户不让实名

```text
咨询案例不错但客户不同意公开名称，如何在视频里证明经验又不泄密？
```

预期交付：建议获授权的匿名过程、方法和有限指标，明确不能暗示未获许可的品牌合作，不生成虚假证言。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

}
