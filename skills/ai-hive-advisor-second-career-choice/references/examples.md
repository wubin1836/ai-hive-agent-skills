# 第二职业选择顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：三个方向只试一个

```text
假设我做财务全职，每周只有6小时，想比较摄影、表格整理和知识写作，试错预算1000元。请选适合先试的方向并解释约束。
```

预期交付：对照固定交付时段、能力证据和职业冲突，给出一次低成本试做。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-second-career-choice",
  "request": "假设我做财务全职，每周只有6小时，想比较摄影、表格整理和知识写作，试错预算1000元。请选适合先试的方向并解释约束。",
  "external_actions": "未授权，不执行发布、群发或投放",

}
```

## 场景 2：不能使用主业客户
