# 专项执行参考

仅供材料准备与核对参考；具体要求以办理地当前官方规则为准，不保证资格或审批结果。

## 资料与交付约定

先确认任务地区/版本/时间范围及输出目录。证据表至少有 source_id、原文件页码或行号、原文、处理值、状态；状态使用 confirmed / uncertain / missing。来源身份与用户隐私不要在公开示例中泄露。

## 本项处理检查

- 数量单位先统一再乘单价，行金额与折扣后总额可复算
- 增项与原合同范围逐项关联，重复计费候选保留出处不直接认定欺诈
- 用户尺寸与报价计量口径不一致时列问题，不自行测量或估造工程量

## 示例请求（虚构输入，仅说明调用方式）

仅示例，以下文件名和情境均为假设，不表示已存在真实数据：假设我已提供 示例_装修初版报价.xlsx、示例_增项报价.xlsx、示例_尺寸与合同范围.pdf。请使用「装修报价查漏与增项核对助手」，逐项复算报价并比较增项，分开人工、主材与辅料，标记重复计量及未写清的包含范围。将结果写入我指定的本地目录，交付 renovation-quote-check-checklist.xlsx、renovation-quote-check-evidence.docx、renovation-quote-check-sources.json。本例先离线处理；输入、工具或适用规则不足时先交缺口说明，不编造结果。需要联网更新来源先征得我同意，不登录账户、不代提交或付款。

## 交付验收

- 按实际产物检查文件结构，不能将 Markdown 改后缀冒充 DOCX/XLSX/PDF。
- 公式、金额、日期和图式编码使用脚本或可审查公式复算；模型生成的数字未经复算不能标为已核验。
- DOCX/PDF应渲染检查页码、字体与批注；XLSX回读表头、数据类型和公式；SVG/HTML实际预览。工具缺失则说明哪项视觉/内容验收未完成。
- 缺少输入时交缺件列表，不创建虚构的全套结果来通过核验；仅完成部分时清楚列出已交与未交。

## 专业与使用边界

仅整理用户授权资料并核对当前属地官方来源，不作资格、批准或专业安全保证，不代登录、签名、提交、支付。实际运行时须重新核验政策及来源；个人隐私最小化。

## 可追溯来源入口

以用户授权的原件、指定版本或当前官方资料为依据；不预设已内置全文或数据库。

原创工作流设计；执行时必须补充用户适用的官方、合同或厂家资料。
