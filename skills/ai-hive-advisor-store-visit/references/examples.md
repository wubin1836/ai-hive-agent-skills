# 门店探店视频顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：首次未到店

```text
咖啡店请我拍30秒探店，但我还没去，这是菜单和地址，先准备提纲。
```

预期交付：提供现场待验证的体验题和镜头清单，价格按菜单待复核，不写已经喝过的主观评价。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-store-visit",
  "request": "咖啡店请我拍30秒探店，但我还没去，这是菜单和地址，先准备提纲。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：小店不靠人气

```text
我们新开的书店平日很安静，做45秒介绍，突出选书和座位，不要假排队。
```

预期交付：以真实书架和阅读动线规划镜头，补足预约、消费与开放信息，不设计虚假客流。
