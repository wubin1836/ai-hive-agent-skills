# 客户见证视频顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：已有访谈选段

```text
客户同意内部先审稿，用这段访谈选一分钟见证片，所有原话要带时间位置。
```

预期交付：语境完整的选段方案及尚未公开发布的确认清单。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-customer-testimonial",
  "request": "客户同意内部先审稿，用这段访谈选一分钟见证片，所有原话要带时间位置。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
