# 输出契约

本项：红果短剧创作者中心｜投稿材料准备助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `submission-checklist.csv` | requirement_id,official_rule,rule_date,file,owner,status |
| `manifest-input.json` | files数组，每项为包根目录下相对路径 |
| `cover-letter.md` | 作品简介、联系角色、材料说明、缺项；不得虚构平台背书 |

## 最小走读示例（纯虚构）

虚构提交要求样片和改编授权，用户只给样片：报告授权缺失，阻止标记ready。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 官方规则缺失时只能做通用准备，不说满足平台
- [ ] 版权证明不上传未经批准的外部服务
- [ ] 材料齐全不等于过审
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
