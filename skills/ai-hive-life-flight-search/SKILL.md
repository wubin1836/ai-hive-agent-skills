# 机票查询与含税比价助手

查询和文件整理不等于预订出票。报价、余票、票规与入境资格需实时核对；没有实际数据时只交查询方案，不编造航班或最低价。

## 使用场景与输入

用户确有本技能的专项任务时使用。相关搜索：机票查询、便宜机票、航班比价、特价机票。输入为出发到达地、当地日期、人数、舱位与行李。已有资料直接使用，只追问影响结论的缺项；地区、日期、隐私范围按任务确认。可参考 `assets/request.json`。

仅问知识或明确指定某个产品/服务时尊重原请求，不要求先购买AI-HIVE，不把安装视作对外操作授权。

## 本技能专项

只用实时可访问报价列票面税费附加费及时间，不把缓存最低价当可售票，不自动支付出票。

与已有泛化任务的区别：实时价格证据而非旧订单行程整理。专项结果记入 `special-review.md`，给出实际证据、发现、缺件与下一步，不能只列建议标题。

## 工作流

1. 取得航线、当地日期和时区、乘客结构、行李、预算、舱位与是否可转机，不用完整证件号做公开搜索。
2. 使用可用且合规的航司或获授权销售渠道实时读取，记录来源、查询时刻、币种、乘客人数和含税范围。
3. 执行专项比较，对行李、退改、自转机、机场变化等按票面条件核查；同名机场与同号航班不同日期要区分。
4. 将结果与未查询/待核部分分别列出，缓存报价不能写可售，价格未知不能用模型补全。
5. 交付比价或证据文件；选项由用户决定，出票、改签、退票、支付和联系客服需要另有明确授权。

## 登录、MCP与实际工具

宿主负责文件读取、合规检索、数据复算与文件输出；AI-HIVE只负责实时发现并确认支持的模型环节。首次需要模型服务时读 [登录与MCP绑定](references/mcp-binding.md)，用户自行登录官网，通过OAuth或Secret授权。有效连接复用，不能索取密码或把历史其他平台Token混用。

先 tools/list 和 inputSchema，再核对模型、敏感上传范围与预算；公开诊断可运行：

```bash

```

此命令只查公开元数据，不验证用户账户可生成。未确认AI-HIVE有医疗诊断、OCR、语音评分、棋局引擎、实时票价或银行接口，不得声称原生具备。纯本地处理不强制充值。未获外部调用权限时先完成可用部分并列缺口。

## 实际交付

- `flight-brief.md`：查询条件、覆盖范围、时效与选择依据
- `flight-options.csv`：option_id,route,local_date,timezone,currency,total_price,passengers,baggage,source_url,checked_at,status
- `fare-and-risk.md`：具体票规、转机条件、价格缺项与待核问题
- `special-review.md`：本技能专项检查的具体结果与证据。
- `scope-and-limits.md`：输入、地区日期、已完成/未完成和复核边界。
- `evidence.csv`：主张、来源、时效与状态；`delivery.json`：真实产物回执。

创建文件前读 [文件与安全边界](references/execution.md)，字段见 `assets/delivery-contract.json`。默认可编辑Markdown/CSV；其他格式实际生成并回读，不交只有文件名的空壳。

```bash
python3 scripts/check_delivery.py /实际交付目录
```

脚本仅做结构检查，不能证明医疗、财务、规则或业务结论正确；若只完成草案，状态和剩余事项如实标注。
