# 新业务试点顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：门店新增企业服务

```text
假设我有一家摄影店，想用4周、1万元测试企业证件照服务。不能影响周末散客交付，请设计试点及停止条件。
```

预期交付：限定接单量和测试客群，同时跟踪毛利、履约和主业影响。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-new-business-pilot",
  "request": "假设我有一家摄影店，想用4周、1万元测试企业证件照服务。不能影响周末散客交付，请设计试点及停止条件。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：咨询团队试订阅

```text
假设5人咨询团队拟向8位老客户测试月度问答订阅，试期6周。请用附上的历史问题设计验证方案，不做客户邀约。
```
