# 输出契约

本项：有戏AI同类流程｜短剧编剧导演交接助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `story-beats.csv` | beat_id,character_goal,new_information,emotion,source_scene |
| `director-shots.csv` | shot_id,beat_id,framing,action,eyeline,sound,duration |
| `approval.md` | 编剧保真意见、导演可拍意见、冲突裁决、批准版本 |

## 最小走读示例（纯虚构）

虚构主角发现信封：先拍可见封口，再拍反应，不提前显示信中答案破坏悬念。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 每个镜头服务明确剧情节点
- [ ] 不可为好看擅改人物关系
- [ ] 未生成素材必须标planned
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
