# 商业观点视频顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：观点缩小范围

```text
我想讲小公司不要急着招销售，依据是自己的两次创业经历，做60秒观点视频。
```

预期交付：将绝对判断收窄到具体阶段和条件，展示两次经历的局限，并讨论已有稳定需求的例外。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-business-opinion",
  "request": "我想讲小公司不要急着招销售，依据是自己的两次创业经历，做60秒观点视频。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：反对流行说法

```text
写一条反驳低价一定更好卖的90秒视频，我有两组真实报价记录。
```

预期交付：核对样本和产品差异，以记录支持有限结论，保留替代解释，不断言价格策略适用所有行业。
