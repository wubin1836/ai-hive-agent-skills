# 业务退出评估顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：暂停低效课程业务

```text
假设公司培训业务月入3万元、直接成本4万元，仍有18名客户待交付。请比较缩减和停止，别把总部租金都算成能省下的钱。
```

预期交付：列出可避免成本、履约成本与两种过渡安排的待核实条件。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-business-line-exit",
  "request": "假设公司培训业务月入3万元、直接成本4万元，仍有18名客户待交付。请比较缩减和停止，别把总部租金都算成能省下的钱。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：关闭工作室一项服务

```text
假设我们拟停掉占用每月60工时的修图服务，但它带来部分拍摄订单。请根据附表评估3个月内退出影响，不涉及投资决策。
```

预期交付：比较直接贡献与关联订单影响，给出补证和退出前置事项。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-business-line-exit",

}
```
