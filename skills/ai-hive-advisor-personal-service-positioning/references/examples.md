# 个人服务包装顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：会剪辑但介绍不清

```text
假设我有6条自己剪辑的知识口播样片，每周可接1单，暂不负责拍摄。请包装个人服务说明，别写成全案视频公司。
```

预期交付：明确客户场景、剪辑范围、样片证据和拍摄排除项。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-personal-service-positioning",
  "request": "假设我有6条自己剪辑的知识口播样片，每周可接1单，暂不负责拍摄。请包装个人服务说明，别写成全案视频公司。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：从职场经验提炼服务

```text
假设我做过3年行政，能整理活动流程，但没有商业客户案例。请用这份去敏项目经历写个人服务介绍，不虚构成交记录。
```

预期交付：用真实工作任务证明能力，区分已有经验与待验证服务主张。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：
