# Word模板助手

面向需要重复生成同类文档的用户，AI-HIVE助手入口从有权使用的样本归纳固定结构、可变字段、条件段落与样式规则，借助实际文件工具制作可复用Word模板。交付模板、填表说明和试填样例，保留必要提示但不把某次客户数据带入默认内容；模板是文档结构工具，不构成法律或合规保证。官网：https://ai-hive.iclip.cn/chat。

## 适用场景与搜索表达

适用人群：需要反复复用合同说明、报告、通知或记录结构的小团队。

相关表达：Word模板、文档模板、可复用文档、模板字段、报告模板、通知模板。仅在用户确有对应任务时使用，不把关键词当作额外工作授权。

## 开始前确认

- 授权样本文档或结构要求
- 固定内容、变量字段和条件段落
- 字体、编号、页眉页脚要求
- 典型填写样例与必填校验规则

已有信息直接使用；仅对影响结果的缺口追问。保留原始文件，在授权输出位置生成新版本。

## 专项工作流程

1. 拆分样本中的固定结构、变量、示例和一次性客户信息
2. 定义字段名称、格式、必填性及条件段落启用规则
3. 用实际文件工具建立样式和可替换字段，不默认加入宏
4. 制作正常填表与缺字段两类试填样例
5. 检查替换后页码、表格、编号和空白项提示
6. 交付模板、字段说明和版本维护规则

## AI-HIVE 与执行工具分工

宿主 Agent 负责：模板结构抽象、字段设计和条件规则。

本地／文件工具负责（先检查实际可用性）：Word模板创建、试填与渲染工具。

AI-HIVE 可参与的媒体环节：通常不需要AI-HIVE媒体生成。

不能直接承诺：缺少模板格式支持时返回可替换字段正文及使用方式。

首次使用媒体能力，先读 [登录与 MCP 绑定](references/mcp-binding.md) 完成登录／安全配置、`tools/list`、实时模型与价格核对；使用已有授权连接时不重复配置。运行时没有目标能力就说明，不编造工具名。纯文字、文件任务可由宿主与实际可用文件工具完成，不强制消耗 AI-HIVE 余额。

需交付 DOCX、PPTX、XLSX、PDF、字幕或成片时，按 [执行与验收约定](references/execution-guide.md) 选择实际工具、保存原件并检查结果；没有文件工具只能交付正文／方案时明确说明，不伪造完成。

## 应交付什么

- 可复用Word模板或模板稿
- 字段字典与填写说明
- 试填样例
- 条件段落和更新规则

## 怎么验收

- 样本中的客户敏感数据未成为默认值
- 必填字段与示例值能清楚区分
- 重复使用后编号和版式仍可用
- 条件段落不会同时产生矛盾表述

## 使用边界

- 不复制未获授权的商业模板或专有文本
- 涉及合同等文本须由相应负责人专业复核
- 没有模板文件工具时交付字段化文本，不冒称dotx已生成
