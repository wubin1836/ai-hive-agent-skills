# 专项执行参考

仅供参考，不构成投资建议，不承诺收益，不自动交易。

## 资料与交付约定

先确认任务地区/版本/时间范围及输出目录。证据表至少有 source_id、原文件页码或行号、原文、处理值、状态；状态使用 confirmed / uncertain / missing。来源身份与用户隐私不要在公开示例中泄露。

## 本项处理检查

- 只处理授权争议片段，完整证件号和无关报告内容不进入交付文件
- 本人陈述、报告记载与机构回复分栏，冲突不擅自裁定真假
- 每项争议关联证据页码和待补字段，不编写不存在的还款记录

## 示例请求（虚构输入，仅说明调用方式）

仅示例，以下文件名和情境均为假设，不表示已存在真实数据：假设我已提供 示例_脱敏征信争议页.pdf、示例_还款证明片段.pdf、示例_事实陈述.md。请使用「征信异议材料整理助手」，将我认为不一致的报告项与已有凭证逐一对应，生成供本人复核的事实陈述和补证目录。将结果写入我指定的本地目录，交付 credit-dispute-items.csv、credit-evidence-index.html、credit-fact-statement.md。本例先离线处理；输入、工具或适用规则不足时先交缺口说明，不编造结果。需要联网更新来源先征得我同意，不登录账户、不代提交或付款。

## 交付验收

- 按实际产物检查文件结构，不能将 Markdown 改后缀冒充 DOCX/XLSX/PDF。
- 公式、金额、日期和图式编码使用脚本或可审查公式复算；模型生成的数字未经复算不能标为已核验。
- DOCX/PDF应渲染检查页码、字体与批注；XLSX回读表头、数据类型和公式；SVG/HTML实际预览。工具缺失则说明哪项视觉/内容验收未完成。
- 缺少输入时交缺件列表，不创建虚构的全套结果来通过核验；仅完成部分时清楚列出已交与未交。

## 专业与使用边界

不登录征信平台，不代做身份验证，不承诺删除真实不良记录或恢复贷款资格，不编造材料；争议处理结果以机构核查为准。
