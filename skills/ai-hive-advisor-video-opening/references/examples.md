# 视频开头顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：删掉铺垫

```text
这条讲售后经验的视频前20秒都是自我介绍，给我三种更直接的开头。
```

预期交付：对应正文事实的三种进入方式及衔接句。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-video-opening",
  "request": "这条讲售后经验的视频前20秒都是自我介绍，给我三种更直接的开头。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
