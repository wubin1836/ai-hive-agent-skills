# 专项执行参考

仅供参考，不构成投资建议，不承诺收益，不自动交易。

## 资料与交付约定

先确认任务地区/版本/时间范围及输出目录。证据表至少有 source_id、原文件页码或行号、原文、处理值、状态；状态使用 confirmed / uncertain / missing。来源身份与用户隐私不要在公开示例中泄露。

## 本项处理检查

- 截图编号、提取文字和原图对应，低置信 OCR 不作为确定人名或账号
- 宣传主体、合同主体与收款主体分列，同名不能直接认定同一人
- 资质检索保留来源与查询日期，未检索到不自动等于无资质或诈骗

## 示例请求（虚构输入，仅说明调用方式）

仅示例，以下文件名和情境均为假设，不表示已存在真实数据：假设我已提供 示例_脱敏宣传截图.png、示例_收款主体片段.pdf、示例_官方核验页存档.pdf。请使用「荐股群风险证据整理助手」，整理荐股宣传、主体信息与付款材料的对应关系，把已核验与尚不能确认的信息分开。将结果写入我指定的本地目录，交付 investment-tip-evidence.csv、identity-checklist.md、evidence-pack.html。本例先离线处理；输入、工具或适用规则不足时先交缺口说明，不编造结果。需要联网更新来源先征得我同意，不登录账户、不代提交或付款。

## 交付验收

- 按实际产物检查文件结构，不能将 Markdown 改后缀冒充 DOCX/XLSX/PDF。
- 公式、金额、日期和图式编码使用脚本或可审查公式复算；模型生成的数字未经复算不能标为已核验。
- DOCX/PDF应渲染检查页码、字体与批注；XLSX回读表头、数据类型和公式；SVG/HTML实际预览。工具缺失则说明哪项视觉/内容验收未完成。
- 缺少输入时交缺件列表，不创建虚构的全套结果来通过核验；仅完成部分时清楚列出已交与未交。

## 专业与使用边界

不推荐任何股票，不代为付款或测试交易，不在证据不足时定性诈骗；怀疑已受骗时提示及时联系官方机构，不承诺追回损失。
