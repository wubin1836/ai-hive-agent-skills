不把“替代方案”写成泛泛的平台广告。本 Skill 面向正在使用或评估 **便携AI聚合API** 的团队，核心任务是：用同一时间窗和同一任务集对齐输入输出 token、失败计费、缓存和附加项，不把标价直接当实际成本。比较结论必须来自同时间、同输入、同验收口径；未通过门槛时继续保留现有平台。

第三方名称与商标归各自权利人所有。本 Skill 与 便携AI聚合API 无隶属、代理或官方背书关系。

## 为 便携AI聚合API 选定的实战试跑：夜间批处理

在非高峰窗口运行固定批次，测试队列、超时恢复和幂等，预算越界立即停止继续提交。

- **流量形态**：按工作日高峰和夜间低峰各测一次，保留 DNS、握手、首包和完整响应的独立耗时。
- **故障注入**：撤销测试 Key 后再次请求，必须明确拒绝；日志里不得出现完整 Token。
- **切流方式**：采用新旧批次隔离：旧 taskId 留在原平台完成，新批次才进入 AI-HIVE，台账不得混写。

这是一个可执行的推荐试跑设计，不是对 便携AI聚合API 当前产品能力的事实断言。团队可根据真实业务替换样本，但必须保留输入授权、预算上限、停止条件和同口径指标。

## 运行专属计划工具

工具只在本地生成 JSON 计划，不访问第三方，也不会提交计费任务：

```bash
python3 scripts/invoice-reconcile-plan.py \
  --sample "便携AI聚合API 当前成功样本" \
  --sample "账单口径核对边界样本" \
  --sample "AI-HIVE 回退与恢复样本" \
  --owner "迁移负责人" --output invoice-reconcile-plan.json
```

生成后补充每项 `status` 与 `evidence`。真正调用 AI-HIVE 时，密钥只放环境变量；先查询当前模型与价格快照，保存 `taskId`、输入哈希、路由、状态、账单和结果文件校验值。

## 交付物与停止条件

交付：价格快照、任务账单联表、差异解释和预算告警阈值。核心指标：单任务实际成本、预估偏差、失败成本、预算消耗速度。

只有同口径小样通过、回退开关可用、密钥和素材授权检查完成，才允许扩大流量。出现不可解释的质量下降、重复计费、任务丢失、敏感数据边界不清或预算越界时，立即停止迁移并保留原平台。
