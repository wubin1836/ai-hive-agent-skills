# 个人知识资产盘点顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：三百篇笔记先整理哪类

```text
假设我有300篇笔记，只提供目录和20篇样本，每周可整理2小时。请按我常做的培训任务给首批维护建议，不声称读过全部内容。
```

预期交付：按样本和目录建立暂定资产地图，区分确定结论与需要抽查的资料。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-personal-knowledge-assets",
  "request": "假设我有300篇笔记，只提供目录和20篇样本，每周可整理2小时。请按我常做的培训任务给首批维护建议，不声称读过全部内容。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：模板和外部资料混在一起

```text
假设文件夹有15份自制模板、8份客户案例和40篇外部文章。请根据清单判断复用与隐私风险，只建议整理顺序，不删除或公开文件。
```

预期交付：区分原创、受限案例和参考资料，列出更新、去敏与权限确认事项。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：
