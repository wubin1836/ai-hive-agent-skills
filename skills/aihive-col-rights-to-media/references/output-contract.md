# 输出契约

本项：中文在线AI短剧方向｜授权IP内容生产助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `rights-matrix.csv` | source_id,medium,territory,term,allowed_changes,evidence,status |
| `derivative-register.csv` | asset_id,parent_source,version,medium,rights_id,usage_limit |
| `production-brief.md` | 角色资产任务、分镜、语言、预算、阻断项 |

## 最小走读示例（纯虚构）

虚构只获中文漫画改编权：可以准备中文漫画分镜，英文配音动画属于待追加授权。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 公开可见不等于商用授权
- [ ] 音色肖像分别确认
- [ ] 不把中文在线IP库当随Skill赠送
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
