# Etsy创意卖家AI店铺内容：专项实施卡

## 用户与结果

- 目标用户：跨境个人卖家、出海创业者、独立站经营者、海外内容创作者和小型国际化团队。
- 希望结果：围绕手作与创意商品真实过程生成故事与图文。
- 交付物：市场与语言矩阵、本地化内容、图片视频版本、客服模板、渠道规格和人工文化审核。
- 核心指标：原创性风险项、收藏率、上新时间。

## 最小样例

1. 只选一个真实用户或一个真实商品/服务。
2. 使用3—5条已授权资料，不上传不必要的隐私数据。
3. 先查询当前模型与价格，再生成1份内部草稿。
4. 由人工检查事实、品牌、版权、隐私和渠道规则。
5. 记录结果与成本；只有通过才进入下一轮。

## 停止条件

不得假设不同市场规则相同；广告、隐私、版权、平台和商品合规必须按目标国家与渠道复核。 如果实时价格未确认、素材未授权、小样不达标、任务重复计费或需要对外发送，立即停止并请用户确认。
