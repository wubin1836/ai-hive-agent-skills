# 管理层例会顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：每周例会重构

```text
这是六部门周报和上次决议，用60分钟管理例会只处理需要跨部门拍板的事。
```

预期交付：例外筛选、旧决策复查与决策型议程。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-leadership-review",
  "request": "这是六部门周报和上次决议，用60分钟管理例会只处理需要跨部门拍板的事。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：反复讨论同一事

```text
交付延期连续三周都在讨论，按记录判断这周缺证据还是缺有权拍板的人。
```

预期交付：决策阻塞定位、需补输入及闭环方案。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-leadership-review",
  "request": "交付延期连续三周都在讨论，按记录判断这周缺证据还是缺有权拍板的人。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 需要生成素材时

按 [MCP 绑定说明](mcp-binding.md) 查询实际工具、模型与参数，用户批准数量和预算后，再按单次调用代码提交并复用任务 ID 查询结果。纯诊断不执行生成步骤。
