# 输出契约

本项：营销素材合格成本助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `cost-input.json` | records，每次成本归属output_id,cost,currency,accepted |
| `quality-definition.md` | 统计单位、质量阈值、复用与人工分摊口径 |
| `cost-findings.md` | 失败原因、缺失费用、平台同题限制、优化建议 |

## 最小走读示例（纯虚构）

虚构3次生成同一张图分别2、2、3元，最后合格：总成本7元/1件，不是每件3元。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 失败费用仍计入总额
- [ ] 重复验收只算同一件
- [ ] 无合格件单位成本为null
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
