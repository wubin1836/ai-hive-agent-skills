# 视频钩子测试顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：两版开头测试

```text
给同一条产品讲解的两个开头设计测试，封面和正文尽量不变，先不发布。
```

预期交付：假设、控制变量、记录字段和判读条件。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-hook-experiment",
  "request": "给同一条产品讲解的两个开头设计测试，封面和正文尽量不变，先不发布。",
  "external_actions": "未授权，不执行发布、群发或投放",

}
```
