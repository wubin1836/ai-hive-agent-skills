# 企业家访谈顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：采访转型企业主

```text
采访一家传统加工厂老板，主题是转向小批量订单，只有30分钟，给8个主问题及追问。
```

预期交付：围绕订单变化、产线取舍、成本和客户反馈形成八问，经营数字列为待确认，不预设转型一定成功。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-entrepreneur-interview",
  "request": "采访一家传统加工厂老板，主题是转向小批量订单，只有30分钟，给8个主问题及追问。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：已有提纲太空

```text
这份访谈全是创业初心和未来愿景，改成能问出真实经营选择的提纲。
```

预期交付：将抽象问题改为具体事件和替代方案追问，说明哪些背景资料仍需补充，不制造受访者故事。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：
