# 跨页表格识别与数值错位复核助手：场景示例

## 场景一：首次执行

```text
这份三页设备报价表第二页没有表头，OCR把数量和单价混了。请按原图恢复列关系，检查单位和合计，输出CSV、单元格证据和待确认项，不修改原始PDF。
```

输入记录示例：

```json
{
  "mode": "演示数据",
  "header": [
    "数量",
    "单价"
  ],
  "ocr_row": {
    "数量": "120.00",
    "单价": "2"
  },
  "user_verified_original": {
    "数量": "2",
    "单价": "120.00"
  },
  "source": "第2页第3行"
}
```

人工构造的输出片段，仅用于解释格式；不是付费模型生成结果或测试成绩：

```json
{
  "illustrative_only": true,
  "sample": {
    "mode": "人工演示，仅依据给定原文",
    "corrected_row": {
      "数量": "2",
      "单价": "120.00"
    },
    "issue": "两列错位",
    "evidence": "第2页第3行",
    "source_pdf_modified": false
  }
}
```

## 场景二：复核与返工

```text
请检查本次输出是否满足：每个关键数值能回指原始页面区域。；续页没有错继承表头、单位或年度。；缺失和不确定值不被自动改成零。；复算差异保留，原始值与修订候选分列。。
把结论分成已验证、未验证、需补资料三类。只修复有证据的问题，不覆盖原文件；先列返工清单和额外调用费用。
```

复核记录建议字段：`check / evidence / actual / status / next_action`。

## 场景三：当前模型或工具不可用

```text
如果当前AI-HIVE没有本任务需要的精确模型或工具，请不要生成冒名结果。给我已发现的能力、缺失条件、可先完成的本地准备材料，以及需要我选择的替代方案。
```

本地演练：在MCP未配置时仍可执行 `scripts/workflow.py`，但其结果必须保持 `phase=offline_plan`、`model_calls=0`。这只能验证工作单，不是验证模型能力。
