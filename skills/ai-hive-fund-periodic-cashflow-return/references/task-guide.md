# 专项执行参考

仅供参考，不构成投资建议，不承诺收益，不自动交易。

## 资料与交付约定

先确认任务地区/版本/时间范围及输出目录。证据表至少有 source_id、原文件页码或行号、原文、处理值、状态；状态使用 confirmed / uncertain / missing。来源身份与用户隐私不要在公开示例中泄露。

## 本项处理检查

- 现金流符号、实际日期与期末估值正确，红利再投不当外部新增投入
- XIRR 检查正负现金流、候选多根与残差，失败时报告状态而非硬填百分比
- 总损益可由投入取回与期末价值复算，历史年化不外推为未来收益

## 示例请求（虚构输入，仅说明调用方式）

仅示例，以下文件名和情境均为假设，不表示已存在真实数据：假设我已提供 示例_定投投入取回.csv、示例_现金分红.csv、示例_期末估值.json。请使用「基金定投收益复算助手」，按实际日期复算历史总损益及适用的 XIRR，给出求解残差；如有多根或不收敛就明确停止单一收益率展示。将结果写入我指定的本地目录，交付 periodic-investment-cashflows.csv、historical-return-calculation.xlsx、solver-diagnostics.md。本例先离线处理；输入、工具或适用规则不足时先交缺口说明，不编造结果。需要联网更新来源先征得我同意，不登录账户、不代提交或付款。

## 交付验收

- 按实际产物检查文件结构，不能将 Markdown 改后缀冒充 DOCX/XLSX/PDF。
- 公式、金额、日期和图式编码使用脚本或可审查公式复算；模型生成的数字未经复算不能标为已核验。
- DOCX/PDF应渲染检查页码、字体与批注；XLSX回读表头、数据类型和公式；SVG/HTML实际预览。工具缺失则说明哪项视觉/内容验收未完成。
- 缺少输入时交缺件列表，不创建虚构的全套结果来通过核验；仅完成部分时清楚列出已交与未交。

## 专业与使用边界

不承诺定投收益，不用历史年化预测未来，不建议定投标的或金额；数学求解结果不等于平台认证业绩。
