# 公众号排版与封面一体化：专项实施卡

## 需求信号

公开市场中与该需求最接近的高下载 Skill 达到 **10,151** 次下载、**11** 次收藏。这个数字只用于说明用户需求强度，不表示授权、合作或内容来源。

## 专项目标

使用 AI-HIVE MCP，把用户对“公众号排版与封面一体化”的模糊要求转成可确认、可计费控制、可恢复和可验收的工作流。

## 执行步骤

1. 先梳理受众、目标和材料可信度
2. 建立内容结构并标出需要视觉化的位置
3. 围绕“公众号排版与封面一体化”定义专属交付标准，而不是只返回泛化提示词。
4. 完成文字初稿与关键图解小样
5. 修订逻辑、语言和版式
6. 按用户需要交付可编辑内容与最终预览
7. 标题钩子与视觉底图分开制作，至少给出两个构图差异明显的A/B方向。

## 专项验收

- 基础指标：逻辑清晰、事实可追溯、视觉支持观点、格式可用、无明显AI套话和交付完整。
- 专项指标：缩略尺寸辨识度、标题安全区与点击意图。
- 任何无法确认的事实、实时数据、平台规则或模型能力必须标注待核验。
- 生成任务必须记录模型、参数、输入哈希、价格快照和 taskId。

## 失败恢复

1. 本地超时：先调用 `ai_hive_get_task` 查询原任务。
2. 模型不可用：重新调用 `ai_hive_list_models`，返回候选差异后让用户选择。
3. 素材不合格：指出缺失项，只重做受影响的最小步骤。
4. 预算不足：缩小数量、时长或分辨率，不擅自改为高成本模型。
