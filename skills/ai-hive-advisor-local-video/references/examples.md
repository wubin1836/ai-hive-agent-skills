# 同城获客视频顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：只服务三公里

```text
我做家电清洗，只接门店3公里内订单，视频总来外区咨询，给5条内容建议。
```

预期交付：强化真实服务范围和适配场景，给五条主题与接单条件表达，设计地域记录表，不爬取附近客户。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-local-video",
  "request": "我做家电清洗，只接门店3公里内订单，视频总来外区咨询，给5条内容建议。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：门店不好找

```text
书店在写字楼二楼，很多人问怎么上来，先规划一条30秒到店说明视频。
```

预期交付：使用真实入口、楼层和开放信息安排镜头，列需实拍路线，不让生成街景冒充导航。
