# AI视频动作顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：动作太多

```text
我想5秒内人物开门、走进房间、坐下再拿杯子，帮我拆成更稳妥的镜头，不生成。
```

预期交付：分离四个动作和镜头运动，建议拆镜或删减，规定各镜头可见结束状态，不保证某模型能一次完成。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-motion-design",
  "request": "我想5秒内人物开门、走进房间、坐下再拿杯子，帮我拆成更稳妥的镜头，不生成。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：产品悬浮问题

```text
这段视频杯子像悬浮，想改成稳定放在桌上、镜头缓慢靠近，先给诊断。
```

预期交付：有可查看片段时指出接触关系和运动冲突；缺片则标假设，建议主体静止与单一镜头运动方案。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-motion-design",

  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
