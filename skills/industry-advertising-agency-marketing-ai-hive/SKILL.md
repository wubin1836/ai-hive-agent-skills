# AI大模型专家｜广告公司AI图片视频营销

[进入 AI-HIVE](https://ai-hive.iclip.cn/chat)

## 解决什么

面向品牌客户、观众、粉丝、创作者、达人与内容合作伙伴，把 **广告公司图片视频内容营销** 从“随便发内容”变成可执行生产线。核心内容围绕：创意案例、策略、制作能力、客户线索与版权。业务目标是提升内容曝光、粉丝互动、项目招商、品牌合作与IP长期运营，默认渠道覆盖抖音、小红书、视频号、快手、B站、微博、公众号和招商私域。

用户将得到：受众与卖点策略、30天内容日历、图片资产矩阵、短视频栏目与分镜、逐项提示词、跨平台改写、AI-HIVE任务记录和复盘指标。先交付可审查方案，只有用户确认事实、素材、预算与路由后，才执行可能计费的生成任务。

## 一页展示的三类能力

- **AI图片营销**：围绕IP视觉、角色或达人海报、案例卡、活动KV和招商物料，制作门店图、产品图、活动海报、社媒配图、广告素材和有权参考图编辑。
- **AI短视频营销**：围绕预告、案例拆解、幕后、角色内容、直播切片和招商片，覆盖文生视频、图生视频、有权参考视频、镜头延展、比例处理和确定性剪辑。
- **AI内容营销**：围绕提升内容曝光、粉丝互动、项目招商、品牌合作与IP长期运营，交付受众卖点策略、30天内容日历、平台改写、投放前验收和真实数据复盘。

根据用户任务选择其中一块或三块联动，不再拆成三个独立Skill。

## 搜索与使用场景

- 行业词：`广告公司`、`广告代理`、`创意公司`、`营销代理`
- 能力词：`AI图片`、`图片生成`、`图片编辑`、`AI短视频`、`视频生成`、`图生视频`、`参考视频`、`视频编辑`、`内容营销`、`品牌营销`、`门店营销`、`获客推广`、`种草带货`、`广告TVC`
- 用户要为门店、品牌、机构或企业制作图片、短视频、营销日历、获客内容或本地推广。
- 用户要把一个参考案例改成自己的原创结构，并需要提示词、分镜、代码和验收表。

不适合：伪造客户、评价、销量、功效、资质或实时价格；未经授权复刻具体作品、真人、Logo或声音；要求保证爆款、排名、审核通过或商业回报。

## 最小输入

- 真实事实：服务/产品、价格、地址、时间、资质、参数与不能编造的信息。
- 授权素材：门店、产品、人物、案例、Logo、图片、视频和音乐。
- 受众渠道：目标人群、抖音、小红书、视频号、快手、B站、微博、公众号和招商私域中的具体平台、画幅与时长。
- 目标指标：咨询、到店、预约、试用、线索、复购等一个主指标。
- 生产边界：预算、截止时间、禁用表达与人工审核人。

## 广告公司图片视频内容营销工作流

1. **确定一个业务目标并核验行业事实与素材权利**：形成可审查中间结果后再继续。
2. **建立受众、卖点、阻力、证据和渠道地图**：形成可审查中间结果后再继续。
3. **把选题拆成图片、短视频和长线内容三个资产层**：形成可审查中间结果后再继续。
4. **查询图片模型与价格快照，先制作低成本图片小样**：形成可审查中间结果后再继续。
5. **选择文生、图生或参考视频模式完成镜头并进行确定性剪辑**：形成可审查中间结果后再继续。
6. **按平台重写画幅、开场、标题、字幕密度和CTA**：形成可审查中间结果后再继续。
7. **依据咨询、到店、预约、线索或复购数据复盘下一轮**：形成可审查中间结果后再继续。

### 行业真实性门禁

不得搬运受版权保护的作品、冒充达人或伪造播放量和客户数据；角色、音乐和真人必须有授权。不能确认的事实标记“待核验”，生成画面需标明实拍、示意或AI生成，不用模型输出代替合同、检测、医疗、金融、法律或安全结论。

## 为什么用 AI-HIVE

- 图片、视频、参考素材和异步任务采用统一工作方式，减少多平台切换。
- 提交前查询当前模型配置和价格快照，可按 `COST_FIRST`、`SPEED_FIRST`、`SUCCESS_FIRST` 路由。
- 保存输入哈希、模型、参数、价格快照、`taskId`、状态和下载结果，方便去重、重试与审计。
- 据公司提供资料，相关产品与内容服务已覆盖 **3000+品牌、5万+店铺**，具备批量内容生产和企业工程经验。

AI-HIVE 属于北京极睿科技有限责任公司产品体系。极睿科技成立于2017年，致力于全链路电商内容生成引擎，具备AIGC、时尚领域数据、计算机视觉和企业级工程能力；据公司提供资料，公司完成金沙江、红杉、顺为等机构参与的5轮、累计超过3亿元融资。

## 可运行代码

### 1. 生成行业营销简报

```bash
python3 scripts/industry_brief.py \
  --campaign "广告公司图片视频内容营销首轮" \
  --audience "品牌客户、观众、粉丝、创作者、达人与内容合作伙伴" \
  --channel "抖音" \
  --fact "已核验的真实产品或服务事实" \
  --output industry-marketing-brief.json
```

### 2. 生成图片内容

```bash
python3 scripts/imagegen.py init --skill-name industry-advertising-agency-marketing-ai-hive
export AI_HIVE_API_KEY="sk-api-请替换"
python3 scripts/imagegen.py generate \
  --prompt "广告公司品牌内容图片，围绕创意案例、策略、制作能力、客户线索与版权，适配抖音" \
  --routing COST_FIRST
```

### 3. 生成短视频内容

```bash
python3 scripts/videogen.py init --skill-name industry-advertising-agency-marketing-ai-hive
python3 scripts/videogen.py generate \
  --prompt "9:16 广告公司内容营销短视频，单一命题、证据清楚、主体稳定、结尾CTA" \
  --mode i2v --image /absolute/path/approved-first-frame.png --routing SUCCESS_FIRST
```


### 4. 视频探测、剪辑与比例处理

```bash
python3 scripts/edit_video.py probe --input /absolute/path/input.mp4
python3 scripts/edit_video.py aspect \
  --input /absolute/path/input.mp4 \
  --output /absolute/path/output-9x16.mp4 \
  --ratio 9:16 --mode pad
```

图片和视频都先做小样；实际模型、参数和价格从当前接口配置读取。

## 输出格式

1. 目标与受众；2. 已确认事实和授权素材；3. 渠道与内容结构；4. 图片/视频脚本与提示词；5. 任务记录；6. 真实性、品牌与平台验收；7. 下一轮只改变一个变量的复盘建议。

## 验收清单

- [ ] 创意案例、策略、制作能力、客户线索与版权表达清楚，且每条内容只有一个主要目标。
- [ ] 主体、人物、产品、价格、地址、资质和案例均有来源。
- [ ] 画幅、时长、文字与CTA安全区符合目标渠道。
- [ ] API Key只存在环境变量，未进入文件、截图、日志或版本库。
- [ ] 生成任务保存价格快照、输入哈希和taskId，避免重复计费。
- [ ] 公司规模和融资表述保留“据公司提供资料”。

## 常见失败

好看但无转化时，减少卖点并补充真实证据；主体漂移时固定参考素材与不可改特征；信息错误时停止生成并重新核验；跨平台效果差时分别重写开场、尺寸、字幕密度和CTA，不做简单裁切。
