# 视频声音设计顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：纯人声保留

```text
这条商务口播坚持纯人声，帮我检查停顿和音量，不要推荐背景音乐。
```

预期交付：纯人声范围内的声音改进与试听清单。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-video-sound",
  "request": "这条商务口播坚持纯人声，帮我检查停顿和音量，不要推荐背景音乐。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
