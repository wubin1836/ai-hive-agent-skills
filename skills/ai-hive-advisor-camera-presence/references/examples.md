# 镜头表现力顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：视线问题

```text
看这段30秒视频，帮我判断是不是一直在找提词器，只给两项练习。
```

预期交付：可见视线问题的时间定位与两项可复拍练习。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-camera-presence",
  "request": "看这段30秒视频，帮我判断是不是一直在找提词器，只给两项练习。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：手势安排

```text
我讲三个步骤时手很乱，用这段素材帮我设计克制一点的手势。
```

预期交付：对应三个步骤的动作提示与无需改变的部分。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-camera-presence",
  "request": "我讲三个步骤时手很乱，用这段素材帮我设计克制一点的手势。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 需要生成素材时

按 [MCP 绑定说明](mcp-binding.md) 查询实际工具、模型与参数，用户批准数量和预算后，再按单次调用代码提交并复用任务 ID 查询结果。纯诊断不执行生成步骤。
