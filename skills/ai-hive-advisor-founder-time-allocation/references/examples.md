# 创始人时间分配顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：会议挤占客户拜访

```text
假设我每周工作45小时，附有过去10天记录，希望每周留8小时见关键客户，周三晚不工作。请给时间分配建议。
```

预期交付：从已有会议与事务中寻找腾挪空间，给出含缓冲的周安排。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-founder-time-allocation",
  "request": "假设我每周工作45小时，附有过去10天记录，希望每周留8小时见关键客户，周三晚不工作。请给时间分配建议。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：一人公司减少碎片化

```text
假设我每天被客服打断15次，仍需每周完成2份方案。请根据这份打断记录设计两个集中处理窗口和例外规则。
```

预期交付：区分真正紧急事项与可批处理事项，保护方案制作时段。
