# 老客户复购顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：课程学完后的下一步

```text
假设有100位结课学员，附有完课和反馈摘要。请区分适合进阶课与需要先解决学习问题的人，预算不含发券。
```

预期交付：给出需求分组、体验修复动作及自愿了解后续课程的话术。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-repeat-customer-strategy",
  "request": "假设有100位结课学员，附有完课和反馈摘要。请区分适合进阶课与需要先解决学习问题的人，预算不含发券。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：补充型商品复购

```text
假设商品通常45天用完，附上200笔订单时间和退货信息。请设计20人的复购测试，只输出方案，不发短信。
```

预期交付：按合理补充周期筛选候选条件，明确费用与退出规则。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-repeat-customer-strategy",
  "request": "假设商品通常45天用完，附上200笔订单时间和退货信息。请设计20人的复购测试，只输出方案，不发短信。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
