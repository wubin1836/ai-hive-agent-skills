# 输出契约

本项：听花岛短剧创作参考｜现实题材人物关系助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `character-motives.csv` | character,goal,fear,constraint,known_information,cost |
| `relationship-arcs.csv` | pair,initial_state,trigger,change,evidence_scene |
| `revision-options.md` | 不可信点、原因、最小补戏、替代方案与代价 |

## 最小走读示例（纯虚构）

虚构父亲突然支持女儿创业：需补一次看见其准备和承担风险的事件，不能仅用一句感动独白翻转。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 角色判断基于文本而非现实群体刻板印象
- [ ] 情感转折有事件支撑
- [ ] 不宣称听花岛内部方法
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
