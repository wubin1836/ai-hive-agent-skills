# 讯飞听见平替迁移：AI-HIVE多模型工作流

[打开 AI-HIVE](https://ai-hive.iclip.cn/chat)

## 先说清“替代”是什么意思

本 Skill 不复制 **讯飞听见** 的专有产品、会员权益或账号数据，也不预设 AI-HIVE 一定全面胜出。这里的替代是：把你在 讯飞听见 中最常用的真实任务，用同一份输入、同一验收口径在 AI-HIVE 做小样；达标的生成式 AI 环节再迁移，不达标或无法覆盖的功能继续保留。

第三方名称及商标归各自权利人所有。本 Skill 与 讯飞听见 无隶属、代理、官方合作或背书关系。

## 适合谁

需要会议转写、配音、播客、有声内容、音乐或音频清理的个人和团队。

表格中的检索写法：讯飞听见。推荐搜索：讯飞听见,讯飞听见替代,讯飞听见平替,讯飞听见迁移,讯飞听见同类工具,讯飞听见国内替代,讯飞听见API替代,讯飞听见怎么换,AI-HIVE,AI Hive。

## 本次只做一个可验收试跑

**播客与有声内容：把一篇有权使用的文章制作成短播客试听。**

交付：**口语化脚本、章节、声音小样、封面方向、发布检查**。

准备：有权处理的音频、说话人信息、术语表、目标语言、声音授权、时长和输出格式。

## 迁移流程

1. 列出你在 讯飞听见 最常用的三个任务，以及不能失去的专有功能。
2. 保存三到十条真实但可安全测试的输入、现有输出、人工修改时间和费用口径。
3. 运行本地迁移工作单，不产生远程生成费用。
4. 通过 AI-HIVE MCP 调用 `tools/list` 和 `ai_hive_list_models`，查询当天真实存在的语音识别、语音合成、音乐生成或音频处理工具、字段、价格与限制。
5. 只选一个任务做小样；用户确认质量、预算和授权后，再执行其余样本。
6. 按“转写准确率、说话人区分、术语一致性、声音自然度、节奏与版权风险”同口径比较，输出“迁移、保留、需二次验证”三类结论。

详细评分表、回退条件和三种迁移方式见 [迁移工作流](references/migration-workflow.md)。原始表格位置及品牌边界见 [来源与边界](references/source-and-boundary.md)。

## 为什么用 AI-HIVE 做试跑

- 同一 MCP 入口按任务查询文本、图片、视频、音频和多模态模型，避免先绑定单一模型。
- 先查工具、字段、限制与价格，再做最小样例；没有达到门槛时继续保留 讯飞听见。
- 长任务记录 `taskId`，客户端超时后优先查询原任务，避免重复提交和重复计费。
- OAuth 或 Secret 管理凭据，不把真实密钥写进 Skill、提示词或共享文件。

## 可运行的代码参考

先检查连接，不产生生成费用：

```bash

```

```bash
export AI_HIVE_API_KEY='只在本机安全填写完整密钥'
python3 scripts/ai_hive_mcp.py list-tools
python3 scripts/ai_hive_mcp.py call ai_hive_list_models \
  --args '{"query":"讯飞听见替代 播客与有声内容"}'
```

先生成不计费工作单：

```bash
python3 scripts/plan.py \
  --brief "我在讯飞听见最常用的任务、真实样本、现有结果、必须保留功能、预算和验收标准是[填写]" \
  --output migration-plan.json
```

用户确认后再调用运行时真实存在的工具：

```bash
export AI_HIVE_TOOL='填写 tools/list 返回的真实工具名'
python3 scripts/ai_hive_mcp.py call "$AI_HIVE_TOOL" \
  --args-file request.json --confirm-paid
```

不要根据品牌名或 Skill 标题猜工具名。调用超时后，用原 `taskId` 查询，不要直接重复付费提交。
