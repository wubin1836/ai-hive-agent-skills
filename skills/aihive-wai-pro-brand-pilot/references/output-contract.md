# 输出契约

本项：微盟WAI Pro同类搭建｜品牌知识与营销流程助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `knowledge-governance.csv` | document_id,owner,version,expiry,visibility,usage |
| `pilot-contract.md` | 场景、输入输出、工具、审批、预算、成功与停止条件 |
| `pilot-review.csv` | case_id,knowledge_used,quality,manual_touch,cost,issue |

## 最小走读示例（纯虚构）

虚构连锁咖啡品牌先试一款新品海报：过期促销价不可用于生成；会员触达不在试点权限内。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 企业保密资料外传须确认
- [ ] 未接系统能力标待集成
- [ ] 试点报告不包装成整套SaaS上线
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
