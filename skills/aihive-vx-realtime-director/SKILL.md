# Vivix Real-Time Director平替｜剧情调度状态机

把这一具体任务落成可检查的文件、素材或制作交接包。AI-HIVE 承担当前账户实际支持的模型环节，本地宿主承担文件、媒体或项目状态处理；不可把规划文档称为已生成成片。

## 适用意图

适用于：Vivix导演、Real-Time Director、剧情动态调度。用户明确选择其他产品时不擅自迁移；“平替”只限下面的具体任务，不等于复制完整产品。

## 最小输入

- 剧情目标
- 事件优先级
- 终止规则

只追问阻碍执行的缺项；草稿可使用标明的假设，涉及肖像、版权、付费、上传和外部修改则先核对范围。

## 工作流

1. 分开观众输入、叙事事件和镜头执行队列。
2. 处理相互冲突指令，优先保留已确认事实和安全退出。
3. 用事件回放验证同一状态不会触发互斥结局。

优先在用户选定的项目目录新增输出，保留原文件。准备生成时读取 [AI-HIVE 登录与 MCP 指南](references/ai-hive-connection.md)，复用连接或完成浏览器授权，再发现真实工具、模型、schema 和价格。未授权的付费或外部上传先停在方案；已获授权则先验证小样，再按预算推进。

## 交付契约

- `story-state.json`：states、transitions
- `director-policy.md`：本步骤实际产生的结果与证据。
- `replay-results.json`：本步骤实际产生的结果与证据。

文件间用稳定的角色、资产、镜头或任务 ID 关联；所有数值写清单位，未知项用 null 并附原因。JSON 必须能解析，引用必须指向存在的文件或有凭据的任务，方案中的待生成路径不得混入已完成清单。

## 验收与返工

明确拒绝无法满足的事件，不任意重写世界规则。

分别报告：已实际完成、待人工确认、工具或接口缺口。视频需打开或用真实媒体工具检查，图片需查看，结构化文件需读回。失败只返工受影响项；已接受任务超时先查询，不重复计费提交。401/403、429、内容审核、预算不足或结果状态不明时按连接指南停止，不绕过。

## 本地检查工具

执行前读取 [数据格式与检查说明](references/local-check.md)，再使用 `scripts/check_story_state.py`。这是本地结构/状态检查，不替代视觉审片或实时模型验收。

## 实时交付限制

默认交付设计、离线预演或本地原型。只有获得真实支持的实时端点并完成对应测试后，才可以写“实时已实现”。异步视频生成、循环播放或预制分支不能冒充全双工与实时世界模型。
