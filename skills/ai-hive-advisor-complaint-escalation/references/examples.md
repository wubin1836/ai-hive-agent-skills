# 客户投诉升级顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：反复转部门

```text
客户退款投诉在销售和客服间转了三次，用这些记录列老板该拍板的事项，别直接承诺赔偿。
```

预期交付：事实时间线、权限卡点和可审批选项。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-complaint-escalation",
  "request": "客户退款投诉在销售和客服间转了三次，用这些记录列老板该拍板的事项，别直接承诺赔偿。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：扩大风险

```text
两名客户反映同批产品可能有安全问题，先组织内部升级资料，不要写已确认缺陷。
```

预期交付：陈述与证据分离、紧急升级及待专业核验事项。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-complaint-escalation",

}
```
