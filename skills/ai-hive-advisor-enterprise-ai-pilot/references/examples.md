# 企业AI落地顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：五个流程选一个先试

```text
假设12人公司想在会议整理、报价、报销、客服和人事筛选五项中先试一项，每月预算1000元。请根据我提供的样例评估，不购买工具。
```

预期交付：比较敏感度、出错代价与复核成本，选择有限试点并给出理由。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-enterprise-ai-pilot",
  "request": "假设12人公司想在会议整理、报价、报销、客服和人事筛选五项中先试一项，每月预算1000元。请根据我提供的样例评估，不购买工具。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：客服草稿试点

