# 渠道合作顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：摄影店与婚礼策划合作

```text
假设摄影店要与1家婚礼策划公司试合作30天，最多接5单。请梳理线索转交、客户沟通和退单时的分成确认问题。
```

预期交付：输出限量合作流程、接手责任与待双方确认的结算条件。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-channel-collaboration",
  "request": "假设摄影店要与1家婚礼策划公司试合作30天，最多接5单。请梳理线索转交、客户沟通和退单时的分成确认问题。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：课程转介绍

