# 经营优先级顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：三人团队取舍

```text
假设3人团队下月只能投入120小时，待办有官网改版、20位客户回访和新套餐设计。请按附表排顺序，必须保留每周交付。
```

预期交付：输出容量可行的重点与暂缓清单，解释依赖和排序理由。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-business-priorities",
  "request": "假设3人团队下月只能投入120小时，待办有官网改版、20位客户回访和新套餐设计。请按附表排顺序，必须保留每周交付。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：应收压力下重排

```text
假设下月固定支出8万元，已有6项增长计划。请基于我给的回款时间表重排4周重点，缺依据不要虚打分。
```

预期交付：区分现金紧迫事项与长期增长事项，给出重排条件。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

{
