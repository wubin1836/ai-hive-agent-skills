# 剪辑节奏顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：压缩粗剪

```text
两分钟演示有点拖，目标约90秒，先指出可删区间，操作步骤不能漏。
```

预期交付：按功能给出的删减区间与需要保留的停留。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-editing-rhythm",
  "request": "两分钟演示有点拖，目标约90秒，先指出可删区间，操作步骤不能漏。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
