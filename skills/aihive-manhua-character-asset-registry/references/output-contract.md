# 输出契约

本项：漫剧角色资产库助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `asset-registry.csv` | asset_id,type,character_id,version,status,path,rights,stable_traits |
| `shot-bindings.csv` | shot_id,character_asset,costume_asset,prop_asset,approved_version |
| `manifest-input.json` | files相对路径列表，用于文件存在性和哈希校验 |

## 最小走读示例（纯虚构）

虚构角色C01夏装V2获批，冬装镜头仍应绑定冬装资产，不因版本号新就全量替换。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 一ID一版本有唯一文件
- [ ] 参考图不等于授权凭据
- [ ] 不保证跨模型绝对一致
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
