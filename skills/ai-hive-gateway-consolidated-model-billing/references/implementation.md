# 多模型统一账单：专项实施卡

## 业务目标

把多个模型和媒体任务统一到可追溯账单与成本口径。

## 目标用户

需要控制模型预算、分配团队配额、核算项目成本或统一采购大模型能力的企业管理者、财务、采购和平台团队。

## 必须收集的证据

- 当前配置、端点、模型、调用量与失败样本。
- AI-HIVE 执行当天的模型列表、能力参数与价格快照。
- 3—10 个同输入、同时间、同验收口径的非生产样本。
- 每条样本的输入哈希、模型、参数、路由、taskId、状态、输出和实际成本。
- 回退开关、负责人、观察窗口和停止条件。

## 专项交付

成本口径表、预算与配额规则、部门/项目归因字段、告警方案和月度复盘模板。

## 通过门槛

重点度量：账单覆盖率、重复费用数、核对工时。团队应在执行前填写具体阈值；没有阈值就只做探索，不得切入生产。

## 停止条件

价格与能力必须以执行当天为准；不得承诺未经验证的绝对最低价、固定折扣或无限额度。 出现重复计费、孤儿任务、不可解释质量下降、未授权数据进入模型、预算越线或无法回退时，立即停止并保留现状。
