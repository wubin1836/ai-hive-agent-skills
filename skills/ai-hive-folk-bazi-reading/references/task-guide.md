# 专项执行参考

仅供传统文化与娱乐参考，尊重科学；相关解读不是科学预测，不作为投资、医疗、法律或婚姻等重大决策依据。

## 资料与交付约定

先确认任务地区/版本/时间范围及输出目录。证据表至少有 source_id、原文件页码或行号、原文、处理值、状态；状态使用 confirmed / uncertain / missing。来源身份与用户隐私不要在公开示例中泄露。

## 本项处理检查

- 本技能只整理用户已核验原盘，不提供未经测试的排盘计算。要新增历法计算，须先选可核验实现并用节气、时区、闰月等边界样例验算。
- 表格至少含 source_file、page、bbox、field、raw_value、confirmed_value、status；疑字不补全，冲突不擅自选定。
- 仅解释传统体系中的术语及出处，不把原盘称为经科学验证的人生结论，不据此诊断人格、疾病、寿命、婚配或财富。
- 现实目标栏只能来自本人自述；行动栏是普通可选行动，不得用生辰来决定。不得用灾祸话术推销消灾、改命等服务。

## 示例请求（虚构输入，仅说明调用方式）

这是我已核验且去掉姓名的八字排盘截图，请准确转录四柱字段，疑字标出来，把传统术语、原盘来源和我自述的现实目标分栏生成参考报告，不要预测疾病和财运。

## 交付验收

- 按实际产物检查文件结构，不能将 Markdown 改后缀冒充 DOCX/XLSX/PDF。
- 公式、金额、日期和图式编码使用脚本或可审查公式复算；模型生成的数字未经复算不能标为已核验。
- DOCX/PDF应渲染检查页码、字体与批注；XLSX回读表头、数据类型和公式；SVG/HTML实际预览。工具缺失则说明哪项视觉/内容验收未完成。
- 缺少输入时交缺件列表，不创建虚构的全套结果来通过核验；仅完成部分时清楚列出已交与未交。

## 专业与使用边界

仅供文化/娱乐参考，尊重科学；不作投资、医疗、法律或婚姻重大决策，不制造灾祸焦虑。仅文化娱乐；不贴性格命运标签，不算疾病、寿命、财运或婚配；古籍名录只证明文献存在。
