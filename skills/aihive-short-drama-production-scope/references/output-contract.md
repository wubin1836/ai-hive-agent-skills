# 输出契约

本项：短剧承制方案助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `scope-of-work.md` | 范围、数量、规格、资料责任、排除项、里程碑 |
| `acceptance.csv` | milestone,deliverable,measure,reviewer,deadline |
| `change-request.csv` | request_id,change,impact_on_cost,impact_on_time,approver,status |

## 最小走读示例（纯虚构）

虚构5集项目要求临时换主角：列受影响角色图和镜头，重新确认费用档期，不算小改。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 数量时长和规格能核对
- [ ] 预算为假设/估算时标明
- [ ] 不能自动接受无限修改
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
