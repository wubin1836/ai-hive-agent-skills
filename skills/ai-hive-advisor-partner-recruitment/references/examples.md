# 招商视频顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：渠道而非加盟

```text
我们招区域经销商，不收加盟费，但有首批采购要求，做90秒介绍的内容框架。
```

预期交付：清楚区分经销关系和采购条件，列出支持与退出待确认项，不改写成低投入稳赚项目。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-partner-recruitment",
  "request": "我们招区域经销商，不收加盟费，但有首批采购要求，做90秒介绍的内容框架。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：个案收益要降温

```text
招商稿里用了一个门店三个月回本的案例，帮我检查怎么讲才不误导，先不出视频。
```

预期交付：核查案例数据和成本口径，提示代表性限制及专业审阅项，不将个案回本写成所有合作方承诺。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：
