# 客户改稿边界顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：海报变成整套物料

```text
假设原确认1张海报、2轮调整，第二轮客户新增易拉宝和朋友圈图。请按附上的确认记录分类，并写一段补范围沟通。
```

预期交付：区分海报约定内修改与新增规格，列出需重新确认的工时和交期。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-revision-boundaries",
  "request": "假设原确认1张海报、2轮调整，第二轮客户新增易拉宝和朋友圈图。请按附上的确认记录分类，并写一段补范围沟通。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：修改里夹着自己的错误

```text
假设客户提出8条改稿意见，其中2条是我漏写了已确认文字。请逐项判断，不能把我自己的错算额外收费。
```

预期交付：分开无偿修正、约定调整和真正范围变化，保留含糊项待确认。
