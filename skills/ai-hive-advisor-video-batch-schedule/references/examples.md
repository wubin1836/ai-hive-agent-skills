# 视频批量生产排程顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：两人做二十条

```text
两个人5天做20条30秒产品视频，只有一人会剪辑，总生成预算500元，先排程。
```

预期交付：把剪辑和审核作为容量约束，分样例校准与后续批次，列不可行项及降规格选择，不直接开20个任务。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-video-batch-schedule",
  "request": "两个人5天做20条30秒产品视频，只有一人会剪辑，总生成预算500元，先排程。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：参考未通过

```text
要做12条人物视频，但人物参考还没确认，客户后天要第一批，帮我排风险。
```

预期交付：将人物参考批准设前置条件，优先安排不依赖该参考的工作，明确首批数量假设与停止线，不先批量生成。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-video-batch-schedule",

  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 需要生成素材时

按 [MCP 绑定说明](mcp-binding.md) 查询实际工具、模型与参数，用户批准数量和预算后，再按单次调用代码提交并复用任务 ID 查询结果。纯诊断不执行生成步骤。
