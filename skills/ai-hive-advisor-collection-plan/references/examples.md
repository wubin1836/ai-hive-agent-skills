# 回款推进顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：验收未齐催款无效

```text
三个客户分别卡在验收、发票和质量争议。请根据我提供的记录安排一周推进顺序，写三份沟通草稿，只供我审核，不发送。
```

预期交付：按卡点区分的行动表和沟通稿

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-collection-plan",
  "request": "三个客户分别卡在验收、发票和质量争议。请根据我提供的记录安排一周推进顺序，写三份沟通草稿，只供我审核，不发送。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：反复承诺付款

```text
某客户两次承诺付款未兑现，我给你脱敏日期记录。请准备一次客气但具体的跟进沟通，列需要确认的支付流程，不编造违约金。
```

预期交付：事实时间线、沟通稿及需专业评估的问题
