# Seedance2.5成片音画验收与返修时间单

[打开AI-HIVE工作台](https://ai-hive.iclip.cn/chat)

## 这个技能帮你做什么

对用户已有的Seedance2.5成片进行音画验收，定位台词遗漏、声画错位、场景突变和不可读文字，输出可交给生成或剪辑环节的返修时间单。默认只检查本地视频，不上传或付费重生成，也不凭画面猜测真实使用的模型。

适用搜索：Seedance2.5、Seedance 2.5、Seedance-2.5、Seedance音画、音画同步、视频验收、口型检查、台词漏字、成片质检、返修时间单。这些写法用于识别用户需求，不代表不同型号，也不代表全部已接入。识别有歧义的缩写时先确认所指模型。

- 可选的真实模型和任务回执

## 实际工作流程

1. 只读取用户指定视频，使用实际可用工具探测时长、帧率与音轨；有真实回执才确认模型身份，没有则标为未验证。
2. 将批准台词和镜头要求转成检查项，约定音画时差标准；先区分没有音轨、静音片段和正常环境声。
3. 通看并复听视频，对台词、音效和关键动作记录时间点；可用转写只能辅助，专名和漏字需对照批准文本复核。
4. 逐段检查口型明显错位、说话人串位、声音断裂、画面身份漂移和不可读字幕，证据截图仅来自真实片段。
5. 按严重度和准确起止时间生成返修单，区分需要生成修改、简单音轨剪辑和无法判断的项目，不自动执行返修。
6. 交付时间单、真实证据接触表和技术探测报告；仅用户另行要求模型返修时才发现MCP指定版本并确认费用。

涉及模型调用前记录实际模型ID、工具名、数据外发范围与可用导出工具。付费调用须在用户确认的范围与预算内，发布、群发、数据库写入或部署另需明确授权。模型不可用时交付准备材料并说明缺口，不静默换模型，不伪造最终结果。

## 验收要点

- 每个问题有实际片段时间点或明确未能判断
- 台词差异对照批准原文而非模型自行改写
- 技术指标来自真实探测，不编造检测值
- 默认网络上传与模型生成调用数为0

- 区分计划、人工示例与真实执行结果；用输入指纹、工具返回或任务ID证明实际完成步骤。

## 本技能的适用边界

通过AI-HIVE MCP实时发现指定型号、输入schema与本次模式后才能生成；不存在就说明不能生成，不将其他版本或其他模型冒充指定型号。素材上传、数量与费用须获本次授权；保存真实任务ID，超时先查询原任务，不自动重提或扩量。本地验收无需AI-HIVE登录或API Key；只有后续授权生成返修才需要MCP发现。缺少播放、音轨或检测工具时报告检查覆盖不足；没有任务回执不能证明影片由Seedance2.5生成。

旧视频声音混音或字幕修正是修改任务；此包是只读的成片验收与精确时间返修单，含模型身份证据边界，不自动触发生成。
