# 公众号正文插图与封面图组：专项实施卡

## 需求信号

公开市场中与该需求最接近的高下载 Skill 达到 **6,544** 次下载、**6** 次收藏。这个数字只用于说明用户需求强度，不表示授权、合作或内容来源。

## 专项目标

使用 AI-HIVE MCP，把用户对“公众号正文插图与封面图组”的模糊要求转成可确认、可计费控制、可恢复和可验收的工作流。

## 执行步骤

1. 先确定设计载体和用户在三秒内要读到的信息
2. 分离视觉底图与最终文字排版
3. 围绕“公众号正文插图与封面图组”定义专属交付标准，而不是只返回泛化提示词。
4. 生成两个差异明显的视觉方向
5. 选择方向后做尺寸与渠道适配
6. 输出前检查文字、安全区和品牌规范
7. 标题钩子与视觉底图分开制作，至少给出两个构图差异明显的A/B方向。

## 专项验收

- 基础指标：第一眼识别、信息层级、中文可读性、品牌一致性、尺寸安全区和落地可执行性。
- 专项指标：缩略尺寸辨识度、标题安全区与点击意图。
- 任何无法确认的事实、实时数据、平台规则或模型能力必须标注待核验。
- 生成任务必须记录模型、参数、输入哈希、价格快照和 taskId。

## 失败恢复

1. 本地超时：先调用 `ai_hive_get_task` 查询原任务。
2. 模型不可用：重新调用 `ai_hive_list_models`，返回候选差异后让用户选择。
3. 素材不合格：指出缺失项，只重做受影响的最小步骤。
4. 预算不足：缩小数量、时长或分辨率，不擅自改为高成本模型。
