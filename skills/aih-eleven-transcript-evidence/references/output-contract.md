# 转写原文与编辑版本对照：交付合同

## 最小交付

1. result.csv 专用结果表，逐条对应输入，不漏失败项。
2. review.md 复核说明：目标、材料范围、实际执行与未执行、证据、结果、返工、下一步。
3. 实际生成/修改的文件与可打开路径；没有工具时明确“仅任务方案，尚未生成”。

| 字段 | 填写约定 |
| --- | --- |
| segment_id | 对应实际的 segment_id 记录；未知写unknown，不编造。 |
| start_s | 对应实际的 start_s 记录；未知写unknown，不编造。 |
| end_s | 对应实际的 end_s 记录；未知写unknown，不编造。 |
| raw_text | 对应实际的 raw_text 记录；未知写unknown，不编造。 |
| edited_text | 对应实际的 edited_text 记录；未知写unknown，不编造。 |
| reason | 对应实际的 reason 记录；未知写unknown，不编造。 |
| verified | 对应实际的 verified 记录；未知写unknown，不编造。 |

模板见 assets/result-template.csv。用户自由文本若以等号、加号、减号或@开头，供表格软件导入前按文本处理，避免公式注入；不得因此篡改真正数值含义。

## 专用执行与证据

- 保留不覆盖的原始转写音频引用，标不确定听辨段
- 把术语纠正和语序润色分开，敏感数字回听确认
- 逐段映射原句改句原因，失败保留原文标待审
- 交付双轨文本差异表，润色文本不能当逐字原始证据

## 验收门槛

- 不填补听不清金额
- 未授权录音不得上传
- 去口头禅不能改变否定含义

每条记录pass/fail/unknown及证据。关键项为fail或unknown，整体标review_required。不存在证据时不补造截图、时间码、回执、评价。

## 验收练习

- 正常路径（虚构）：不是不支持不能改成不支持，必须回听并保留语义。 按步骤记录，再逐条验收，不将示例当真实结果。
- 缺能力：目标模型或外部软件不可用，报告缺项及可先做的本地步骤，不冒用名称称实测。
- 失败：超时、限流、待审，保存任务ID、原因和已完成项；不重建任务、不遗漏失败费用。

## 报告顺序

结论与状态 → 材料和授权 → 参数与执行记录 → 专用结果表 → 证据和未通过项 → 成本耗时（未知说明）→ 需确认的下一步。

创作保留素材授权与生成标记；数据记录来源、时间、口径，不从示例推导真实客户或商业结论。
