# 输出契约

本项：乐言内容智造机同类｜跨境Listing本地化助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `listing.md` | 标题、分点、产品说明、适用范围、目标站点规则日期 |
| `keyword-map.csv` | keyword,intent,verified_attribute,placement,exclude_reason |
| `fact-backcheck.csv` | sentence,claim,source,unit_conversion,status |

## 最小走读示例（纯虚构）

虚构0.5升保温杯向英语站上架：明确容量和单位换算，不能为流量加竞品品牌名。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 不能把潜在关键词当商品能力
- [ ] 限制长度按当期站点规则，不写永久通用值
- [ ] 不保证排名
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
