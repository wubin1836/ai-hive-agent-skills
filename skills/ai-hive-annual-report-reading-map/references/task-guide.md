# 专项执行参考

仅供参考，不构成投资建议，不承诺收益，不自动交易。

## 资料与交付约定

先确认任务地区/版本/时间范围及输出目录。证据表至少有 source_id、原文件页码或行号、原文、处理值、状态；状态使用 confirmed / uncertain / missing。来源身份与用户隐私不要在公开示例中泄露。

## 本项处理检查

- 每个导航链接落到原 PDF 的真实页码，区分印刷页码与文件页序
- 审计意见、报表与风险章节分别有原件出处，未找到的章节明确留空
- 合并与母公司口径、报告期不混用，阅读问题不写成已证实结论

## 示例请求（虚构输入，仅说明调用方式）

仅示例，以下文件名和情境均为假设，不表示已存在真实数据：假设我已提供 示例_年度报告.pdf、示例_阅读问题.md。请使用「股票年报导航助手」，围绕审计意见、收入确认和现金流制作可点击阅读导航，不对公司进行投资评级。将结果写入我指定的本地目录，交付 annual-report-map.html、report-page-index.csv、reading-questions.md。本例先离线处理；输入、工具或适用规则不足时先交缺口说明，不编造结果。需要联网更新来源先征得我同意，不登录账户、不代提交或付款。

## 交付验收

- 按实际产物检查文件结构，不能将 Markdown 改后缀冒充 DOCX/XLSX/PDF。
- 公式、金额、日期和图式编码使用脚本或可审查公式复算；模型生成的数字未经复算不能标为已核验。
- DOCX/PDF应渲染检查页码、字体与批注；XLSX回读表头、数据类型和公式；SVG/HTML实际预览。工具缺失则说明哪项视觉/内容验收未完成。
- 缺少输入时交缺件列表，不创建虚构的全套结果来通过核验；仅完成部分时清楚列出已交与未交。

## 专业与使用边界

只提供阅读导航，不给股票评级、目标价或财务造假定性；不能读清的扫描表格不得猜数。
