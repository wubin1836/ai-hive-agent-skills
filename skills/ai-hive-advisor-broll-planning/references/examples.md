# 空镜素材顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：仓库口播配画面

```text
这段60秒口播讲真实发货流程，列六个以内空镜，哪些必须现场拍请标明。
```

预期交付：每个镜头对应旁白信息，事实证明镜头明确要求实拍。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-broll-planning",
  "request": "这段60秒口播讲真实发货流程，列六个以内空镜，哪些必须现场拍请标明。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：已有素材匹配

```text
用我这12段门店素材给口播配画面，缺的先列出来别生成。
```

预期交付：已有素材匹配和未覆盖缺口，不编造素材内容。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-broll-planning",
  "request": "用我这12段门店素材给口播配画面，缺的先列出来别生成。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 需要生成素材时

按 [MCP 绑定说明](mcp-binding.md) 查询实际工具、模型与参数，用户批准数量和预算后，再按单次调用代码提交并复用任务 ID 查询结果。纯诊断不执行生成步骤。
