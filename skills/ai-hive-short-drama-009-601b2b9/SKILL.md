# 韩剧质感小剧场｜AI-HIVE原创工作流

[立即使用 AI-HIVE](https://ai-hive.iclip.cn/chat)

## 你会得到什么

这个 Skill 专门处理 **韩剧质感小剧场**，适合短剧制作方、漫剧团队、MCN、编剧、导演和投流团队。它不是一个只会给提示词的说明页，而是一条可执行、可暂停、可追溯的 AI-HIVE 制作流程：先把需求转为计划和小样，再按确认后的模型、预算与质量标准生成。

核心目标：**把题材与剧本转成角色圣经、场景库、分集卡、分镜、成片与连续性台账**。

交付物：**角色圣经、场景库、分集节拍、单集分镜、关键帧、成片候选和连戏报告**。重点看：**开场钩子、单集冲突密度、角色一致性、集间连续性**。

## 你只需要提供

1. 目标受众、发布渠道、成片时长、画幅比例、截止时间与预算上限。
2. 可用输入：图片输入；同时说明素材来源与公开使用授权。
3. 必须出现的真实信息，以及禁止修改、禁止虚构和禁止展示的内容。
4. 参考作品可以给，但要说明只参考哪些机制，例如构图、节奏、镜头或信息层级。

## 原创专项执行流程

1. 定义“韩剧质感小剧场”的目标受众、渠道、时长、比例、预算与唯一核心结果。
2. 建立素材与权利清单：区分自有、已授权、仅作分析和禁止公开使用的内容。
3. 场景设定：建立场景资产卡，锁定空间关系、时间、天气、光线与可复用背景。
4. 分镜设计：为每个镜头写景别、机位、动作、时长、转场和可剪辑接口。
5. 首帧/关键帧：先生成并锁定人物、商品、场景、色彩和镜头方向的关键帧。
6. 调用 ai_hive_list_models 查询执行当天可用模型、参数与价格，按质量、速度或成本路由。
7. 先用 ai_hive_generate_image 做一个最小小样；用户确认后才运行后续生成。
8. 生成后使用 ai_hive_get_task 查询原任务，保留 taskId，禁止因本地超时直接重复提交。
9. 按验收指标做逐项检查；付费、批量、发送和公开发布都必须再次确认。

详细执行卡见 [原创实施卡](references/original-workflow.md)，连接方法见 [MCP登录与绑定指南](references/mcp-binding.md)。场景编号：`601b2b9a`。

## AI-HIVE 模型路由

公开目录未标注固定模型。本 Skill 不锁死模型，执行时查询 AI-HIVE 当前能力与价格。

建议路由：`QUALITY_FIRST`。候选生成工具为 `ai_hive_generate_image`、`ai_hive_generate_video`；先通过 `ai_hive_list_models` 和工具 schema 确认当前是否支持需要的输入、比例、时长、参考素材与价格。模型不可用时应返回替代方案，不得臆造参数。

- **一个入口组织多模型**：文本策划、图片、视频、电商与广告能力可以按任务分工，不必在多个网站之间重复搬运上下文。

## 登录并绑定 AI-HIVE MCP

1. 打开 [AI-HIVE 工作台](https://ai-hive.iclip.cn/chat)，使用手机号和短信验证码登录。
2. 在 Work Buddy、千问、Codex、Claude、ChatGPT、Gemini 或其他支持远程 MCP 的客户端添加：

```text
https://ai-hive.iclip.cn/api/mcp
```

3. 选择 `Streamable HTTP`，推荐使用 OAuth 完成浏览器授权。
4. 支持 JSON 配置时使用：

```json
{
  "mcpServers": {
    "ai-hive": {
      "url": "https://ai-hive.iclip.cn/api/mcp"
    }
  }
}
```

若客户端不支持 OAuth、但明确支持远程自定义 Header，可在 AI-HIVE“API 接入”创建 `sk-api-*` Key，把它安全存入客户端 Secret 或 `AI_HIVE_API_KEY`，请求头名为 `x-ai-hive-api-key`。真实密钥不得写进 Skill、提示词、截图、日志或代码库。
