# 提示词缓存不命中诊断助手：场景示例

## 场景一：首次执行

```text
两次请求cached_tokens都是0，我只改了客户问题。请比较我提供的脱敏请求，检查前缀和工具列表是否变化，生成不超过三组的测试方案，先不付费执行。
```

输入记录示例：

```json
{
  "mode": "演示数据",
  "request_a": {
    "prefix": "生成于10:01；固定规则"
  },
  "request_b": {
    "prefix": "生成于10:02；固定规则"
  },
  "cached_tokens": [
    0,
    0
  ]
}
```

人工构造的输出片段，仅用于解释格式；不是付费模型生成结果或测试成绩：

```json
{
  "illustrative_only": true,
  "sample": {
    "mode": "人工演示，未调用真实服务",
    "candidate_cause": "稳定规则之前存在变化时间戳",
    "certainty": "待单变量测试",
    "experiment": "移除前缀动态时间，仅改变客户问题"
  }
}
```

## 场景二：复核与返工

```text
请检查本次输出是否满足：原因均对应具体请求差异或官方限制。；缓存使用量缺失不等于命中为零。；模型、版本、保留期和输入规模均固定或明示变化。；不同租户敏感内容不为提高命中率而拼接。。
把结论分成已验证、未验证、需补资料三类。只修复有证据的问题，不覆盖原文件；先列返工清单和额外调用费用。
```

复核记录建议字段：`check / evidence / actual / status / next_action`。

## 场景三：当前模型或工具不可用

```text
如果当前AI-HIVE没有本任务需要的精确模型或工具，请不要生成冒名结果。给我已发现的能力、缺失条件、可先完成的本地准备材料，以及需要我选择的替代方案。
```

本地演练：在MCP未配置时仍可执行 `scripts/workflow.py`，但其结果必须保持 `phase=offline_plan`、`model_calls=0`。这只能验证工作单，不是验证模型能力。
