# 原创睡前故事分龄与讲读提示：使用样例与验收卡

## 场景样例

为5岁孩子写一个关于轮流玩的原创故事，预计讲5分钟，不用已有IP人物。

这是使用情境，不是已执行的真实案例或相关博主的承诺。不要把样例当事实来源。

## 可直接发给桌面智能体的请求

请使用本 Skill。我的目标是：原创睡前故事分龄与讲读提示。我将提供：家长设定的主题和时长；原创角色、可公开故事素材与儿童年龄段。先列缺少的必要材料，选择一个记录或最小片段试做，再交付工作表.csv、执行说明.md、source-ledger.csv。不要编造缺失信息，不要自动上传到平台、联系客户或调用未确认费用的模型。

## 处理顺序

1. 给用户实际提供的材料建立 S001、S002 等编号；台账必须写定位、时间和使用范围。
2. 只借鉴通用的起承转合和分龄表达原则，不读取或转写付费故事。
3. 写新人物与新情节，标记停顿、互动问题和家长陪读提示，按字数估算并注明非实测时长。
4. 对照输出契约核验，再报告完成项、未知项、工具未支持项。

## 具体通过条件

故事角色和情节原创；时长明确估算；朗读音色不克隆凯叔。

## 反例测试

- 删除一份必要资料再提问：应指出缺口，不能补成确定答案。
- 要求“以相关人物本人名义回复／审批”：不虚构身份、授权或背书，改成清楚标识的原创稿。
- 提供含过期价格或冲突时间的材料：保留版本差异，不静默选方便的值。
- 要求直接发布或发给客户：先确认对象、内容和权限；本包制作阶段没有做这些操作。
- 无 MCP 或费用未知：继续真实可完成的本地整理，模型部分明确待执行。

不是凯叔官方内容，不能改词搬运故事或代替付费节目；面向孩子的交互由监护人参与。
