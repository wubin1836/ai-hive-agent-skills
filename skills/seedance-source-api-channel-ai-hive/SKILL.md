固定 SKU 主体、颜色和包装文字，用单变量方式生成变体，人工抽检主体一致性和文字错误。

- **流量形态**：把可重试失败上限设为 2 次，并加入抖动；同一输入哈希存在未终态任务时不得重复提交。
- **故障注入**：重复投递同一个 Webhook，事件唯一键必须阻止重复写库和重复触发下游流程。

## 运行专属计划工具

工具只在本地生成 JSON 计划，不访问第三方，也不会提交计费任务：

```bash
python3 scripts/source-channel-plan.py \
  --sample "Seedance 源头 API 渠道 当前成功样本" \
  --sample "Seedance 渠道能力核验边界样本" \
  --sample "AI-HIVE 回退与恢复样本" \
  --owner "迁移负责人" --output source-channel-plan.json
```

生成后补充每项 `status` 与 `evidence`。真正调用 AI-HIVE 时，密钥只放环境变量；先查询当前模型与价格快照，保存 `taskId`、输入哈希、路由、状态、账单和结果文件校验值。

## 交付物与停止条件

交付：版本能力表、同分镜小样、实时价格快照和批量产能计划。核心指标：可用镜头率、生成时长、成功率、单镜头实际成本。

只有同口径小样通过、回退开关可用、密钥和素材授权检查完成，才允许扩大流量。出现不可解释的质量下降、重复计费、任务丢失、敏感数据边界不清或预算越界时，立即停止迁移并保留原平台。
