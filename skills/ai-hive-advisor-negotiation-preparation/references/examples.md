# 商务谈判准备顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：客户要求降价

```text
假设项目报价3万元，客户希望降到2.4万元。我可减少交付范围，但不能延长付款超过30天。请准备交换条件和5个追问。
```

预期交付：把价格与范围、付款拆开讨论，给出有条件让步及暂停信号。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-negotiation-preparation",
  "request": "假设项目报价3万元，客户希望降到2.4万元。我可减少交付范围，但不能延长付款超过30天。请准备交换条件和5个追问。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：供应商交期谈判

```text
假设我要采购100套展示架，现报价每套180元，最迟20天到货，另有一家可选供应商。请帮我演练交期和验收谈判。
```

预期交付：明确证据、替代选择和验收议题，不虚构别家的更低报价。
