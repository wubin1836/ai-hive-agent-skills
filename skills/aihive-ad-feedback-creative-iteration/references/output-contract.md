# 输出契约

本项：广告素材回流迭代助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `campaign-input.json` | 统一口径records含asset_id和曝光点击转化消耗收入币种 |
| `creative-features.csv` | asset_id,hook,claim,pacing,visual,caption,version |
| `iteration-brief.csv` | next_id,parent_id,evidence,hypothesis,changed_variable,held_constant,reviewer |

## 最小走读示例（纯虚构）

虚构高CTR低CVR素材可能承诺过度：先检查商品事实和页面，而非继续夸张开头。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 丢失素材ID时不得强行归因
- [ ] 不跨人群窗口直接下因果结论
- [ ] 不得伪造投放效果
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
