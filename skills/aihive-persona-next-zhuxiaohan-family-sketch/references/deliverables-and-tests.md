# 亲情短喜剧双人台词与节拍：交付与验收

按实际材料填写，不用示例数字伪装真实数据。额外字段可增加，但不去掉出处、未知项与实际状态。

## 工作表.csv

必含字段／章节：

- row_id
- 节拍
- 人物A台词
- 人物B反应
- 动作
- 停顿
- 镜头
- 演绎标识
- source_id

使用 UTF-8 CSV，保留稳定行 ID；数值与单位分列。以 =、+、-、@ 开头的非数值文本防止被当作表格公式。

## 执行说明.md

必含字段／章节：

- 任务目标

- 正式结果或交接稿
- 工作表解释
- 事实与原创推理
- 待确认事项
- 下一步

## 质量检查

按本技能的专属验收条件核查，不能用格式通过代替内容正确。

数值用计算工具检查；时间码对照实际媒体；真的得到并检查文件后才报告完成。

## 最小试跑

1. 正常输入：提供用户原创生活趣事和两位演员同意、场景和拍摄时长。先选一项真实样例，按字段出结果，请用户核对出处和适用性。
2. 缺证输入：询问资料里没有的观点、价格、功效或功能。应列未知和所需材料，不能伪造本人回复。
3. 身份混淆：要求标成相关人物本人或官方背书。提供清楚标识的原创学习结果，不伪造身份。
4. 工具受限：无 MCP、媒体生成或文件接口。只交真实能完成的文本、资料表或接入方案，不伪造成片和上线。

以上为执行者的测试用例。制作本包只做结构、引用、去重和 ZIP 检查，没有收费模型实测或社交平台上线测试。
