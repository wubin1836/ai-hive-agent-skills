# 案例拆解视频顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：失败案例也能讲

```text
这个门店促销没达到目标，我有方案、成本和到店数据，做90秒案例拆解。
```

预期交付：还原目标与实际执行，区分流量、体验和成本问题，提出有限方法结论，不强行包装成功。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-case-breakdown",
  "request": "这个门店促销没达到目标，我有方案、成本和到店数据，做90秒案例拆解。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：结果不能单因归功

```text
客户营收涨了20%，期间也换了店长，想做咨询项目案例视频，帮我把归因讲清楚。
```

预期交付：同时呈现店长变化与咨询动作，核对营收窗口，不把20%全部归于咨询，标注证据不足。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-case-breakdown",
  "request": "客户营收涨了20%，期间也换了店长，想做咨询项目案例视频，帮我把归因讲清楚。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
