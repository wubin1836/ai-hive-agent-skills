# 招投标项目匹配筛选助手：交付契约

## 任务示例

这12个项目帮我筛出值得进一步看的，我们只有材料里的资质，本月最多投入20个人日；不确定的资格单独列。

## 人工测试场景（不是实际客户案例）

人工测试：A硬门槛通过、B明确缺必需资质、C未提供证书。A进入可排序池，B不推荐，C待补证；不能把C直接排在A前面。

## 反例与停止点

资质证书到期而项目要求覆盖交付期：保持待专业核实，不把续期意向视作有效证明。

## 交付字段

### eligibility-matrix.csv

project_key,requirement,notice_ref,evidence_ref,result,reason。

### shortlist.csv

project_key,gate_status,rank,score_basis,coverage,deadline,resource_conflict。

### clarifications.md

缺证、未知项、需要用户确认的权重与参与建议。

字段名是文件契约，不是AI-HIVE工具参数。具体调用仍读实时schema。缺失项保留空值和原因，不把未知填0；CSV供表格打开时防止以 =、+、-、@ 开头的非数值来源文字变成公式。

## 执行证据

交付时附本次输入范围、实际处理工具、输出位置及已检查／未检查项。说明资料来自用户、官方网页还是模型分析。不得把人工示例、待填模板、模型推断写成已发生事实。

如果需要Word／Excel／PPT／音视频成品，检查宿主是否真有对应制作和检查工具；没有就交付当前可完成的中间文件，并列明尚缺的工具。对外发布、发送或系统写入另需对应授权。
