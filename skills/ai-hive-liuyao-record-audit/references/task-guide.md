# 专项执行参考

仅供传统文化、学习与娱乐参考，尊重科学；不宣称能够科学预测命运，不作为投资、医疗、法律、婚姻等重大决策依据。

## 资料与交付约定

先确认任务地区/版本/时间范围及输出目录。证据表至少有 source_id、原文件页码或行号、原文、处理值、状态；状态使用 confirmed / uncertain / missing。来源身份与用户隐私不要在公开示例中泄露。

## 本项处理检查

- 先明确六次记录的时间顺序及初爻在下的显示口径；未确认顺序不排图。
- 仅使用用户确认的币值映射与动静规则复算六个爻；缺一次记录就标缺失，不随机补卦。
- 本卦、动爻和变卦逐行对照，爻位及来源记录一一对应。

## 示例请求（虚构输入，仅说明调用方式）

请使用我授权提供的资料完成“六爻助手｜摇卦记录与本卦变卦核对”。范围先按我的原件与指定版本确认，生成liuyao-records.csv及其余约定文件，疑点附来源，不自动对外提交。

## 交付验收

- 按实际产物检查文件结构，不能将 Markdown 改后缀冒充 DOCX/XLSX/PDF。
- 公式、金额、日期和图式编码使用脚本或可审查公式复算；模型生成的数字未经复算不能标为已核验。
- DOCX/PDF应渲染检查页码、字体与批注；XLSX回读表头、数据类型和公式；SVG/HTML实际预览。工具缺失则说明哪项视觉/内容验收未完成。
- 缺少输入时交缺件列表，不创建虚构的全套结果来通过核验；仅完成部分时清楚列出已交与未交。

## 专业与使用边界

仅为传统文化学习、娱乐参考，尊重科学。本包未内置经验证的自动起卦算法；禁止凭空排盘、补投掷结果、给吉凶保证或据此作重大决定。
