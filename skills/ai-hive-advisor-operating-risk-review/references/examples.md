# 经营风险排查顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：关键人员依赖

```text
公司只有一人掌握客户系统配置，另有两家核心供应商，帮我做经营风险清单，不编概率。
```

预期交付：记录依赖证据、潜在影响和已有备份措施，列责任与补证要求，不把潜在离职说成已发生危机。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-operating-risk-review",
  "request": "公司只有一人掌握客户系统配置，另有两家核心供应商，帮我做经营风险清单，不编概率。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：数据不完整

```text
我有交付延期记录和未来三个月付款计划，想排查最该先看的问题，账目还不完整。
```

预期交付：在给定范围内梳理履约和付款安排，标记缺失账目及专业核验项，不认定资不抵债或保证资金安全。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-operating-risk-review",
  "request": "我有交付延期记录和未来三个月付款计划，想排查最该先看的问题，账目还不完整。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
