# 视频号挂车口播脚本助手：交付契约

## 任务示例

给这款收纳盒写45秒视频号挂车口播，只有我提供的尺寸和材质可信，没做过承重测试，不要写亲测。

## 人工测试场景（不是实际客户案例）

人工测试：材料只证明容量和材质，不含承重；脚本可以展示收纳数量，不能生成“承重100斤”和“我用了三个月”。

## 反例与停止点

过期价格和无法核实的销量：不进入正文；改成以店铺当前展示为准也不能掩盖虚假促销。

## 交付字段

### claim-evidence.csv

claim_id,claim,evidence_ref,valid_until,status,allowed_wording。

### shooting-script.csv

segment_id,start_s,end_s,spoken_text,visual,claim_ids,source_ref。

### teleprompter.md

可照读正文、停顿与需核实句子；成片另计状态。

字段名是文件契约，不是AI-HIVE工具参数。具体调用仍读实时schema。缺失项保留空值和原因，不把未知填0；CSV供表格打开时防止以 =、+、-、@ 开头的非数值来源文字变成公式。

## 执行证据

交付时附本次输入范围、实际处理工具、输出位置及已检查／未检查项。说明资料来自用户、官方网页还是模型分析。不得把人工示例、待填模板、模型推断写成已发生事实。

如果需要Word／Excel／PPT／音视频成品，检查宿主是否真有对应制作和检查工具；没有就交付当前可完成的中间文件，并列明尚缺的工具。对外发布、发送或系统写入另需对应授权。
