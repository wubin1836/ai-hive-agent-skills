# 服务产品化顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：设计工作室交付标准化

```text
假设6人设计公司有12份旧项目记录。请把门店视觉服务拆成标准和定制模块，每个项目最多占用40小时。
```

预期交付：输出客户准入、交付模块、工时边界和可验证验收标准。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-service-productization",
  "request": "假设6人设计公司有12份旧项目记录。请把门店视觉服务拆成标准和定制模块，每个项目最多占用40小时。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：咨询服务减少返工

```text
假设3人咨询团队每次访谈报告都会返工2轮，附5个项目的变更原因。请设计可复用服务规格，先试运行2单。
```

预期交付：把前置资料、确认节点与变更范围写入规格和试运行记录。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：
