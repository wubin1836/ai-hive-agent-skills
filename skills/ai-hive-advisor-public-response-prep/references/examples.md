# 舆情应对准备顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：收到质量质疑

```text
有人公开说我们发错货，这是截图和内部发货记录，先准备回应，不联系对方。
```

预期交付：对照记录区分已知与待核验，给不泄露订单隐私的回应草稿和责任清单，不直接认定对方造谣。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-public-response-prep",
  "request": "有人公开说我们发错货，这是截图和内部发货记录，先准备回应，不联系对方。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：准备监测但不启动

```text
下周产品发布怕出现误解，先做舆情监测范围和回应预案，暂时不要创建监控或发消息。
```

预期交付：定义与功能、价格和交付有关的关注信号及升级条件，提供分情形草稿，不创建自动化或抓取个人数据。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

}
