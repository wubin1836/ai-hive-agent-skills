# 折扣审批顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：大单九折申请

```text
虚构案例：原报价10万元、直接交付成本6万元，客户要九折且延后60天付款。请比较条件并列三个待确认问题，不替我批准。
```

预期交付：毛利和账期代价说明、条件交换选项

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-discount-review",
  "request": "虚构案例：原报价10万元、直接交付成本6万元，客户要九折且延后60天付款。请比较条件并列三个待确认问题，不替我批准。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：不降价怎么回应

```text
客户要免费增加两个月服务，我提供服务清单和每月工时。请准备范围缩减、预付与分期交付三个方案，不宣称任何方案一定成交。
```

预期交付：三种可讨论方案及各自代价

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-discount-review",

}
```

## 需要生成素材时

按 [MCP 绑定说明](mcp-binding.md) 查询实际工具、模型与参数，用户批准数量和预算后，再按单次调用代码提交并复用任务 ID 查询结果。纯诊断不执行生成步骤。
