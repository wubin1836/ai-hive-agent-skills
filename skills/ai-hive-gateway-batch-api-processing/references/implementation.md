# Batch API批量模型任务：专项实施卡

## 业务目标

把大量离线任务分批、限速、续跑并对齐结果与输入。

## 目标用户

希望采购、集成、转售、白标或标准化调用多模态模型能力的 AI 创业公司、ISV、渠道伙伴和企业平台团队。

## 必须收集的证据

- 当前配置、端点、模型、调用量与失败样本。
- AI-HIVE 执行当天的模型列表、能力参数与价格快照。
- 3—10 个同输入、同时间、同验收口径的非生产样本。
- 每条样本的输入哈希、模型、参数、路由、taskId、状态、输出和实际成本。
- 回退开关、负责人、观察窗口和停止条件。

## 专项交付

能力边界、合作或协议需求表、最小验证方案、计费与权限模型、交付责任和验收清单。

## 通过门槛

重点度量：批次完成率、漏单率、单位任务成本。团队应在执行前填写具体阈值；没有阈值就只做探索，不得切入生产。

## 停止条件

不得转售无授权能力或泄露上游凭据；合作、价格、SLA、发票和商标使用以双方书面协议为准。 出现重复计费、孤儿任务、不可解释质量下降、未授权数据进入模型、预算越线或无法回退时，立即停止并保留现状。
