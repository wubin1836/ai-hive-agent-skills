# 销售管道复盘顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：月底预测清理

```text
我有40条商机，其中12条连续两次推迟签约。请按现有证据分档复盘，给一页老板周会清单，不编造成交概率。
```

预期交付：延期商机卡点、可信预测范围和本周动作

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-sales-pipeline",
  "request": "我有40条商机，其中12条连续两次推迟签约。请按现有证据分档复盘，给一页老板周会清单，不编造成交概率。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：阶段定义不一致

```text
两个销售组对方案阶段的定义不同，我提供各自规则及匿名样本。请统一可核验的阶段条件并列需重新确认的商机，不修改系统。
```

预期交付：统一阶段规则和需要人工复核的清单

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{

  "paid_generation": "未授权，先给方案与预算"
}
```
