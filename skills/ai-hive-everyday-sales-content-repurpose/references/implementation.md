# 销售案例AI多格式改编：专项实施卡

## 用户与结果

- 目标用户：个人销售、销售团队、客服、售后、私域运营、招商主管和客户成功团队。
- 希望结果：将已获客户授权的案例改编为图文、PPT和短视频。
- 交付物：客户分层、沟通SOP、话术与素材、跟进节奏、人工转接规则和效果复盘表。
- 核心指标：授权覆盖率、素材复用率、线索转化率。

## 最小样例

1. 只选一个真实用户或一个真实商品/服务。
2. 使用3—5条已授权资料，不上传不必要的隐私数据。
3. 先查询当前模型与价格，再生成1份内部草稿。
4. 由人工检查事实、品牌、版权、隐私和渠道规则。
5. 记录结果与成本；只有通过才进入下一轮。

## 停止条件

不得群发骚扰、伪造身份或未经同意处理敏感信息；对外发送和自动回复必须由用户明确授权。 如果实时价格未确认、素材未授权、小样不达标、任务重复计费或需要对外发送，立即停止并请用户确认。
