# 商业承诺审查顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：交付时间说满

```text
销售PPT写所有项目7天上线，实际需要客户按时交资料，帮我审查并改表达。
```

预期交付：识别无条件时限承诺，核对流程与例外，建议明确前提和适用范围，不擅加赔偿条款。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-commercial-promises",
  "request": "销售PPT写所有项目7天上线，实际需要客户按时交资料，帮我审查并改表达。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：效果保证缺依据

```text
报价单写保证效率提升30%，我们只有一个客户数据，先检查风险别给法律结论。
```

预期交付：对应证据范围与个案限制，提出收窄或删除保证的建议，明确需业务及专业确认，不编造更多案例。
