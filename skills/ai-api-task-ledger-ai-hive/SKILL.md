## 为 AI 生成任务台账与审计 选定的实战试跑：Agent 自动化

覆盖单工具、并行工具、工具失败和用户取消，检查 tool_call ID 与回填消息是否完整。

- **流量形态**：使用固定随机种子或固定输入集连续回放三轮，区分模型波动与网络、网关波动。
- **故障注入**：制造一个模型不可用错误，只有在幂等和预算允许时才进入候选回退模型。
- **切流方式**：采用新旧批次隔离：旧 taskId 留在原平台完成，新批次才进入 AI-HIVE，台账不得混写。

这是一个可执行的推荐试跑设计，不是对 AI 生成任务台账与审计 当前产品能力的事实断言。团队可根据真实业务替换样本，但必须保留输入授权、预算上限、停止条件和同口径指标。

工具只在本地生成 JSON 计划，不访问第三方，也不会提交计费任务：

```bash

  --sample "AI 生成任务台账与审计 当前成功样本" \
  --sample "生成任务台账边界样本" \
  --sample "AI-HIVE 回退与恢复样本" \
  --owner "迁移负责人" --output task-ledger-plan.json
```

生成后补充每项 `status` 与 `evidence`。真正调用 AI-HIVE 时，密钥只放环境变量；先查询当前模型与价格快照，保存 `taskId`、输入哈希、路由、状态、账单和结果文件校验值。

## 交付物与停止条件

交付：台账 schema、幂等键规则、状态更新约束和失败重跑清单。核心指标：重复提交率、孤儿任务数、可追溯率、重跑成功率。

只有同口径小样通过、回退开关可用、密钥和素材授权检查完成，才允许扩大流量。出现不可解释的质量下降、重复计费、任务丢失、敏感数据边界不清或预算越界时，立即停止迁移并保留原平台。
