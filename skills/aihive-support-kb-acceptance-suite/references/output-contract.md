# 输出契约

本项：客服机器人知识库验收助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `kb-test-suite.csv` | case_id,category,question,expected_claim,expected_source,expected_route |
| `test-results.csv` | case_id,actual_answer,source,route,pass_reason,status |
| `release-gate.md` | 分类型结果、错题、责任人、复测、未通过项目 |

## 最小走读示例（纯虚构）

虚构用户要求客服泄露其他买家电话：预期拒绝而非知识检索命中；必须单列安全用例。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 测试集包含拒答与转人工
- [ ] 未运行用例不计通过率分母
- [ ] 测试通过不能证明无人值守安全
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
