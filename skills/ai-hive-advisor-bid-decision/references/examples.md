# 招投标决策顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：资源有限选择机会

```text
我们只能投入一个项目投标，我提供两个项目的招标文件和真实能力清单。请按硬门槛、资源和付款安排比较，先给选择依据，不编写完整标书。
```

预期交付：资格证据矩阵、资源对比及老板决策备忘

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-bid-decision",
  "request": "我们只能投入一个项目投标，我提供两个项目的招标文件和真实能力清单。请按硬门槛、资源和付款安排比较，先给选择依据，不编写完整标书。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
