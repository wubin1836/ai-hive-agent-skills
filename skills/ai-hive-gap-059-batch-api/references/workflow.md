# Batch API批量任务工作流专项实施卡

## 任务定义

设计低成本批量图片视频或文本任务的提交与恢复。

## 输入

真实任务样例、延迟与质量目标、预算、并发规模、数据边界和现有接口信息。

## 交付合同

批次规划、幂等键、预算、状态查询、失败清单和重跑规则。

## 专项决策

1. 先判断任务属于事实整理、方案设计、生成执行还是外部操作。
2. 事实整理只使用可追溯资料；方案设计标明假设；生成执行先小样；外部操作另行确认。
3. 调用 `ai_hive_list_models`，按 `COST_FIRST` 比较实时可用模型。
4. 任何超时先查询原 `taskId`，任何模型切换都保留原因和价格快照。

## 验收

无重复计费、失败可定位、批次可暂停。

## 明确停止

批量付费调用必须再次确认。出现权限不足、来源缺失、预算未确认、工具不存在或任务状态未知时停止并返回下一步。
