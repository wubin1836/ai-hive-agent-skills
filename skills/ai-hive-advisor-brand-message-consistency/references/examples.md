# 品牌表达一致性顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：三处简介对照

```text
假设官网写企业培训，短视频简介写个人成长，销售册写全行业咨询。请按我确认的中小企业培训定位检查3份文案并建议修改。
```

预期交付：指出目标客户和服务范围冲突，给出适合各渠道长度的统一变体。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
```

## 场景 2：交付承诺不一致

