# 参考图准备顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：杯柄被裁掉

```text
这三张杯子图准备用于图生视频，其中两张杯柄不完整，帮我选并列补拍要求。
```

预期交付：实际看图后比较主体完整性和动作空间，推荐可靠图或补拍，不脑补缺失杯柄并保证生成正确。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-reference-image-prep",
  "request": "这三张杯子图准备用于图生视频，其中两张杯柄不完整，帮我选并列补拍要求。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：只有商品链接

```text
我只有商品页链接，现在不能上传图，先告诉我拍一只背包的参考图要注意什么。
```

预期交付：给主体、角度、光线和细节准备清单，明确尚未看过产品，不声称已检查网页或图片。
