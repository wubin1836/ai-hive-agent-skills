# 输出契约

本项：短剧报价与成本核算助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `budget.csv` | cost_item,type,quantity,unit_price,currency,source,estimate_range |
| `cost-input.json` | records含output_id,cost,currency,accepted；包括失败重试 |
| `budget-variance.md` | 计划与实际、复用口径、返工原因、超支触发点 |

## 最小走读示例（纯虚构）

虚构10镜头首试100元、返工30元、人工20元，8个合格镜头：单位合格镜头成本18.75元。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 税费币种和人工时间口径明确
- [ ] 费用未知不能出看似精确总价
- [ ] 输出不是任何公司官方报价
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
