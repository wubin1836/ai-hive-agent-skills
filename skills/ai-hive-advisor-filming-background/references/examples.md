# 拍摄背景布置顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：办公室角落

```text
这是我办公室两张照片，预算不超过200元，做一个不露客户白板的口播角落。
```

预期交付：利用现有物品的布置与隐私遮挡清单，采购价格不虚构。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-filming-background",
  "request": "这是我办公室两张照片，预算不超过200元，做一个不露客户白板的口播角落。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
