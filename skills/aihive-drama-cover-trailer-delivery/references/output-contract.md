# 输出契约

本项：短剧封面与预告素材助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `promo-plan.csv` | asset_id,channel,spec,story_promise,spoiler_limit,source_version |
| `trailer-edl.csv` | segment,in_time,out_time,visual,audio,caption,source |
| `release-check.md` | 权利、文字、事实、规格、文件、审批状态 |

## 最小走读示例（纯虚构）

虚构悬疑剧封面只展示失踪线索，预告不能拼接成已揭露凶手的误导关系。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 不能凭空添加明星主演
- [ ] 不盗用已有海报构图与角色组合
- [ ] 无实际文件不称成片
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
