# 口播收音顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：衣物摩擦

```text
领夹麦这段录音有杂声，帮我判断是否衣服摩擦，安排两个摆位测试。
```

预期交付：有依据的现象判断与两次对照试录。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-speech-recording",
  "request": "领夹麦这段录音有杂声，帮我判断是否衣服摩擦，安排两个摆位测试。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：小房间回声

```text
在空办公室录60秒口播回声很大，只能挪位置和用现有软装。
```

预期交付：现有条件下的摆位试验，不承诺后期全部修好。
