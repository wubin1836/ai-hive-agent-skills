# 输出契约

本项：短剧买量复盘助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `campaign-input.json` | records包含asset_id,impressions,clicks,conversions,spend,revenue,currency |
| `review.md` | 口径、聚合结果、异常、样本限制、候选原因 |
| `next-experiment.csv` | hypothesis,variable,controls,metric,minimum_evidence,stop_rule |

## 最小走读示例（纯虚构）

虚构A点击多但购买少：先检查落地页和归因窗口，不能直接认定剧情无效。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 不跨币种和不同归因窗口混算
- [ ] 小样本不宣称显著
- [ ] 不擅改投放预算
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
