# 评论分析工作室：执行契约

## 输入与缺项

授权导出的评论、时间范围、商品类别、需匿名的字段。

先列已有材料、必须补充项、可由工具读取的公开项。不完整时仅执行资料足够的部分。

## 可直接发给助手的请求

> 请根据我提供的材料完成评论分析工作室。先核对授权导出的评论，然后交付 comment-tags.csv、voc-summary.md、action-backlog.csv。执行前告诉我哪些工具和模型实际可用，外发哪些资料以及费用上限；只做已确认的范围。

## 本任务决策规则

- 阶段1：去重并保留原评论ID，把观点与事实分开。
- 阶段2：编码需求、抱怨、障碍和购买动机并抽样复核。
- 阶段3：输出频次、代表片段与产品内容行动表。

## 验收重点

分母、去重规则可复算，不把评论者个别反馈推广到所有人。

## 反例测试

- 用户没有提供必要材料：列缺项并交付可完成的离线部分，不编造输入。
- 指定模型不存在或没有所需模态：停在能力差异说明，不冒用其他型号。
- 工具返回task_id但无产物：保持待完成状态，按服务端建议有限查询，不重复提交付费任务。
- 用户只要求文件：不把文件自动发布、投放、发送或写回业务系统。
