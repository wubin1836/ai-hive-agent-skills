# 发布会切片顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：三款产品发布

```text
这场发布会讲三款软件，只有A已上线，选6条切片，B和C要标内测。
```

预期交付：按产品和受众给六个候选，逐条保留上线或内测条件，并列真实源位置或待定位需求。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-launch-clips",
  "request": "这场发布会讲三款软件，只有A已上线，选6条切片，B和C要标内测。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：发布仍在保密

```text
新品发布会录好了，下周一上午10点解禁，先做4条切片策划，不上传任何文件。
```

预期交付：仅使用已提供资料规划主题和剪点要求，注明具体日期时区待确认及解禁状态，不调用上传或发布。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-launch-clips",
  "request": "新品发布会录好了，下周一上午10点解禁，先做4条切片策划，不上传任何文件。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
