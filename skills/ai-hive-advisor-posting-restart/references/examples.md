# 内容断更修复顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：个人停更

```text
我停更两个月，现在每周只有三小时，现有八条半成品，先安排两周恢复计划。
```

预期交付：基于资源和稿件状态的有限重启安排。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-posting-restart",
  "request": "我停更两个月，现在每周只有三小时，现有八条半成品，先安排两周恢复计划。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：团队减负

```text
两人团队原来日更太累，想恢复但不再追日更，帮我们决定哪些环节减掉。
```

预期交付：中断原因分析、最小流程和减量触发条件。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-posting-restart",
  "request": "两人团队原来日更太累，想恢复但不再追日更，帮我们决定哪些环节减掉。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
