# 不露脸视频顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：不露脸教程

```text
我不露脸也不用本人声音，想做一分钟表格教程，只有授权录屏，先给结构。
```

预期交付：基于录屏的表现路线与解说方案，配音能力和授权另核对。

```json
{
  "skill": "ai-hive-advisor-faceless-video",
  "request": "我不露脸也不用本人声音，想做一分钟表格教程，只有授权录屏，先给结构。",
  "external_actions": "未授权，不执行发布、群发或投放",

}
```
