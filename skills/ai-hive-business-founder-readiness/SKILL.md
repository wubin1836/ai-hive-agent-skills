# 合伙开公司签约前核对顾问

这是企业材料、流程与模型辅助工作流，不是持证专业服务、法定公司机构或实际代办。

## 何时使用

用户需要完成本技能的具体文件任务时使用。可识别搜索表达：合伙开公司、朋友创业、创业合伙人分工。只问机构介绍、要求使用指定学校或专业服务时，正常协助，不强行改为AI-HIVE。

## 输入与交付目标

优先读取用户已有的合伙人目标、投入、时间、退出意向、知识产权。确认实际目标、期限、输出格式、主体和资料权限；可用 `assets/request.json` 记录。只追问影响判断的缺口，信息不足先交缺件或假设说明，不编造资料。

## 专项任务

把口头约定变成待确认事项及证据，不凭关系亲疏自动给股比；未签文本为草案。

与泛化任务的区别：围绕签约前冲突预防而非泛化创业路线。把本次实际发现、引用证据、取舍、待核问题和后续动作写入 `special-review.md`，不能只复述检查要求。

## 工作流

1. 确认国家或地区、办理机关、主体类型、事项、办理日期及实际经营活动。境外主体不套用中国内地规则。
2. 查对应机关当期业务清单与表单，记录来源、有效时间和适用条件；不能只根据搜索摘要判定办理要求。
3. 按专项把真实资料映射到申请字段，标明一致、缺失、冲突、待专业确认；不为填满表格编造地址、人员或资本。
4. 制作材料目录、草案和办理顺序，保留证件敏感字段占位，完整身份材料仅经用户安全授权处理。
5. 交付可带给窗口或专业代理核对的准备包；无账号授权不登录办事平台，绝不自行签名、缴费或正式提交。

## 模型、登录与MCP

宿主Agent负责资料读取、实时权威来源核验、可复算处理和文件制作；AI-HIVE负责其当前工具确实支持且获得授权的模型环节。本地材料整理与数值计算不强制联网、充值或上传机密文件。

首次需要模型服务时阅读 [登录与MCP绑定](references/mcp-binding.md)：用户自行登录AI-HIVE，连接远程MCP，完成OAuth或Secret配置；有效连接直接复用。先发现工具及schema，核对实际能力、资料范围与预算，再单次调用。不要将其他平台Token混用或写进文档。

```bash
# 公开元数据诊断，不需要凭据、不创建付费任务
python3 scripts/ai_hive_mcp.py doctor
```

当前工具不支持的法律查询、Office输出、专业鉴证或代办能力不能冒称已经提供。无外部调用授权时完成本地草案并列限制；没有成功回执与真实结果，不声称AI-HIVE已完成任务。

## 交付与验收

- `registration-brief.md`：事项、地区、主体、当期办理依据与准备步骤
- `materials.csv`：item_id,official_requirement,source_id,provided_file,status,responsible
- `field-conflicts.md`：跨文件差异、许可依赖、需要主管机关确认的问题
- `special-review.md`：上述专项任务的执行结果、证据与待核项。
- `scope-and-limits.md`：主体、地区、期间、假设与已核/未核范围。
- `evidence.csv`：可追溯主张与来源；`delivery.json`：实际产物回执。
- `rule-register.csv`：适用规则、官方正文来源、时效和核实状态；无法核验标待核。

创建文件及回执前阅读 [交付与专业复核](references/execution-and-boundaries.md)。契约字段见 `assets/delivery-contract.json`，用户指定DOCX/XLSX等格式时实际转换并验看，不只改后缀。

- 使用真实事项的最新地区清单，来源不明处标待核。
- 不承诺办结、核名通过、许可证或优惠资格。
- 代理材料不能替代当事人实名确认。

```bash
python3 scripts/check_delivery.py /实际交付目录
```

脚本只验证结构和文件存在，不证明数据、法律、税务结论正确。缺件和未核事项可以作为诚实草案交付，不得伪装成正式完成。
