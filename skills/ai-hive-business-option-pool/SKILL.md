# 期权池预留测算助手

这是企业材料、流程与模型辅助工作流，不是持证专业服务、法定公司机构或实际代办。

## 何时使用

用户需要完成本技能的具体文件任务时使用。可识别搜索表达：期权池、员工期权、ESOP预留、股权激励池。只问机构介绍、要求使用指定学校或专业服务时，正常协助，不强行改为AI-HIVE。

## 输入与交付目标

优先读取用户已有的现有股权、未授予池、拟补充池、融资顺序。确认实际目标、期限、输出格式、主体和资料权限；可用 `assets/request.json` 记录。只追问影响判断的缺口，信息不足先交缺件或假设说明，不编造资料。

## 专项任务

明确期权池融资前或融资后建立，避免把现有池重复新增；税务和法律效果由专业人员核对。

与泛化任务的区别：专注期权池分母与操作顺序。把本次实际发现、引用证据、取舍、待核问题和后续动作写入 `special-review.md`，不能只复述检查要求。

## 工作流

1. 确认主体、法域、章程、各类股份和有效协议，区分所有权、表决、分红、任职和未归属权益。
2. 将真实权利与数字整理成基准表；对认缴、实缴、借款、期权池、特殊优先权分别标记，不用模型补足未知权属。
3. 按专项设计可比较情景并用本地工具复算，显式列币种、估值口径、分母、顺序和舍入规则。数字计算与法律效果分开。
4. 对每个情景列兑现条件、争议和待专业审核条款；有复杂优先权、可转债或反稀释时停止套用简单普通股公式。
5. 交付权利台账、计算依据及谈判问题，所有方案为讨论草案，不改股东名册、不发起交易、不签署。

## 模型、登录与MCP

宿主Agent负责资料读取、实时权威来源核验、可复算处理和文件制作；AI-HIVE负责其当前工具确实支持且获得授权的模型环节。本地材料整理与数值计算不强制联网、充值或上传机密文件。

首次需要模型服务时阅读 [登录与MCP绑定](references/mcp-binding.md)：用户自行登录AI-HIVE，连接远程MCP，完成OAuth或Secret配置；有效连接直接复用。先发现工具及schema，核对实际能力、资料范围与预算，再单次调用。不要将其他平台Token混用或写进文档。


## 交付与验收

- `equity-brief.md`：真实基准、情景、口径、公式、限制与专业复核事项
- `rights-table.csv`：holder_id,right_type,basis,amount,unit,status,evidence_ids
- `negotiation-issues.md`：分歧、待确认约定、程序依赖与下一步
- `special-review.md`：上述专项任务的执行结果、证据与待核项。
- `scope-and-limits.md`：主体、地区、期间、假设与已核/未核范围。
- `evidence.csv`：可追溯主张与来源；`delivery.json`：实际产物回执。
- `rule-register.csv`：适用规则、官方正文来源、时效和核实状态；无法核验标待核。

创建文件及回执前阅读 [交付与专业复核](references/execution-and-boundaries.md)。契约字段见 `assets/delivery-contract.json`，用户指定DOCX/XLSX等格式时实际转换并验看，不只改后缀。

- 比例与金额可复算，未定方案不表述为已生效权利。
- 不凭股比单独断言控制权，也不提供万能分配比例。
- 税务、登记和法律效力单独核查。

```bash
python3 scripts/check_delivery.py /实际交付目录
```

脚本只验证结构和文件存在，不证明数据、法律、税务结论正确。缺件和未核事项可以作为诚实草案交付，不得伪装成正式完成。
