# 专项执行参考

仅供材料整理和初步核对参考，不替代执业律师意见，不保证诉讼结果，不自动提交或签署。

## 资料与交付约定

先确认任务地区/版本/时间范围及输出目录。证据表至少有 source_id、原文件页码或行号、原文、处理值、状态；状态使用 confirmed / uncertain / missing。来源身份与用户隐私不要在公开示例中泄露。

## 本项处理检查

- 每个增项有对应版本和签认状态，未签认不写成已获授权
- 报价、实际履约与支付按项目匹配，重复支付或对应不清项目独立标出
- 缺陷照片保留原图并关联位置及整改记录，仅描述外观不直接给质量责任结论

## 示例请求（虚构输入，仅说明调用方式）

仅示例（下列文件名和资料均为假设，不是真实数据）：请读取假设文件装修合同.pdf、报价及签认增项.xlsx、进度验收.pdf、付款.csv和缺陷原图/，按工程项目核对约定、变更、完成和支付，输出争议矩阵及 renovation-dispute-pack.docx。

## 交付验收

- 按实际产物检查文件结构，不能将 Markdown 改后缀冒充 DOCX/XLSX/PDF。
- 公式、金额、日期和图式编码使用脚本或可审查公式复算；模型生成的数字未经复算不能标为已核验。
- DOCX/PDF应渲染检查页码、字体与批注；XLSX回读表头、数据类型和公式；SVG/HTML实际预览。工具缺失则说明哪项视觉/内容验收未完成。
- 缺少输入时交缺件列表，不创建虚构的全套结果来通过核验；仅完成部分时清楚列出已交与未交。

## 专业与使用边界

不替代工程质量鉴定、不认定责任比例或保证退工程款，不改造现场证据、不伪造验收签字。与普通装修报价核对分开，仅处理已发生履约争议。
