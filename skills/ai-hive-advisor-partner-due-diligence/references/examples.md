# 业务合作尽调顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：代工能力核对

```text
供应商说能月产10万件，这是他们给的资质和产能表，先做资料尽调，不联系对方。
```

预期交付：核对主体、资质范围和产能依据，列需解释的设备工时与外协情况，不凭表格确认真实产能或信用。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-partner-due-diligence",
  "request": "供应商说能月产10万件，这是他们给的资质和产能表，先做资料尽调，不联系对方。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：案例角色不清

```text
合作机构展示了三个大客户Logo，但没证明服务内容，帮我准备核验问题。
```

预期交付：要求说明项目角色、时间、授权及可核验证据，将Logo展示标为未经证实主张，不直接认定造假。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-partner-due-diligence",

  "paid_generation": "未授权，先给方案与预算"
}
```
