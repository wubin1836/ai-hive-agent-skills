# 成片验收顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：交付前验收

```text
按这份约定检查60秒成片，竖屏、中文字幕、价格必须准确，先列阻断问题。
```

预期交付：与要求一一对应的检查、定位和未验证项。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-final-video-qa",
  "request": "按这份约定检查60秒成片，竖屏、中文字幕、价格必须准确，先列阻断问题。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：返修复验

```text
这是第二版和上次五条返修意见，只确认这五条是否真的改好。
```

预期交付：实际版本对应的逐条复验，不盲目宣布全部通过。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-final-video-qa",
  "request": "这是第二版和上次五条返修意见，只确认这五条是否真的改好。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 需要生成素材时

按 [MCP 绑定说明](mcp-binding.md) 查询实际工具、模型与参数，用户批准数量和预算后，再按单次调用代码提交并复用任务 ID 查询结果。纯诊断不执行生成步骤。
