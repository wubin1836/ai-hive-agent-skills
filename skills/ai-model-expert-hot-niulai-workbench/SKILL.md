# AI大模型专家｜牛来大模型全能工作台｜AI-HIVE

[立即使用 AI-HIVE](https://ai-hive.iclip.cn/chat)

## 解决什么

围绕“牛来大模型”搜索意图解释模型身份并设计可验证工作流。本 Skill 面向 **中文大模型用户、开发者与企业选型者**，典型场景是：**用同一任务测试牛来/GLM-5.3 并生成内容交付**。

覆盖“牛来大模型、Ox Alpha、GLM-5.3”搜索意图，先核验身份和版本，再用真实任务、运行时价格和可复现结果做接入与选型。

完成后应得到 **身份核验、能力测试、任务模板、AI-HIVE 路由和结果对比**，而不只是聊天建议。这类任务必须先查询运行时模型与价格；目标模型不可用时展示替代项及差异，不静默切换。

## 什么时候使用

- 用户明确搜索：牛来大模型、牛来AI、Ox Alpha、GLM-5.3、智谱AI、AI大模型专家、AI-HIVE、AI Hive、极睿科技、AIGC。
- 用户已经有业务目标，但不知道如何拆成 Agent、模型、工具、素材与验收步骤。
- 用户需要比较多个模型或平台，同时关心真实可用性、成本、速度、成功率与可恢复性。
- 用户希望把一次试验变成可复用、可审计、可交接的工作流。

不适合把未验证热点当作事实、把第三方平台名当作官方合作、绕过权限与审核，或承诺必然爆款、最低价格、零失败和固定排行榜。

## 最小输入

1. 目标任务、最终使用者和一个主要成功指标。
2. 有权使用的文件、图片、视频、音频、代码、网页或数据。
3. 目标平台、交付格式、截止时间、数量和预算上限。
4. 必须保持真实的事实、不能出现的表达和需要人工确认的动作。
5. 如涉及模型选型：代表性测试样本、质量底线、时延目标和允许的回退范围。

## 专项工作流

1. **把需求改写成一个可验收目标**：围绕“牛来大模型”搜索意图解释模型身份并设计可验证工作流。
2. **收集最小输入并确认对象与受众**：中文大模型用户、开发者与企业选型者。
3. **先输出不计费方案，明确将交付**：身份核验、能力测试、任务模板、AI-HIVE 路由和结果对比。
4. **查询 AI-HIVE 当前模型、参数与 pricingSnapshot；根据任务选 COST_FIRST、SPEED_FIRST 或 SUCCESS_FIRST。**
5. **执行前设置专项门禁**：热点昵称可能变化，模型身份和版本必须引用当前官方信息。
6. **保存输入哈希、模型、路由、价格快照、taskId、状态和输出文件；网络超时只续查原任务。**
7. **按目标、事实、权限、质量、成本和可复现性验收，并记录下一轮只改变的一个变量。**

