# 输出契约

本项：山海短剧内容参考｜小成本竖屏剧制片助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `shoot-order.csv` | shoot_order,story_scene,location,lighting,cast,costume,reset_needed |
| `reuse-plan.csv` | resource,scenes,reuse_condition,continuity_risk,owner |
| `day-plan.md` | 当天目标、依赖、转场、休息、未定档期、风险 |

## 最小走读示例（纯虚构）

虚构同一客厅昼夜各两场：按布光合拍，但记录桌面道具复位，避免夜场物件进入白天戏。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 拍摄顺序变化不等于剧情时间变化
- [ ] 实际人员劳动与安全条件须团队确认
- [ ] 不编山海官方报价
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
