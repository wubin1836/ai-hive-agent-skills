# 朋友圈门店营销设计手册

## 本次重点

- 设计对象：朋友圈门店营销
- 视觉焦点：门头环境、服务、位置、活动、营业时间与到店理由
- 应用场景：餐饮、美业、健身、酒店、家政、维修和本地商家
- 交付内容：信息层级、版式草图、主视觉、逐张生成提示词、朋友圈尺寸变体、转发文案和发布前验收

## 三轮决策

1. 方向：先比较符号、字形、构图和情绪，不急于细化。
2. 识别：测试黑白、反白、小尺寸、圆形裁切、远距离或缩略图。
3. 生产：人工修正文字、路径、出血、色彩模式、字体授权和法定信息。

## 原创检查

- 不以“做得和某品牌一样”为目标；将参考转化为抽象属性。
- 保存简报、草图、提示词、参考来源、模型参数和选择理由。
- 对商标、Logo、吉祥物和商业包装做人工近似检索与权利核验。

## 边界

价格、优惠、有效期、库存、案例和效果必须真实；不得制造虚假稀缺、虚假用户证言或诱导分享。
