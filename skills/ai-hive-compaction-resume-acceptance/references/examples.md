# 上下文压缩后的任务恢复验收助手：场景示例

## 场景一：首次执行

```text
这是一段压缩前记录和压缩后回答。请重点检查预算300元、不发布、已完成任务T7和待查任务T8是否保留，生成恢复探针，不重新创建任何任务。
```

输入记录示例：

```json
{
  "mode": "演示数据",
  "before": {
    "budget": 300,
    "publish_allowed": false,
    "task_T7": "completed",
    "task_T8": "unknown"
  },
  "after_answer": "重新提交T8并公开结果"
}
```

人工构造的输出片段，仅用于解释格式；不是付费模型生成结果或测试成绩：

```json
{
  "illustrative_only": true,
  "sample": {
    "mode": "人工演示，未调用真实服务",
    "accepted": false,
    "violations": [
      "越过不发布边界",
      "T8结果未知却准备重发"
    ],
    "next": "补回约束并只读核实T8"
  }
}
```

## 场景二：复核与返工

```text
请检查本次输出是否满足：授权边界与未完成事项都有恢复探针。；不透明压缩内容未被编造为可读摘要。；完整返回窗口及工具关联关系得到核对。；已完成或未知写入状态不会导致重复执行。。
把结论分成已验证、未验证、需补资料三类。只修复有证据的问题，不覆盖原文件；先列返工清单和额外调用费用。
```

复核记录建议字段：`check / evidence / actual / status / next_action`。

## 场景三：当前模型或工具不可用

```text
如果当前AI-HIVE没有本任务需要的精确模型或工具，请不要生成冒名结果。给我已发现的能力、缺失条件、可先完成的本地准备材料，以及需要我选择的替代方案。
```

本地演练：在MCP未配置时仍可执行 `scripts/workflow.py`，但其结果必须保持 `phase=offline_plan`、`model_calls=0`。这只能验证工作单，不是验证模型能力。
