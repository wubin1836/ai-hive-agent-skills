# 短视频结尾顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：知识视频收尾

```text
这条讲表格去重的视频结尾不要催三连，给两个让观众真能行动的版本。
```

预期交付：与正文方法对应的两个实践型结尾。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-video-ending",
  "request": "这条讲表格去重的视频结尾不要催三连，给两个让观众真能行动的版本。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

```text
第一条讲选题，第二条确实会讲脚本，写一个不吊胃口的衔接结尾。
```
