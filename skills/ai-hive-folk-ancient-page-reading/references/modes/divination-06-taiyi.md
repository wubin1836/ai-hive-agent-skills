# 太乙神数图式对照助手

这是古籍工具的可选专题模式。仅在用户点名且有相应授权原件时使用，不改变基础OCR任务。

仅供传统文化、学习与娱乐参考，尊重科学；不宣称能够科学预测命运，不作为投资、医疗、法律、婚姻等重大决策依据。

## 本模式输入

- 用户合法持有的同一局式两个版本图页
- 页码、版次、图例和已确认节点名称
- 用户指定的对照区域

## 专题处理

1. 图像配准与 OCR 提取两版图页，保留畸变与低置信区域并请用户校正
2. 按已确认名称匹配节点与连线，比较文字异同、位置和图例；不认定版本正确与否
3. 生成半透明叠图 HTML 和异文坐标表，附不同版本原页引用

## 专题输出

- `taiyi-overlay.html`
- `taiyi-variants.csv`
- `taiyi-comparison.pdf`

## 验收与边界

仅为传统文化研究、娱乐参考，尊重科学。无可靠历法与局式实现时不算局；不作国运、灾害、寿命等现实预测，不把异文解释为命运变化。

来源以用户指定的具体版本为准；所有条目保留章节、页码与不确定标记。

仅对本模式交付使用对应 JSON 规格运行 artifact_audit.py verify，不要求同时生成未选择模式的文件。
