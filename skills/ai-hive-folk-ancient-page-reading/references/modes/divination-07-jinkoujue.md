# 六壬金口诀案例索引助手

这是古籍工具的可选专题模式。仅在用户点名且有相应授权原件时使用，不改变基础OCR任务。

仅供传统文化、学习与娱乐参考，尊重科学；不宣称能够科学预测命运，不作为投资、医疗、法律、婚姻等重大决策依据。

## 本模式输入

- 用户合法持有的口诀与案例资料
- 原页码、版本和已确认段落标题
- 需要查找的术语或用户标记

## 专题处理

1. 本地 OCR 后逐段对齐原页坐标，保持口诀原文与用户注释分栏
2. 关键词检索及人工确认把案例引用连回具体口诀，标出找不到出处、同名异段和引文缺字
3. 建立离线全文检索 HTML 与双向引用 CSV，生成待人工核实清单

## 专题输出

- `jinkoujue-index.html`
- `jinkoujue-links.csv`
- `jinkoujue-review.pdf`

## 验收与边界

仅供传统文化资料学习、娱乐参考，尊重科学。按本技能流程由宿主工具处理；不擅自补口诀或模拟秘传，不执行招财、消灾或医疗等仪式，不用案例声称预测准确。

来源以用户指定的具体版本为准；所有条目保留章节、页码与不确定标记。

仅对本模式交付使用对应 JSON 规格运行 artifact_audit.py verify，不要求同时生成未选择模式的文件。
