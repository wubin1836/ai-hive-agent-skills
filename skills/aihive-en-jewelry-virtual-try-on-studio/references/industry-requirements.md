# Industry-specific source notes

Reviewed on 2026-09-24. These notes inform the workflow design, not a promise of acceptance or a complete current policy checklist. Recheck the official source for the actual destination at execution time.

## Game marketing assets

[Steam's asset overview](https://partner.steamgames.com/doc/store/assets?language=english) distinguishes store graphics, screenshots, library assets and event assets. Build a manifest by placement instead of exporting one generic cover. Current templates, dimensions and rules are the source of truth; they are intentionally not frozen into this skill.

[Steam's graphical asset rules](https://partner.steamgames.com/doc/store/assets/rules) define different constraints for these placements. Check them before final export. This pack additionally requires truthful labeling: marketing concepts are not proof of actual gameplay. It does not grant permission to publish to a store or imply affiliation with Valve or Steam.

## Restaurant marketplace photography

[DoorDash's photo issue guide](https://help.doordash.com/en-us/merchants/article/common-photo-issues-explained) distinguishes item, header, carousel and logo photos and describes content, rights and format checks. An attractive generic food picture is not sufficient evidence that it is the correct photo for a particular menu item. Keep the restaurant's item reference and its photo linked.

Do not assume DoorDash requirements also apply to Uber Eats or another marketplace. Check each destination's current official instructions, including whether and how edited or generated media is accepted. Never promise automatic approval.

## Product and category accuracy

[Shopify's photography guide](https://help.shopify.com/en/manual/products/product-media/product-photography) emphasizes clear product presentation and consistent photographic preparation. The category workflows add their own task-specific checks, such as jewelry placement, measured furniture scale and cosmetic color uncertainty. These additions are design judgments, not Shopify certification or claims of conversion improvement.

## Common distinction

An English industry workflow can specialize an existing AI-HIVE capability without claiming a new native model feature. Image generation is not a certified gemstone assessment; a restaurant layout is not automatic dietary verification; concept game art is not an implemented game; a room render is not a measured construction drawing. Use actual host tools for files, editing, code and layout, and AI-HIVE only for supported, approved model steps.
