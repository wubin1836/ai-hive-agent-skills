# 短视频留资顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：只需预约时间

```text
整理师视频想引导预约电话咨询，只需要称呼、联系方式和时间，帮我检查入口。
```

预期交付：评估字段必要性、联系说明和退出安排，给简洁行动提示，不增加家庭住址或收入字段。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-video-lead-capture",
  "request": "整理师视频想引导预约电话咨询，只需要称呼、联系方式和时间，帮我检查入口。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：免费清单领取

```text
我有一份真实盘点清单，想让观众领取，能不能不留手机号，先做方案。
```

预期交付：比较匿名领取与自愿订阅方案，明确交付方式待配置，不把索取手机号设为默认条件。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-video-lead-capture",
  "request": "我有一份真实盘点清单，想让观众领取，能不能不留手机号，先做方案。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
