# 输出契约

本项：来也AI员工同类助手｜从SOP制作岗位任务包。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `sop-decision-table.csv` | rule_id,condition,action,owner,exit_condition |
| `shift-handover.csv` | case_id,last_step,pending_reason,next_owner,source_version |
| `job-pack.md` | 日常触发、输入表、职责、异常入口、交接签收 |

## 最小走读示例（纯虚构）

虚构售后班次有3件退货，其中1件缺物流凭证：2件可进入审核，1件带缺件原因交接，不自动退款。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 每个异常都有接手人或明确待指定
- [ ] 交接可从last_step恢复，不重复外部动作
- [ ] 引用SOP版本号，冲突规则不静默取舍
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
