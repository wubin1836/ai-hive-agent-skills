# 专家咨询准备顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：三十分钟法律咨询

```text
假设我约了30分钟律师咨询，涉及一份服务合同和6次沟通。请按我给的日期整理摘要和5个优先问题，不判断我是否一定胜诉。
```

预期交付：整理合同版本与事件索引，留下需律师判断的争议和证据缺项。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-expert-consult-preparation",
  "request": "假设我约了30分钟律师咨询，涉及一份服务合同和6次沟通。请按我给的日期整理摘要和5个优先问题，不判断我是否一定胜诉。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：复诊前整理问题

```text
假设我已预约15分钟复诊，提供两份报告和自己记录的变化。请只整理事实时间线及想问医生的问题，不解释检查结论或调整用药。
```

预期交付：形成来源清楚的就诊摘要，保留报告原意并把判断交给医生。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：
