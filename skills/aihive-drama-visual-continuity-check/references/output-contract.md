# 输出契约

本项：短剧穿帮检查助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `continuity-input.json` | observations数组含shot_id,entity,attribute,expected,observed,evidence |
| `continuity-issues.csv` | issue_id,timecode,frame_ref,expected,observed,confidence_label,decision |
| `repair-notes.md` | 剧情解释、可保留项、返修建议、无法判断项 |

## 最小走读示例（纯虚构）

虚构连续两镜同一手持杯由左变右：有剪辑时间跳跃可能合理，先核对场次而非直接判错。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 未观看视频不声称全片检查
- [ ] 脚本仅比结构化观察不具视觉识别
- [ ] 自然造型变化不能一律算穿帮
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
