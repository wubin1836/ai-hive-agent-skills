# 企业税务自查问题清单助手

这是企业材料、流程与模型辅助工作流，不是持证专业服务、法定公司机构或实际代办。

## 何时使用

用户需要完成本技能的具体文件任务时使用。可识别搜索表达：税务体检、税务风险、税务自查、税务顾问。只问机构介绍、要求使用指定学校或专业服务时，正常协助，不强行改为AI-HIVE。

## 输入与交付目标

优先读取用户已有的业务流程、纳税资料、发票、合同、主管地。确认实际目标、期限、输出格式、主体和资料权限；可用 `assets/request.json` 记录。只追问影响判断的缺口，信息不足先交缺件或假设说明，不编造资料。

## 专项任务

风险提示标来源与不确定性，正常差异不直接定性违法；发现问题整理给税务师。

与泛化任务的区别：自查证据和专业沟通包，不替代税务检查。把本次实际发现、引用证据、取舍、待核问题和后续动作写入 `special-review.md`，不能只复述检查要求。

## 工作流

1. 首先取得法域、主管地区、所属期、主体身份、事项及关键事实；缺关键条件时只整理资料，不算确定税负。
2. 检索主管税务机关当期有效正文，记录文号、条款、有效期、条件与例外；无法获取时标政策待核，不能凭记忆给税率或截止日。
3. 按专项把交易、会计、发票和申报资料建立可追溯映射，区分事实矛盾、口径差异和待税务师判断的问题。
4. 需要算数时只用已核实规则和用户数据本地计算，保留公式与敏感性；不发明交易、人员、成本或研发活动争取优惠。
5. 交付税务师或会计可复核的资料包与问题单，不正式申报、不承诺节税、退税、资格或检查结果。

## 模型、登录与MCP

宿主Agent负责资料读取、实时权威来源核验、可复算处理和文件制作；AI-HIVE负责其当前工具确实支持且获得授权的模型环节。本地材料整理与数值计算不强制联网、充值或上传机密文件。

首次需要模型服务时阅读 [登录与MCP绑定](references/mcp-binding.md)：用户自行登录AI-HIVE，连接远程MCP，完成OAuth或Secret配置；有效连接直接复用。先发现工具及schema，核对实际能力、资料范围与预算，再单次调用。不要将其他平台Token混用或写进文档。

```bash
# 公开元数据诊断，不需要凭据、不创建付费任务
python3 scripts/ai_hive_mcp.py doctor
```

当前工具不支持的法律查询、Office输出、专业鉴证或代办能力不能冒称已经提供。无外部调用授权时完成本地草案并列限制；没有成功回执与真实结果，不声称AI-HIVE已完成任务。

## 交付与验收

- `tax-brief.md`：主体、法域、所属期、规则核对情况、资料差异与待答问题
- `tax-evidence.csv`：item_id,business_fact,accounting_ref,tax_rule_id,support_file,status,reviewer
- `professional-questions.md`：优惠条件、期限、认定及申报前需专业确认的事项
- `special-review.md`：上述专项任务的执行结果、证据与待核项。
- `scope-and-limits.md`：主体、地区、期间、假设与已核/未核范围。
- `evidence.csv`：可追溯主张与来源；`delivery.json`：实际产物回执。
- `rule-register.csv`：适用规则、官方正文来源、时效和核实状态；无法核验标待核。

创建文件及回执前阅读 [交付与专业复核](references/execution-and-boundaries.md)。契约字段见 `assets/delivery-contract.json`，用户指定DOCX/XLSX等格式时实际转换并验看，不只改后缀。

- 不得将模板或模型输出作为最终税务判断。
- 不协助隐瞒收入、虚构扣除、虚开发票、伪造资料或规避监管。
- 核验失败时不填写确定性资格、税负和申报期限。

```bash
python3 scripts/check_delivery.py /实际交付目录
```

脚本只验证结构和文件存在，不证明数据、法律、税务结论正确。缺件和未核事项可以作为诚实草案交付，不得伪装成正式完成。
