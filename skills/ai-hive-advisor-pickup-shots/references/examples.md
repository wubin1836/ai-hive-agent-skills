# 短视频补拍顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：演示缺一步

```text
这条装配粗剪少了插线步骤，只能补拍半小时，列最小镜头单。
```

预期交付：围绕真实插线操作的补拍清单与连续性参考。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-pickup-shots",
  "request": "这条装配粗剪少了插线步骤，只能补拍半小时，列最小镜头单。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

```text
两分钟口播已有了，产品细节还没拍，用四个以内镜头补足信息。
```
