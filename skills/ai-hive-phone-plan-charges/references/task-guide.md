# 专项执行参考

仅供材料准备与核对参考；具体要求以办理地当前官方规则为准，不保证资格或审批结果。

## 资料与交付约定

先确认任务地区/版本/时间范围及输出目录。证据表至少有 source_id、原文件页码或行号、原文、处理值、状态；状态使用 confirmed / uncertain / missing。来源身份与用户隐私不要在公开示例中泄露。

## 本项处理检查

- 账期、套餐版本与优惠有效期匹配，不能把历史优惠默认延续
- 用量单位、阶梯或包含范围有条款依据，逐项费用汇总与账单勾稽
- 缺少开通同意记录只记待查证，不补造授权或直接认定非法收费

## 示例请求（虚构输入，仅说明调用方式）

仅示例，以下文件名和情境均为假设，不表示已存在真实数据：假设我已提供 示例_三期通信账单.csv、示例_套餐协议.pdf、示例_优惠及增值开通记录.pdf。请使用「手机宽带套餐扣费核对助手」，逐期核对基础费、超量费、设备费及增值费，列出优惠到期和缺少开通凭据的项目。将结果写入我指定的本地目录，交付 phone-plan-charges-checklist.xlsx、phone-plan-charges-evidence.docx、phone-plan-charges-sources.json。本例先离线处理；输入、工具或适用规则不足时先交缺口说明，不编造结果。需要联网更新来源先征得我同意，不登录账户、不代提交或付款。

## 交付验收

- 按实际产物检查文件结构，不能将 Markdown 改后缀冒充 DOCX/XLSX/PDF。
- 公式、金额、日期和图式编码使用脚本或可审查公式复算；模型生成的数字未经复算不能标为已核验。
- DOCX/PDF应渲染检查页码、字体与批注；XLSX回读表头、数据类型和公式；SVG/HTML实际预览。工具缺失则说明哪项视觉/内容验收未完成。
- 缺少输入时交缺件列表，不创建虚构的全套结果来通过核验；仅完成部分时清楚列出已交与未交。
