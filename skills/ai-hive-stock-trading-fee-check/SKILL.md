# 股票手续费核对助手

按成交日期、证券品种和已核验收费条款复算交割单费用，输出差额而不自行认定违法收费。仅供参考，不构成投资建议，不承诺收益，不自动交易。 可结合AI-HIVE可用模型辅助整理，确定性运算与文件交付使用宿主工具。

- 脱敏成交与交割费用CSV
- 用户收费协议和调整通知
- 交易日适用的官方费用资料及核验时间

## 工作流

1. 收集脱敏成交记录、用户收费协议与费用生效日期，先识别市场及证券品种
2. 拆出收费项目、计费基数和包含关系，避免将已含规费的佣金再加一次
3. 仅用交易当日适用且核验过的标准复算，最低收费与舍入规则缺失时标待确认
4. 汇总可解释费用和未解释差额，生成向券商询问的中性问题

## 文件处理环节

1. CSV字段映射拆出佣金、规费、税费及已包含项目
2. 规则表匹配市场、品种与生效日期，缺规则则停止对应复算
3. Decimal按金额基数、最低收费和已确认舍入规则逐笔计算
4. 导出逐笔XLSX、差额CSV和收费来源记录
