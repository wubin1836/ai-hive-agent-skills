# 专项执行参考

仅供参考，不构成投资建议，不承诺收益，不自动交易。

## 资料与交付约定

先确认任务地区/版本/时间范围及输出目录。证据表至少有 source_id、原文件页码或行号、原文、处理值、状态；状态使用 confirmed / uncertain / missing。来源身份与用户隐私不要在公开示例中泄露。

## 本项处理检查

- 每笔规则匹配市场、品种及当时生效日期，不套用未核验现行费率
- 佣金包含项目不重复计费，最低收费与舍入按已确认条款处理
- 总差额等于逐笔差额汇总；缺少条款的记录标未计算而非零差额

## 示例请求（虚构输入，仅说明调用方式）

仅示例，以下文件名和情境均为假设，不表示已存在真实数据：假设我已提供 示例_成交费用.csv、示例_收费协议.pdf、示例_历史费用规则.pdf。请使用「股票手续费核对助手」，逐笔复算指定交易月的费用，区分佣金已包含项目与另收项目，并生成待向券商核实清单。将结果写入我指定的本地目录，交付 trade-fee-check.xlsx、unexplained-fees.csv、fee-rule-sources.json。本例先离线处理；输入、工具或适用规则不足时先交缺口说明，不编造结果。需要联网更新来源先征得我同意，不登录账户、不代提交或付款。

## 交付验收

- 按实际产物检查文件结构，不能将 Markdown 改后缀冒充 DOCX/XLSX/PDF。
- 公式、金额、日期和图式编码使用脚本或可审查公式复算；模型生成的数字未经复算不能标为已核验。
- DOCX/PDF应渲染检查页码、字体与批注；XLSX回读表头、数据类型和公式；SVG/HTML实际预览。工具缺失则说明哪项视觉/内容验收未完成。
- 缺少输入时交缺件列表，不创建虚构的全套结果来通过核验；仅完成部分时清楚列出已交与未交。

## 专业与使用边界

不预填未核验费率，不把现行标准套到历史交易，不推荐开户或换券商，不在证据不足时认定多收费。
