# 输出契约

本项：用友YonGPT同类问数｜业务报表口径助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `metric-contract.md` | 指标定义、分子分母、过滤、粒度、时间、数据版本 |
| `evidence-table.csv` | metric,dimension,numerator,denominator,value,source |
| `query-review.md` | 只读查询/公式、去重检查、排除项、数据缺口 |

## 最小走读示例（纯虚构）

虚构问复购率：先确认是期间两单用户/购买用户，还是老客订单/总订单；两者不得混用。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 确认口径前不给单一结论
- [ ] 查询仅草稿时明确未执行
- [ ] 隐藏客户级敏感原始数据
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
