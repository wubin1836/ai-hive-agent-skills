# 关键人才保留顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：工作负担反馈

```text
核心交付经理自愿反馈加班太多，用项目记录准备留任沟通，先不承诺涨薪。
```

预期交付：实际负担证据、支持选项和尊重本人选择的问题。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-key-talent-retention",
  "request": "核心交付经理自愿反馈加班太多，用项目记录准备留任沟通，先不承诺涨薪。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
