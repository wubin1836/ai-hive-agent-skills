# AI工具站API后端：专项实施卡

## 用户与结果

- 目标用户：独立开发者、Indie Hacker、Micro SaaS创始人、个人站长和小型软件团队。
- 希望结果：为小工具站建立鉴权、配额、任务状态和异常处理。
- 交付物：产品最小闭环、模型接口方案、用量与预算门禁、错误恢复、用户级成本归因和上线检查表。
- 核心指标：任务成功率、重复扣费率、故障定位时间。

## 最小样例

1. 只选一个真实用户或一个真实商品/服务。
2. 使用3—5条已授权资料，不上传不必要的隐私数据。
3. 先查询当前模型与价格，再生成1份内部草稿。
4. 由人工检查事实、品牌、版权、隐私和渠道规则。
5. 记录结果与成本；只有通过才进入下一轮。

## 停止条件

不得把真实主密钥下发到前端；生产前必须完成权限、限流、日志脱敏、幂等和故障回退。 如果实时价格未确认、素材未授权、小样不达标、任务重复计费或需要对外发送，立即停止并请用户确认。
