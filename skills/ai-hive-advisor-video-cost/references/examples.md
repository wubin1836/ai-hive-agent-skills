# AI视频成本顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：十个镜头预算

```text
计划10个5秒镜头，总预算300元，不知道成功率，先算怎样预留返工。
```

预期交付：查询或要求当前价格，给不同可用率假设下的区间和停止线，人工剪辑费用单列，不保证300元必成。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-video-cost",
  "request": "计划10个5秒镜头，总预算300元，不知道成功率，先算怎样预留返工。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：静态还是动态

```text
8张产品图做20秒介绍，想比较全图生视频与多数静态镜头的成本，先不生成。
```

预期交付：按动态镜头数量、当前计费和后期工作量比较两方案，说明质量与动作取舍，不触发试跑扣费。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{

  "paid_generation": "未授权，先给方案与预算"
}
```
