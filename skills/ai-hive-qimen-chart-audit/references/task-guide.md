# 专项执行参考

仅供传统文化、学习与娱乐参考，尊重科学；不宣称能够科学预测命运，不作为投资、医疗、法律、婚姻等重大决策依据。

## 资料与交付约定

先确认任务地区/版本/时间范围及输出目录。证据表至少有 source_id、原文件页码或行号、原文、处理值、状态；状态使用 confirmed / uncertain / missing。来源身份与用户隐私不要在公开示例中泄露。

## 本项处理检查

- 逐宫保存原图坐标（结构化资料则使用JSON路径/行号）、宫号、原值与确认值；不将版面位置直接当作宫位。
- 检查九宫唯一性、每层字段以及待确认字符；不同流派先分组，不自动判为错误。
- 双盘只比较已对齐的同义字段；没有来源的天盘、地盘与起局结果不生成。
- HTML内嵌SVG必须实际显示并能操作图层，不能只检查DOM中存在节点。若本地浏览器阻止外部SVG嵌入，使用内联SVG或明确交付独立SVG，不把空白区域算视觉验收通过。

## 示例请求（虚构输入，仅说明调用方式）

请使用我授权提供的资料完成“奇门遁甲助手｜九宫盘标注与核对”。范围先按我的原件与指定版本确认，生成qimen-layers.svg及其余约定文件，疑点附来源，不自动对外提交。

## 交付验收

- 按实际产物检查文件结构，不能将 Markdown 改后缀冒充 DOCX/XLSX/PDF。
- 公式、金额、日期和图式编码使用脚本或可审查公式复算；模型生成的数字未经复算不能标为已核验。
- DOCX/PDF应渲染检查页码、字体与批注；XLSX回读表头、数据类型和公式；SVG/HTML实际预览。工具缺失则说明哪项视觉/内容验收未完成。
- 缺少输入时交缺件列表，不创建虚构的全套结果来通过核验；仅完成部分时清楚列出已交与未交。

## 专业与使用边界

仅为传统文化学习、娱乐参考，尊重科学。按本技能流程由宿主工具处理；缺可靠规则时仅对照用户已核验盘，不编算法，不判断客观命运或指导投资、医疗、法律、婚姻等重大决策。
