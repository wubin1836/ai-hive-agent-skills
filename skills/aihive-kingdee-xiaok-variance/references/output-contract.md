# 输出契约

本项：金蝶小K同类分析｜经营报表异常解释助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `variance.csv` | metric,period,value,baseline,absolute_change,relative_change,source_cell |
| `hypotheses.md` | 异常证据、主假设、替代解释、验证数据、负责人 |
| `management-brief.md` | 前三项需核实事项、数据限制、建议调查顺序 |

## 最小走读示例（纯虚构）

虚构运费环比涨20%，同时订单数量涨30%：需看单均运费，不能直接判断物流效率恶化。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 基数为零不输出无限增长率
- [ ] 不自动记账/报税
- [ ] 没有凭据的原因只写假设
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
