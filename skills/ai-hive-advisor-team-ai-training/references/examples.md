# 团队AI培训规划顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：混合岗位半天培训

```text
假设销售6人、行政4人、运营5人参加3小时AI培训，基础差异很大。请按附上的岗位任务安排分层练习，不能用真实客户姓名。
```

预期交付：给出共同安全环节、岗位练习、时间安排和独立验收标准。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-team-ai-training",
  "request": "假设销售6人、行政4人、运营5人参加3小时AI培训，基础差异很大。请按附上的岗位任务安排分层练习，不能用真实客户姓名。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：培训后的效果检查

```text
假设团队上周学了AI会议整理，这周提供了8份练习结果。请制定30分钟复盘和两周迁移任务，不因文笔流畅就判合格。
```

预期交付：检查事实遗漏、行动项准确性及复核过程，再安排对应补练。
