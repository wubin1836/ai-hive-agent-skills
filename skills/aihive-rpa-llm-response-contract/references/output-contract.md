# 输出契约

本项：RPA大模型接入助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `integration-contract.md` | 输入输出schema、状态机、trace_id、幂等、超时、日志脱敏 |
| `extraction.json` | 用于样例契约验证的required和fields(name,value,source) |
| `failure-tests.csv` | case,input_error,expected_branch,side_effect_allowed,observed |

## 最小走读示例（纯虚构）

虚构模型返回success但缺invoice_id：契约层判review，不允许RPA点击确认入账。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 模型输出不能任意执行shell/SQL
- [ ] 真正接口需从当前文档或发现的工具获取
- [ ] 429按Retry-After停止批处理
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
