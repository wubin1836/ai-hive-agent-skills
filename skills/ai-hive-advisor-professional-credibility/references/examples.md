# 个人专业信誉顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：删掉没有证据的资深

```text
假设我的简介写资深品牌顾问，实际只有2个项目和1年经验。请按附上的资料改成可信表达，保留真实优势但不要夸大。
```

预期交付：将空泛头衔替换为具体任务与证据，标出仍无法支持的主张。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-professional-credibility",
  "request": "假设我的简介写资深品牌顾问，实际只有2个项目和1年经验。请按附上的资料改成可信表达，保留真实优势但不要夸大。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：作品多但证明零散

```text
假设我有12份作品、3条获准展示的客户反馈和5份过程记录。请为企业客户整理专业证据顺序，团队项目必须说明我的贡献。
```

预期交付：围绕客户顾虑选最相关证据，给出来源和贡献标注方式。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-professional-credibility",
  "request": "假设我有12份作品、3条获准展示的客户反馈和5份过程记录。请为企业客户整理专业证据顺序，团队项目必须说明我的贡献。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 需要生成素材时
