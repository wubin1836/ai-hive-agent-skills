# 工作室产能顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：短视频工作室接单判断

```text
假设3人工作室有8条视频在制，下周还想接6条，只有1人能调色。请用附上的实际工时判断能否接，周末不能加班。
```

预期交付：按环节寻找瓶颈，给出可承接范围和延后条件，不只按人数平均分配。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-studio-capacity",
  "request": "假设3人工作室有8条视频在制，下周还想接6条，只有1人能调色。请用附上的实际工时判断能否接，周末不能加班。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：设计项目等待堆积

```text
假设5个设计项目都在等客户确认，客户可能同一天回复。请根据2名设计师的排期做正常与集中返工两种情景。
```

预期交付：分别计算净容量和返工峰值，给出保留缓冲及接单限制。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-studio-capacity",
  "request": "假设5个设计项目都在等客户确认，客户可能同一天回复。请根据2名设计师的排期做正常与集中返工两种情景。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 需要生成素材时
