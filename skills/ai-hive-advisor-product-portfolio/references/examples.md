# 企业产品组合顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：三条软件线

```text
我们有3条软件产品线，收入相近但维护工时不同，这里有半年数据，决定下季度资源投入。
```

预期交付：统一贡献和维护口径，检查共享客户与技术资源，给投入情景和数据缺口，不仅按收入决定。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-product-portfolio",
  "request": "我们有3条软件产品线，收入相近但维护工时不同，这里有半年数据，决定下季度资源投入。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：别变套餐设计

```text
公司卖设备、耗材和培训，我要决定保留哪条业务，不是把它们打包卖。
```

预期交付：分析三条产品线的贡献、依赖和存量承诺，给资源取舍与退出约束，不输出套餐搭配方案。
