# 视频询盘诊断顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：高播放低询盘

```text
10条视频共5万播放，只有3次咨询，这里是脚本和入口截图，帮我找先检查哪里。
```

预期交付：先核对播放与咨询口径，分析人群、价值表达和入口，缺点击数据时不直接断言表单导致流失。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-video-inquiry-diagnosis",
  "request": "10条视频共5万播放，只有3次咨询，这里是脚本和入口截图，帮我找先检查哪里。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：入口点击多

```text
一个视频有200次链接点击但只有2次提交，表单要填12项，给诊断和测试方案。
```

预期交付：评估必要字段及提交预期，保留访问质量和技术问题的替代解释，提出简化字段测试，不自行修改表单。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{

  "paid_generation": "未授权，先给方案与预算"
}
```
