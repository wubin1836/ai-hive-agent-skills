# 客户流失访谈顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：订阅客户不续约

```text
假设最近有12位客户不续约，我只获准邀请其中4位。请设计20分钟访谈提纲，不把价格太高作为默认答案。
```

预期交付：围绕使用经历和决定过程追问，说明样本限制与退出方式。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-customer-exit-interviews",
  "request": "假设最近有12位客户不续约，我只获准邀请其中4位。请设计20分钟访谈提纲，不把价格太高作为默认答案。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：五份退出反馈归因

```text
假设附上5份匿名客户退出访谈文字稿，请把事实、客户解释和我的猜测分开，只提出有证据支持的改进假设。
```

预期交付：形成可追溯编码和假设清单，不宣称统计上代表全部客户。
