# 输出契约

本项：艺赛旗DocAgent同类｜文档比对与字段质检助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `version-diff.csv` | key,old_value,new_value,old_source,new_source,change_type,reviewer |
| `extraction.json` | 新版关键字段与来源，required字段明确 |
| `review-queue.md` | 重大变化、版式变化、无法对齐项、待确认版本 |

## 最小走读示例（纯虚构）

虚构两版合同付款期限从30天变45天，页码改变：以条款主题对齐，记录实质变更。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 每条差异同时有新旧证据或明确缺失
- [ ] 不能自行判定合同有效性
- [ ] 扫描不清与真实删除区分
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
