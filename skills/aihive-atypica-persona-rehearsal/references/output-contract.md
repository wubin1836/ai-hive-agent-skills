# 输出契约

本项：Atypica同类研究｜AI消费者访谈预演助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `persona-evidence.csv` | persona_id,context,claim,evidence_or_assumption,source |
| `simulated-interviews.md` | 显著标注AI模拟；问题、回答、反例与不确定 |
| `human-validation-plan.md` | 待检验假设、真实招募条件、访谈题、判定方法 |

## 最小走读示例（纯虚构）

虚构高价保温杯概念：模拟办公室与户外场景对容量的冲突，转成真人试用问题，不推导市场需求比例。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 不能把虚拟角色数写成真实受访人数
- [ ] 不提供虚构显著性/市场占有率
- [ ] 输出至少一个挑战主张的反例
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
