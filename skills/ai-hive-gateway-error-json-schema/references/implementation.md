# JSON Schema输出失败：专项实施卡

## 业务目标

缩小schema、检查不支持关键字、截断和非JSON前后缀。

## 目标用户

正在处理大模型 API 接入失败、生成任务异常、流式响应中断或扣费争议的开发者、客服和平台运维人员。

## 必须收集的证据

- 当前配置、端点、模型、调用量与失败样本。
- AI-HIVE 执行当天的模型列表、能力参数与价格快照。
- 3—10 个同输入、同时间、同验收口径的非生产样本。
- 每条样本的输入哈希、模型、参数、路由、taskId、状态、输出和实际成本。
- 回退开关、负责人、观察窗口和停止条件。

## 专项交付

最小复现、分层诊断树、脱敏证据、修复步骤、回归用例和升级支持信息。

## 通过门槛

重点度量：结构化解析率、schema兼容率、重试次数。团队应在执行前填写具体阈值；没有阈值就只做探索，不得切入生产。

## 停止条件

日志和截图必须脱敏；禁止公开 API Key、OAuth Token、私密提示词、用户素材与完整计费信息。 出现重复计费、孤儿任务、不可解释质量下降、未授权数据进入模型、预算越线或无法回退时，立即停止并保留现状。
