# 输出契约

本项：有赞加我智能同类｜商家经营任务助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `merchant-actions.csv` | issue,evidence,priority,owner,next_action,approval,metric |
| `campaign-draft.md` | 客群、真实优惠、内容主题、素材任务、风险 |
| `review-calendar.csv` | action_id,baseline,measurement_window,decision_rule,status |

## 最小走读示例（纯虚构）

虚构某款点击高转化低且尺寸咨询多：先补尺寸图实验，不直接建议全店降价。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 数据过期明确时点
- [ ] 促销不能超出利润和规则约束
- [ ] 库存未核验不承诺有货
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
