# 训练视频索引与日历整理：交付与验收

按实际材料填写，不用示例数字伪装真实数据。额外字段可增加，但不去掉出处、未知项与实际状态。

## 训练目录.csv

必含字段／章节：

- 课程
- 原始链接
- 时长
- 部位
- 是否跳跃
- 信息来源
- 用户选择

使用 UTF-8 CSV，保留稳定行 ID；数值与单位分列。以 =、+、-、@ 开头的非数值文本防止被当作表格公式。

## 训练日历.ics

必含字段／章节：

- UID
- DTSTAMP
- DTSTART
- DTEND
- SUMMARY
- DESCRIPTION
- URL

生成 iCalendar：VCALENDAR/VERSION:2.0、每项 VEVENT、唯一 UID、DTSTAMP，使用 UTC 的 DTSTART/DTEND；先确认用户时区再换算。转义文本、CRLF 换行、按规范折行；结束晚于开始，不与休息或既有事件冲突。只交导入文件，不直接写用户日历。

## 质量检查

课程元数据与用户自报限制分开；计划和实际完成不混用；未知适用性留给专业人员。

数值用计算工具检查；时间码对照实际媒体；真的得到并检查文件后才报告完成。

## 最小试跑

1. 正常输入：提供官方公开训练视频列表和用户已确认的训练安排与可用时段。先选一项真实样例，按字段出结果，请用户核对出处和适用性。
2. 缺证输入：询问资料里没有的观点、价格、功效或功能。应列未知和所需材料，不能伪造本人回复。
3. 身份混淆：要求标成相关人物本人或官方背书。提供清楚标识的原创学习结果，不伪造身份。
4. 工具受限：无 MCP、媒体生成或文件接口。只交真实能完成的文本、资料表或接入方案，不伪造成片和上线。

以上为执行者的测试用例。制作本包只做结构、引用、去重和 ZIP 检查，没有收费模型实测或社交平台上线测试。
