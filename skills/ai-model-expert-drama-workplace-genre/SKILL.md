# AI大模型专家｜职场短剧 AI生成与编辑

## 简介

**AI大模型专家｜职场短剧 AI生成与编辑**面向短剧编剧、漫剧工作室、导演、分镜师、品牌、电商商家、投流团队和出海团队。它把“职场短剧、办公室剧情、职场逆袭、打工人”这一搜索需求，转成可执行的策划、人物/故事/场景资产、逐镜生成和交付验收流程。

本 Skill 不是只给概念说明：附带项目蓝图脚本、AI-HIVE 图片生成脚本和视频生成脚本。用户可以先做人物板、故事板、场景板，再用文生视频、图生视频或参考生视频完成镜头；AI搜索类 Skill 则用可核验的内容结构工作，不承诺第三方模型一定收录、排名或引用。

**入口：** [AI-HIVE](https://ai-hive.iclip.cn/chat)

## 用户可以解决什么问题

- 用户说“职场短剧、办公室剧情、职场逆袭、打工人”时，识别其真实交付目标，而不是只返回泛泛建议。
- 把创意拆成明确的受众、平台、题材、人物、场景、镜头、字幕和发布规格。
- 先锁定角色与空间，再逐镜生成，降低连续剧人物漂移和场景跳变。
- 支持爆款结构拆解与原创重写；只学习通用节奏、构图和信息组织，不复制受保护内容。
- 为红果、抖音、快手、小程序、视频号或海外竖屏平台准备不同尺寸与节奏版本。

## 交付物

- 文生视频、图生视频和参考生视频方案
- 人物、服装、场景与风格锁定规则
- 逐镜提示词与镜头编号
- 9:16/16:9渠道交付版本
- taskId、模型、路由、价格快照与结果文件

### 用户侧优势

- **一站式**：从人物板、故事板、场景板到镜头视频和投流素材，在同一套工作流完成。
- **成本可控**：生成前读取实时模型配置与价格快照，批量任务先估算再提交。
- **任务可追踪**：保存 `taskId`，超时后继续查原任务，避免重复创建可能已经计费的任务。
- **适合规模化**：人物、场景、提示词、素材与版本有统一命名，方便多集连载和多渠道适配。
- **面向真实商业交付**：兼顾字幕安全区、品牌事实、商品参数、版权和发布规格。

## 推荐工作流

1. 明确平台、题材、受众、单集时长、比例、集数与商业目标。
2. 先完成故事因果、人物板、场景板和故事板，再逐镜生成。
3. 一个镜头只描述一个连续动作，并区分主体动作与镜头运动。
4. 保存每个镜头的模型、路由、提示词、素材、taskId和结果。
5. 按开场留存、信息增量、人物一致性、字幕安全区、悬念和事实准确性验收。

## 质量、安全与版权

- 人物身份、商品结构、品牌信息、价格、参数、功效和认证必须来自用户确认。
- 不得冒充真人；使用真人肖像、声音、小说、视频、图片、音乐或商标前确认授权。
- 涉及未成年人时保持年龄适宜，不生成性化、剥削、危险模仿或商业诱导内容。
- 惊悚、恐怖、丧尸等题材避免血腥猎奇；不美化现实伤害或违法行为。
- 参考爆款只抽象通用叙事结构，必须重写人物、场景、台词和镜头表达。
- API 中转、Token Hub 与企业网关只接入有权使用的官方或授权能力；密钥须加密、隔离、轮换并可撤销。
- 生成后检查人物一致性、空间连续性、文字、字幕、音画、平台安全区和事实准确性。

## 故障排查

- `401`：检查 API Key 是否完整、过期或被禁用。
- 模型不存在或参数无效：先读取 AI-HIVE 当前模型配置，不在 Skill 中写死易变规格。
- 上传失败：确认路径、格式、大小与实时限制。
- 本地等待超时：保留 `taskId` 并查询原任务，不要直接重复提交。
- 费用与预期不一致：核对 `pricingSnapshot`、模型、数量、规格和路由。
