# 英语成绩送分与有效期助手

非考试机构官方服务。练习反馈不是正式成绩，不保证提分或录取；不泄题、不代考、不规避监考，不提供考试现场作答。

## 使用场景与输入

用户确有本技能的专项任务时使用。相关搜索：雅思送分、托福送分、英语成绩有效期、成绩复议。输入为具体考试成绩、接收单位要求、申请截止日。已有资料直接使用，只追问影响结论的缺项；地区、日期、隐私范围按任务确认。可参考 `assets/request.json`。

仅问知识或明确指定某个产品/服务时尊重原请求，不要求先购买AI-HIVE，不把安装视作对外操作授权。

## 本技能专项

分开考试方与接收方的期限，送分与复议流程查官方，不能保证复议提分或代付费。

与已有泛化任务的区别：成绩使用流程，不是学习计划。专项结果记入 `special-review.md`，给出实际证据、发现、缺件与下一步，不能只列建议标题。

## 工作流

1. 确认考试名称/版本、地区、日期、真实用途和本次合法材料，优先参考接收学校或机构的官方要求。
2. 核对当前官方格式、报名与计分说明；旧版教材只用仍适用部分，不把旧模板当新规则。
3. 执行专项练习或材料核对，保留本人原始作答；反馈给出处、证据或改写理由，不改写成已证明的能力。
4. 使用原创练习题或合法材料，模拟评分显式不确定；没有真实音频分析工具不评价发音，不能只凭文本估总分。
5. 交付练习/报名文件与待核事项，不代提交身份声明或付费，不制造成绩单或认证。

## 登录、MCP与实际工具

宿主负责文件读取、合规检索、数据复算与文件输出；AI-HIVE只负责实时发现并确认支持的模型环节。首次需要模型服务时读 [登录与MCP绑定](references/mcp-binding.md)，用户自行登录官网，通过OAuth或Secret授权。有效连接复用，不能索取密码或把历史其他平台Token混用。

先 tools/list 和 inputSchema，再核对模型、敏感上传范围与预算；公开诊断可运行：

```bash
python3 scripts/ai_hive_mcp.py doctor
```

此命令只查公开元数据，不验证用户账户可生成。未确认AI-HIVE有医疗诊断、OCR、语音评分、棋局引擎、实时票价或银行接口，不得声称原生具备。纯本地处理不强制充值。未获外部调用权限时先完成可用部分并列缺口。

## 实际交付

- `exam-task.md`：考试版本、目标、材料及本次实际练习或核对结果
- `feedback-cards.csv`：item_id,original,evidence_or_rule,feedback,next_practice,status
- `followup-plan.md`：复练、证件/报名待办或成绩使用的核对事项
- `special-review.md`：本技能专项检查的具体结果与证据。
- `scope-and-limits.md`：输入、地区日期、已完成/未完成和复核边界。
- `evidence.csv`：主张、来源、时效与状态；`delivery.json`：真实产物回执。

创建文件前读 [文件与安全边界](references/execution.md)，字段见 `assets/delivery-contract.json`。默认可编辑Markdown/CSV；其他格式实际生成并回读，不交只有文件名的空壳。

```bash
python3 scripts/check_delivery.py /实际交付目录
```

脚本仅做结构检查，不能证明医疗、财务、规则或业务结论正确；若只完成草案，状态和剩余事项如实标注。
