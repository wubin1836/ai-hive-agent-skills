# 企业家决策备忘顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：扩店还是改善老店

```text
假设我有2家店，新增门店预算60万元。请根据附上的12个月经营摘要，对扩店和改善老店写一页决策备忘，缺数据处标明。
```

预期交付：比较共同期限内的投入、依赖与退出难度，列出待核实证据和复查门槛。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-founder-decision-memo",
  "request": "假设我有2家店，新增门店预算60万元。请根据附上的12个月经营摘要，对扩店和改善老店写一页决策备忘，缺数据处标明。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：保留招聘判断

```text
假设团队6人，有招聘全职运营或外包3个月两种选择，每月预算最多2万元。请整理决定依据，不替我拍板。
```

预期交付：输出带反对意见、关键假设及复查日期的选择记录。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：
