# 输出契约

本项：快麦小智萝卜塔同类客服｜商品知识库与售后分流助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `knowledge.csv` | knowledge_id,sku,region,effective_from,effective_to,claim,source |
| `qa-cases.csv` | case_id,question,expected_knowledge,expected_route,actual_route,status |
| `routing.md` | 售前售后分流、退款审批、证据冲突、未知问题、版本更新 |

## 最小走读示例（纯虚构）

虚构鞋款A可机洗、B不可：问题未给SKU时先问款号，而非沿用高频回答。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 不能用A商品政策回答B商品
- [ ] 未知订单状态不伪称已查物流
- [ ] 不能要求买家发送密码或验证码
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
