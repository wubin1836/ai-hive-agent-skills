# 海报生成助手：具体任务示例

这些是可交给宿主 Agent 的任务请求，不是伪造的 AI-HIVE API。所有示例均需按当前用户范围执行；媒体生成需要另行明确数量和预算。

## 示例 1：门店活动海报

```text
做一张周六手冲体验活动海报，20人、报名费59元，地址和二维码在附件。
```

期望交付：先核对活动具体日期与给定入口，设计清楚层级；授权AI底图后通过实际工具排版，检查二维码和人数价格。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-assistant-poster-maker",
  "request": "做一张周六手冲体验活动海报，20人、报名费59元，地址和二维码在附件。",
  "external_actions": "未授权，不执行发布/投递/群发",
  "media_budget": "未授权，先给方案或询问预算"
}
```

## 示例 2：仅做数字展示

```text
做一张线上Excel公开课海报，1080×1440，不需要印刷，也不放二维码。
```

期望交付：按屏幕规格制作主视觉与课程文字，行动入口使用用户确认的方式，不添加虚假讲师资质或默认生成二维码。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-assistant-poster-maker",
  "request": "做一张线上Excel公开课海报，1080×1440，不需要印刷，也不放二维码。",
  "external_actions": "未授权，不执行发布/投递/群发",
  "media_budget": "未授权，先给方案或询问预算"
}
```

## 有媒体需求时怎么接入

先读 [MCP 绑定说明](mcp-binding.md)。根据任务找到当前真实工具，查询模型与 schema 后创建本地参数文件；不要将上面的任务描述对象误当作工具参数。已授权生成时再执行该说明的单次调用命令，并查询任务状态。纯文字和文件任务不执行这一步。
