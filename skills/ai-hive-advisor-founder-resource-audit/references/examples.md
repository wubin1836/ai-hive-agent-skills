# 创业者资源盘点顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：启动上门摄影服务

```text
假设我想在30天内试做上门摄影，已有相机、6份作品和周末16小时，预算3000元。请盘点资源缺口，朋友场地还没获准使用。
```

预期交付：将朋友场地列待确认，区分必要启动资源与可延后采购项。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-founder-resource-audit",
  "request": "假设我想在30天内试做上门摄影，已有相机、6份作品和周末16小时，预算3000元。请盘点资源缺口，朋友场地还没获准使用。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：知识服务资源核实

```text
假设我要做小型培训，认识3位企业HR但未谈合作，有10篇原创文章。请整理资源地图和本周验证步骤，不直接替我联系他们。
```

预期交付：把关系、内容及交付能力分别核实，提供低成本验证顺序。
