# 看板指标字典与数据核对：交付合同

## 最小交付

1. result.csv 专用结果表，逐条对应输入，不漏失败项。
2. review.md 复核说明：目标、材料范围、实际执行与未执行、证据、结果、返工、下一步。
3. 实际生成/修改的文件与可打开路径；没有工具时明确“仅任务方案，尚未生成”。

| 字段 | 填写约定 |
| --- | --- |
| metric_id | 对应实际的 metric_id 记录；未知写unknown，不编造。 |
| definition | 对应实际的 definition 记录；未知写unknown，不编造。 |
| source | 对应实际的 source 记录；未知写unknown，不编造。 |
| query | 对应实际的 query 记录；未知写unknown，不编造。 |
| period | 对应实际的 period 记录；未知写unknown，不编造。 |
| value | 对应实际的 value 记录；未知写unknown，不编造。 |
| refreshed_at | 对应实际的 refreshed_at 记录；未知写unknown，不编造。 |

模板见 assets/result-template.csv。用户自由文本若以等号、加号、减号或@开头，供表格软件导入前按文本处理，避免公式注入；不得因此篡改真正数值含义。

## 专用执行与证据

- 把每个指标写成分子分母、去重键、时区和过滤条件
- 在只读副本先计算小样与总表核对，查询语句和来源附在指标旁
- 生成可审阅的本地看板或有权限的BI草稿，标注最后更新时间
- 发现数据源未接通则只交付静态快照；自动刷新必须由真实调度器另行配置

## 验收门槛

- 不能宣称静态网页实时刷新
- 不执行数据库写入
- 缺数显示未知不补零

每条记录pass/fail/unknown及证据。关键项为fail或unknown，整体标review_required。不存在证据时不补造截图、时间码、回执、评价。

## 验收练习

- 正常路径（虚构）：收入同比需要同口径退款处理，不能拿含退款毛额对比净额。 按步骤记录，再逐条验收，不将示例当真实结果。
- 缺能力：目标模型或外部软件不可用，报告缺项及可先做的本地步骤，不冒用名称称实测。
- 失败：超时、限流、待审，保存任务ID、原因和已完成项；不重建任务、不遗漏失败费用。

## 报告顺序

结论与状态 → 材料和授权 → 参数与执行记录 → 专用结果表 → 证据和未通过项 → 成本耗时（未知说明）→ 需确认的下一步。

创作保留素材授权与生成标记；数据记录来源、时间、口径，不从示例推导真实客户或商业结论。
