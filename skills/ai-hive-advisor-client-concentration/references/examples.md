# 客户集中度风险顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：最大客户占比过半

```text
最大客户贡献55%收入，我提供各客户毛利、应收和人员占用。请比较其订单减少20%与付款延期30天两种情况，列三项优先准备。
```

预期交付：收入、资金和资源分别展示的情景影响

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-client-concentration",
  "request": "最大客户贡献55%收入，我提供各客户毛利、应收和人员占用。请比较其订单减少20%与付款延期30天两种情况，列三项优先准备。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
