# 绩效指标顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：客服指标改进

```text
客服只追接单量导致问题没解决，按这些记录设计三项以内试运行指标，不直接挂奖金。
```

预期交付：可控成果、口径、副作用和质性复核安排。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-performance-metrics",
  "request": "客服只追接单量导致问题没解决，按这些记录设计三项以内试运行指标，不直接挂奖金。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
