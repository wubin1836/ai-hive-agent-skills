# 素材复用顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：素材库选片

```text
这20段素材给新款产品讲解选可用镜头，旧款接口不能混进去。
```

预期交付：按实际内容和产品版本筛选的清单与缺口。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-asset-reuse",
  "request": "这20段素材给新款产品讲解选可用镜头，旧款接口不能混进去。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

```text
以前只获内部培训授权的客户片段能否放宣传片？先检查记录，不要外发。
```

预期交付：授权不足标记、可用替代和需另行确认的事项。
