# 专项执行参考

仅供参考，不构成投资建议，不承诺收益，不自动交易。

## 资料与交付约定

先确认任务地区/版本/时间范围及输出目录。证据表至少有 source_id、原文件页码或行号、原文、处理值、状态；状态使用 confirmed / uncertain / missing。来源身份与用户隐私不要在公开示例中泄露。

## 本项处理检查

- 主体、期间、币种与单位全部匹配后才进行桥接
- 调整项目按原始正负号求和，残差与公式可重复计算
- 缺失调整项标待补，不用模型填数或直接认定财务造假

## 示例请求（虚构输入，仅说明调用方式）

仅示例，以下文件名和情境均为假设，不表示已存在真实数据：假设我已提供 示例_利润表.xlsx、示例_现金流补充资料.pdf。请使用「财报利润与现金流核对助手」，按同一合并口径把净利润桥接到经营现金流，单列无法解释的调整差额。将结果写入我指定的本地目录，交付 profit-to-cash-bridge.xlsx、cashflow-evidence.csv、unexplained-differences.md。本例先离线处理；输入、工具或适用规则不足时先交缺口说明，不编造结果。需要联网更新来源先征得我同意，不登录账户、不代提交或付款。

## 交付验收

- 按实际产物检查文件结构，不能将 Markdown 改后缀冒充 DOCX/XLSX/PDF。
- 公式、金额、日期和图式编码使用脚本或可审查公式复算；模型生成的数字未经复算不能标为已核验。
- DOCX/PDF应渲染检查页码、字体与批注；XLSX回读表头、数据类型和公式；SVG/HTML实际预览。工具缺失则说明哪项视觉/内容验收未完成。
- 缺少输入时交缺件列表，不创建虚构的全套结果来通过核验；仅完成部分时清楚列出已交与未交。

## 专业与使用边界

这是一项报表核对，不据单一指标断言公司好坏、造假或值得买卖；不预测未来现金流。
