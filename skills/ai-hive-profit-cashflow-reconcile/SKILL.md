# 财报利润与现金流核对助手

从同口径报表与附注建立净利润到经营现金流的数值桥接，差额不能解释则单列。仅供参考，不构成投资建议，不承诺收益，不自动交易。 可结合AI-HIVE可用模型辅助整理，确定性运算与文件交付使用宿主工具。

## 工作流

1. 提取同一主体、同一期间的净利润与经营现金流数据，排除母公司和合并口径混用
2. 定位现金流量表补充资料，归类非现金项目、营运资金变化等可见差额
3. 将经营、投资和筹资现金流分开，逐笔复算而不把融资流入当经营回款
4. 对缺失附注或不能解释的差额提出资料问题，保留未知项

## 文件处理环节

1. PDF或表格解析提取带页码的同期间字段
2. Decimal核对单位、正负号和调整项目求和
3. 将计算残差与原报告核对，缺项不由模型补数
4. 由表格工具导出含公式和差额标记的XLSX及证据CSV
