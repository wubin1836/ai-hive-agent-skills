# 专项执行参考

仅供参考，不构成投资建议，不承诺收益，不自动交易。

## 资料与交付约定

先确认任务地区/版本/时间范围及输出目录。证据表至少有 source_id、原文件页码或行号、原文、处理值、状态；状态使用 confirmed / uncertain / missing。来源身份与用户隐私不要在公开示例中泄露。

## 本项处理检查

- 精确代码与份额类别、费率版本和渠道优惠适用条件逐项一致
- 申赎及持有费按基数与分段期限计算，净值已扣费用不重复扣
- 每个情景列出假设和未知项，不生成通用划算天数或投资适合度结论

## 示例请求（虚构输入，仅说明调用方式）

仅示例，以下文件名和情境均为假设，不表示已存在真实数据：假设我已提供 示例_A类说明书.pdf、示例_C类说明书.pdf、示例_渠道优惠.pdf、示例_持有情景.csv。请使用「基金A/C份额费用计算器」，按我给出的金额、持有期和净值假设计算两类份额的费用情景，仅比较已证实收费，不给购买建议。将结果写入我指定的本地目录，交付 fund-share-fee-scenarios.xlsx、fee-term-evidence.csv、missing-conditions.md。本例先离线处理；输入、工具或适用规则不足时先交缺口说明，不编造结果。需要联网更新来源先征得我同意，不登录账户、不代提交或付款。

## 交付验收

- 按实际产物检查文件结构，不能将 Markdown 改后缀冒充 DOCX/XLSX/PDF。
- 公式、金额、日期和图式编码使用脚本或可审查公式复算；模型生成的数字未经复算不能标为已核验。
- DOCX/PDF应渲染检查页码、字体与批注；XLSX回读表头、数据类型和公式；SVG/HTML实际预览。工具缺失则说明哪项视觉/内容验收未完成。
- 缺少输入时交缺件列表，不创建虚构的全套结果来通过核验；仅完成部分时清楚列出已交与未交。

## 专业与使用边界

不建议购买哪只基金或哪类份额，不给通用长短期分界天数，不将成本低等同于投资更合适；不得把净值已扣费用再次扣除。
