# Seedance2.5绿幕换景与人物边缘检查

[打开AI-HIVE工作台](https://ai-hive.iclip.cn/chat)

## 这个技能帮你做什么

将授权绿幕视频中的主体放入指定新场景，检查发丝、透明物、边缘色溢和接地关系，同时保留人物动作。明确模型生成的换景与传统抠像合成的不同，交付成片和边缘问题记录，不把绿色背景去掉就当作完整验收。

## 实际工作流程

1. 核验Seedance2.5的真实绿幕/视频编辑能力，查看原片中的绿衣、反光、透明道具和遮挡，确认哪些区域可能难以分离。
2. 记录人物轮廓、脚底位置和动作节奏，选择与机位、地平线和主光方向相容的新场景。
3. 明确只换环境还是允许环境带来的光照互动，不能把背景授权扩展成改脸、换衣或改变动作。
4. 用户确认素材与预算后提交并保存任务ID；状态不明查原任务，不无限返修难以分离的发丝。
5. 按运动关键帧检查发丝、手指、道具、边缘绿溢和落地阴影，再通看是否出现人物外形或动作漂移。
6. 交付换景视频、边缘抽查图和问题清单；如果只有传统合成工具可用，先获得同意再改方案并明确执行方式。

涉及模型调用前记录实际模型ID、工具名、数据外发范围与可用导出工具。付费调用须在用户确认的范围与预算内，发布、群发、数据库写入或部署另需明确授权。模型不可用时交付准备材料并说明缺口，不静默换模型，不伪造最终结果。

## 验收要点

- 主体衣物、脸部和动作未有未授权改动
- 发丝、手指与道具边缘问题被记录
- 机位、光照和接地关系没有明显冲突
- 交付文件没有被误称为带Alpha透明通道的视频

- 区分计划、人工示例与真实执行结果；用输入指纹、工具返回或任务ID证明实际完成步骤。

## 本技能的适用边界

通过AI-HIVE MCP实时发现指定型号、输入schema与本次模式后才能生成；不存在就说明不能生成，不将其他版本或其他模型冒充指定型号。素材上传、数量与费用须获本次授权；保存真实任务ID，超时先查询原任务，不自动重提或扩量。默认输出是带新背景的成片，不保证透明Alpha或传统逐像素抠像结果。人物外观可能受生成影响，必须核对；缺少绿幕编辑能力时不假称已完成模型换景。
