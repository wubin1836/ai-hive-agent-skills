# 线索质量复盘顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：咨询很多却不适配

```text
上月60次咨询，很多超出服务城市，这是脱敏记录和视频来源，帮我复盘质量。
```

预期交付：按地域适配、需求和响应状态分组，核对重复与未知记录，评估视频范围表达，不给客户贴贬义标签。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-lead-quality-review",
  "request": "上月60次咨询，很多超出服务城市，这是脱敏记录和视频来源，帮我复盘质量。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：长周期不能算无效

```text
企业咨询通常决策两个月，老板把当月未成交都算无效，帮我重做质量口径。
```

预期交付：区分已确认适配、评估中、暂缓和不适配，设一致观察窗口，不将尚未成熟线索计作失败。
