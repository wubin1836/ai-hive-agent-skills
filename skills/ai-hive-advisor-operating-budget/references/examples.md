# 经营预算顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：季度费用压缩

```text
有三个部门共申请80万元，下季度可用预算60万元。我提供项目目标和合同承诺，请给保底、平衡两个方案，不直接按比例砍预算。
```

预期交付：两方案及不可压缩承诺、受影响目标

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-operating-budget",
  "request": "有三个部门共申请80万元，下季度可用预算60万元。我提供项目目标和合同承诺，请给保底、平衡两个方案，不直接按比例砍预算。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：新增投放预算审核

```text
营销申请追加10万元，但只提供曝光预测。请帮我做一页预算追问清单，要求补充线索目标、试验规模和停损条件，不替我审批。
```

预期交付：待补证事项、分阶段投入建议与复查点

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-operating-budget",
```
