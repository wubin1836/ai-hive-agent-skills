# 文档AI生成社媒素材：专项实施卡

## 用户与结果

- 目标用户：不会编程但希望在办公软件、零代码平台、聊天客户端或手机端使用多模型能力的个人和企业用户。
- 希望结果：从授权文档提取观点、引用和视觉需求制作草稿。
- 交付物：登录绑定步骤、无密钥示例、首个只读验证、场景模板、付费确认门和常见错误处理。
- 核心指标：引用准确率、素材复用率、出稿时间。

## 最小样例

1. 只选一个真实用户或一个真实商品/服务。
2. 使用3—5条已授权资料，不上传不必要的隐私数据。
3. 先查询当前模型与价格，再生成1份内部草稿。
4. 由人工检查事实、品牌、版权、隐私和渠道规则。
5. 记录结果与成本；只有通过才进入下一轮。

## 停止条件

不要把API Key粘贴到聊天、截图或同步文档；不支持安全密钥存储的客户端优先使用OAuth或网页。 如果实时价格未确认、素材未授权、小样不达标、任务重复计费或需要对外发送，立即停止并请用户确认。
