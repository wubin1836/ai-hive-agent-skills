# 输出契约

本项：来也APA流程拆解｜跨系统任务交接助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `task-graph.json` | tasks数组，id、depends_on、approval_required、approver |
| `handoff-contract.csv` | from,to,business_key,input_schema,receipt,retry_policy |
| `partial-failure.md` | 故障位置、已成功动作、回执查询、人工补偿和恢复点 |

## 最小走读示例（纯虚构）

虚构发票已在A生成，B入库请求超时：先按发票业务键查询B，保留unknown状态。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 依赖图无环且没有不存在的节点
- [ ] 无法查询写入结果时停止，不推定失败重发
- [ ] 补偿也是有副作用动作，须授权
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
