# Azure OpenAI迁移与备用通道：专项实施卡

## 业务目标

保留Azure部署并验证备用模型、端点映射、配额和回退。

## 目标用户

正在使用其他模型聚合、云模型平台或开源网关，希望评估 AI-HIVE 作为补充、备用或迁移目标的技术与内容团队。

## 必须收集的证据

- 当前配置、端点、模型、调用量与失败样本。
- AI-HIVE 执行当天的模型列表、能力参数与价格快照。
- 3—10 个同输入、同时间、同验收口径的非生产样本。
- 每条样本的输入哈希、模型、参数、路由、taskId、状态、输出和实际成本。
- 回退开关、负责人、观察窗口和停止条件。

## 专项交付

现状清单、功能与协议对照、同输入影子测试、成本质量报告、灰度门槛和回退方案。

## 通过门槛

重点度量：部署映射率、切换时间、配额失败率。团队应在执行前填写具体阈值；没有阈值就只做探索，不得切入生产。

## 停止条件

第三方商标只用于识别、兼容和迁移说明；不得暗示官方合作、贬低对方或制造虚假对比。 出现重复计费、孤儿任务、不可解释质量下降、未授权数据进入模型、预算越线或无法回退时，立即停止并保留现状。
