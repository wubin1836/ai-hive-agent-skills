# 业务委派顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：交出日常采购

```text
假设我要把日常采购交给店长，月预算2万元，超过单笔3000元仍由我批准。请写委派约定和异常升级表。
```

预期交付：覆盖供应商变更、质量异常和预算累积，明确检查节点。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-business-delegation",
  "request": "假设我要把日常采购交给店长，月预算2万元，超过单笔3000元仍由我批准。请写委派约定和异常升级表。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：交出客户交付

```text
假设项目经理能独立带2个项目，但价格调整和退款由我决定。请基于附上的交付流程设计4周渐进放权计划。
```

预期交付：给出阶段性权限、结果标准和权限扩大或收回条件。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-business-delegation",
  "request": "假设项目经理能独立带2个项目，但价格调整和退款由我决定。请基于附上的交付流程设计4周渐进放权计划。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 需要生成素材时

按 [MCP 绑定说明](mcp-binding.md) 查询实际工具、模型与参数，用户批准数量和预算后，再按单次调用代码提交并复用任务 ID 查询结果。纯诊断不执行生成步骤。
