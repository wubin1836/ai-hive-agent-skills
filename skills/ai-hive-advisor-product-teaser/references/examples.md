# 新品预热视频顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：样机仍在测试

```text
我们的折叠灯月底计划上市，续航还在测试，先策划3条15秒预热。
```

预期交付：只围绕已确认外观和使用场景释放信息，续航与日期状态明确，概念画面不冒充测试结果。

```json
{
  "skill": "ai-hive-advisor-product-teaser",

  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：不玩假稀缺

```text
新课程两周后开售，想做三阶段预热，没有报名人数，不要只剩名额这种话。
```

预期交付：以问题、课程练习和交付说明递进，所有招募数据留空待确认，不添加虚假倒计时压力。
