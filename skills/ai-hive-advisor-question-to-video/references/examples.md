# 用户问题视频化顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：客服问题成片方案

```text
这十条脱敏咨询都问怎么安装，整理成一条45秒能看懂的视频方案。
```

预期交付：共同问题、真实安装依据和必要演示镜头。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-question-to-video",
  "request": "这十条脱敏咨询都问怎么安装，整理成一条45秒能看懂的视频方案。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
