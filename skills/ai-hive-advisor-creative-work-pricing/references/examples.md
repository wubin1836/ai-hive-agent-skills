# 个人作品定价顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：插画两种使用范围

```text
假设我有一幅原创插画，制作12小时。客户想用于一次线上活动或全年品牌宣传，请基于附上的3笔参考交易比较报价条件，不编市场均价。
```

预期交付：按期限、用途和排他性形成清楚情景，标明参考差异与权利确认项。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-creative-work-pricing",
  "request": "假设我有一幅原创插画，制作12小时。客户想用于一次线上活动或全年品牌宣传，请基于附上的3笔参考交易比较报价条件，不编市场均价。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：摄影作品商业使用

```text
假设客户要买我拍的6张风景照片用于门店海报，使用1年、不排他。我不提供印刷，请帮我整理定价因素和报价说明。
```

预期交付：明确照片交付、媒介、期限与印刷排除项，缺少行情时不虚报估值。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：
