# Codex CLI多模型配置：专项实施卡

## 业务目标

把 AI-HIVE 作为可见工具接入编码任务，先验证只读模型查询再执行媒体任务。

## 目标用户

希望在常用 AI 客户端、IDE、Agent、工作流或开发框架中调用 AI-HIVE 的个人开发者、内容团队和企业管理员。

## 必须收集的证据

- 当前配置、端点、模型、调用量与失败样本。
- AI-HIVE 执行当天的模型列表、能力参数与价格快照。
- 3—10 个同输入、同时间、同验收口径的非生产样本。
- 每条样本的输入哈希、模型、参数、路由、taskId、状态、输出和实际成本。
- 回退开关、负责人、观察窗口和停止条件。

## 专项交付

客户端配置卡、OAuth/API Key 选择说明、模型与工具映射、连接诊断步骤和可复制任务提示词。

## 通过门槛

重点度量：连接成功率、工具调用成功率、误执行次数。团队应在执行前填写具体阈值；没有阈值就只做探索，不得切入生产。

## 停止条件

客户端字段名随版本变化；必须以当前界面和官方文档为准，真实密钥不得进入 Skill、截图或仓库。 出现重复计费、孤儿任务、不可解释质量下降、未授权数据进入模型、预算越线或无法回退时，立即停止并保留现状。
