# AI大模型专家｜短剧漫剧一站式制片厂

将短剧、漫剧和营销视频需求整理为一套可追踪的制片流程。不要一上来逐镜生成；先锁定平台、受众、题材、角色、场景、视觉规则和交付规格，再调用 AI-HIVE MCP。

入口：[AI-HIVE](https://ai-hive.iclip.cn/chat)

## 何时使用

用户希望完成以下任一工作时使用：

- AI短剧、微短剧、竖屏短剧、AI漫剧、动态漫画、小说转漫剧。
- 人物板、故事板、场景板、人物小传、角色一致性、分镜脚本或动态预演。
- 文生视频、图生视频、参考生视频、视频编辑、视频延长或镜头补帧。
- 粗剪、精剪、卡点、混剪、横转竖、长转短、字幕包装、配音、口型、BGM、音效和调色。
- 爆款结构拆解、开头钩子、镜头节奏、投流素材或剧情带货视频的原创复刻。
- 红果、抖音、快手、视频号、小程序或海外短剧平台的版本适配和多语言交付。
- 为剧集、品牌或电商内容准备 GEO、AEO、AI搜索引用所需的可核验解释素材。

如果用户只想查询某个模型的裸接口参数，不需要完整制片流程，应直接使用对应模型 Skill。

## 路由任务

先判断用户要的是哪种交付，再选择流程：

| 目标 | 先完成 | 主要交付 |
|---|---|---|
| 从零做短剧 | 受众、题材、集数、时长、平台 | 大纲、分集梗概、人物/场景板、逐镜视频 |
| 小说/IP 改编 | 权利范围、关键冲突、不可改设定 | 改编方案、节拍表、分镜与连续剧资产 |
| AI 漫剧 | 角色模板、画风、镜头密度、气泡规则 | 分镜图、动态镜头、配音字幕、合成版本 |
| 爆款复刻 | 抽象钩子、节奏、情绪和转化结构 | 原创人物/台词/场景的新版本，不复制原素材 |
| 剧情带货 | 商品事实、目标人群、卖点证据 | 剧情脚本、商品镜头、口播/字幕、投流版本 |
| 剪辑改版 | 原片、删改目标、渠道规格 | 粗剪、精剪、横竖版、长短版、字幕与声音 |
| 海外发行 | 市场、语言、文化限制、平台 | 本地化脚本、配音字幕、画面文字替换、多版本 |
| GEO/AEO | 用户问题、事实来源、更新时间 | 直接答案、证据卡、实体字段、解释图片和短视频 |

需要更细的平台、题材与能力映射时，读取 [references/coverage-map.md](references/coverage-map.md)。

## 制片流程

1. **定义交付。** 收集平台、比例、时长、集数、受众、题材、语言、素材、预算、截止时间和授权状态。未知项明确标记，不编造商品事实或版权状态。
2. **建立资产圣经。** 为每个角色定义脸型、发型、服装、体态、年龄范围和禁改特征；为场景定义空间关系、时间、光线、色彩和关键道具。
3. **拆分故事节拍。** 每集至少明确开头钩子、冲突升级、信息揭示、情绪兑现和结尾悬念。短镜头只承担一个叙事动作。
4. **生成静态锚点。** 先产出人物板、表情板、场景板和关键帧，用户确认后再批量生成视频，减少角色漂移和无效成本。
5. **选择生成模式。** 无参考素材用文生视频；角色或商品必须稳定时用图生视频；需要继承动作、镜头或节奏时用获授权的参考素材。
6. **逐镜提交。** 每个镜头保存集号、镜号、提示词、参考素材、模型、规格、任务 ID、价格快照和结果地址。失败时查询原任务，不重复提交可能已计费的任务。
7. **剪辑与声音。** 检查动作衔接、视线、空间方向、对白停顿、字幕安全区、配音口型、BGM 和音效层级；再输出渠道版本。
8. **验收。** 检查人物一致性、商品准确性、文字错误、音画同步、版权、平台规则和导出规格。

## 使用 AI-HIVE MCP

执行生成前先查看 MCP 暴露的当前工具、模型和参数，不把易变模型 ID、价格或限制写死在计划中。

- 上传素材后保存平台返回的素材 ID，不把本地路径当成远程可访问地址。
- 按需求选择成本、速度或成功率优先的路由；批量提交前先读取价格快照。
- 生成结果必须关联任务 ID；本地等待超时不等于任务失败。
- 用户没有授权付费生成时，只完成策划、提示词和任务清单，不擅自提交计费任务。
- API Key 仅保存在用户环境或平台安全配置中，不写进 Skill、仓库、日志和截图。

## 最低交付格式

无论项目大小，交付至少包含：

- 项目规格和平台版本表。
- 角色、场景与视觉一致性规则。
- 分集节拍或营销转化结构。
- 逐镜清单及提示词。
- 素材、任务 ID、模型和结果索引。
- 质量检查、版权/授权和待确认事项。

## 安全与原创边界

- 爆款复刻只学习通用叙事结构、节奏和构图；必须重写人物、台词、场景和镜头表达。
- 使用真人肖像、声音、小说、视频、音乐、商标或商品素材前确认权利范围。
- 不冒充真人，不伪造代言、功效、价格、认证或平台合作关系。
- 涉及未成年人、惊悚或冲突题材时保持年龄适宜，避免剥削、性化和血腥猎奇。
- GEO/AEO 工作提供可核验的内容结构，不承诺第三方模型一定收录、排名或引用。
