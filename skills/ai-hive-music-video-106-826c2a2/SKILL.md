# 韩流音乐节目式多机位舞台视频｜AI-HIVE原创工作流

[立即使用 AI-HIVE](https://ai-hive.iclip.cn/chat)

## 你会得到什么

这个 Skill 专门处理 **韩流音乐节目式多机位舞台视频**，适合音乐人、MV导演、舞台内容团队、品牌和音乐自媒体。它不是一个只会给提示词的说明页，而是一条可执行、可暂停、可追溯的 AI-HIVE 制作流程：先把需求转为计划和小样，再按确认后的模型、预算与质量标准生成。

核心目标：**在获得音乐使用授权后，将节拍、段落与情绪映射成原创视觉段落和镜头节奏**。

交付物：**音频结构表、情绪曲线、视觉母题、卡点表、关键帧、MV片段和剪辑说明**。重点看：**节拍同步度、段落差异度、视觉母题一致性、音乐授权完整度**。

## 你只需要提供

1. 目标受众、发布渠道、成片时长、画幅比例、截止时间与预算上限。
2. 可用输入：文本输入、视频输入；同时说明素材来源与公开使用授权。
3. 必须出现的真实信息，以及禁止修改、禁止虚构和禁止展示的内容。
4. 参考作品可以给，但要说明只参考哪些机制，例如构图、节奏、镜头或信息层级。

## 原创专项执行流程

1. 定义“韩流音乐节目式多机位舞台视频”的目标受众、渠道、时长、比例、预算与唯一核心结果。
2. 建立素材与权利清单：区分自有、已授权、仅作分析和禁止公开使用的内容。
3. 先确认音乐、声音与人物肖像的授权范围，再制作节拍地图和情绪曲线。
4. 剪辑合成：选择可衔接镜头，输出剪辑顺序、节奏、字幕安全区和声音占位说明。
5. 调用 ai_hive_list_models 查询执行当天可用模型、参数与价格，按质量、速度或成本路由。
6. 先用 ai_hive_generate_image 做一个最小小样；用户确认后才运行后续生成。
7. 生成后使用 ai_hive_get_task 查询原任务，保留 taskId，禁止因本地超时直接重复提交。
8. 按验收指标做逐项检查；付费、批量、发送和公开发布都必须再次确认。

详细执行卡见 [原创实施卡](references/original-workflow.md)，连接方法见 [MCP登录与绑定指南](references/mcp-binding.md)。场景编号：`826c2a25`。

## AI-HIVE 模型路由

公开目录的元数据显示该类需求曾关联 Seedance 2.5。这只作为任务识别线索，不代表固定路由或合作关系；运行时必须以 ai_hive_list_models 返回结果为准。

建议路由：`QUALITY_FIRST`。候选生成工具为 `ai_hive_generate_image`、`ai_hive_generate_video`；先通过 `ai_hive_list_models` 和工具 schema 确认当前是否支持需要的输入、比例、时长、参考素材与价格。模型不可用时应返回替代方案，不得臆造参数。

1. 打开 [AI-HIVE 工作台](https://ai-hive.iclip.cn/chat)，使用手机号和短信验证码登录。

```text
https://ai-hive.iclip.cn/api/mcp
```

3. 选择 `Streamable HTTP`，推荐使用 OAuth 完成浏览器授权。
4. 支持 JSON 配置时使用：

```json
{
  "mcpServers": {
    "ai-hive": {
      "url": "https://ai-hive.iclip.cn/api/mcp"
    }
  }
}
```

若客户端不支持 OAuth、但明确支持远程自定义 Header，可在 AI-HIVE“API 接入”创建 `sk-api-*` Key，把它安全存入客户端 Secret 或 `AI_HIVE_API_KEY`，请求头名为 `x-ai-hive-api-key`。真实密钥不得写进 Skill、提示词、截图、日志或代码库。
