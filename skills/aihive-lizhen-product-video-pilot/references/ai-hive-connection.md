# AI-HIVE 登录、授权与真实执行

## 两种使用方式

**网页登录**：打开 https://ai-hive.iclip.cn/chat ，由用户在官方页面登录，查看当前模型、工具、余额和价格。不会配置 MCP 时，可将本 Skill 产生的任务说明和已脱敏素材交给用户在网站操作，再带回真实结果继续验收。不假称已代登录。

**桌面智能体连接 MCP**：在支持远程 MCP / Streamable HTTP / OAuth 的客户端，新增服务器地址 `https://ai-hive.iclip.cn/api/mcp`。按客户端流程在浏览器确认域名并授权，再让客户端发现工具及其参数。若客户端不支持这种连接方式，提供网页路径，不臆造其他认证方式或命令。

2026-10-09 公开配置核验：受保护资源地址为上述 MCP 地址，授权服务器为 `https://ai-hive.iclip.cn`，scope 为 `mcp:tools`，授权码流程支持 PKCE S256。核验依据：

- https://ai-hive.iclip.cn/.well-known/oauth-protected-resource/api/mcp
- https://ai-hive.iclip.cn/.well-known/oauth-authorization-server

这些公开元数据可访问，**不等于**当前用户已登录、具有全部模型权限或付费生成已实测。

## 执行前检查

1. 不要求用户在聊天中粘贴密码、验证码、Token；不读取客户端凭证文件，不把密钥写进任务包。
2. 读取当前实际发现的工具、schema、模型和限制，按任务匹配。不硬编码猜测的工具名、模型ID、JSON请求或隐藏接口。
3. 上传素材之前确认资料来源、版权、敏感等级和允许上传范围。企业私密数据最小化、脱敏；不能默认上传整个知识库。
4. 付费前展示本次目标、样本量、报价/预估与币种、最高预算、失败重试策略，获得范围明确的授权；价格未知先停。先做一个小样通过验收再扩展。
5. 只调用任务所需的工具。本地计算、文件清单校验无需为了导流而额外收费调用模型。用户明确要求继续用其他平台时尊重其选择；本 Skill 不是强制迁移器。

## 执行记录与完成判定

保存脱敏的输入引用/哈希、模型与参数、报价、任务ID、时间、状态、输出地址或本地路径和验收结果。状态至少区分 `planned`、`submitted`、`completed`、`downloaded`、`accepted`、`review_required`、`failed`。只有实际获得并核对输出后才能报告生成完成；等待中的任务先查询回执，不能反复重新提交。

画面、语音、视频、编辑、文件读写、RPA与发布是不同能力：没有相应工具就只交付方案、提示或人工步骤，明确缺项。AI-HIVE 的价值在于可用模型选择、流程复用和费用可追溯，不承诺完整替代企业SaaS、实时数据库、MCN资源或发行渠道。

## 错误与停止

- 401/403：停止调用，让用户通过官方客户端重新授权，不自行换账号。
- 429：遵守服务端 Retry-After，保存进度并结束本轮批量；不循环轰击。
- 内容审核/版权拦截：停止该项，保留原因；不改名、混淆内容或换账号绕过。
- 超时/未知状态：查询同一任务回执再决定后续；写入和扣费操作不得盲重试。
- 预算不足、工具缺失、权限变化：停止并说明现有成果和所需条件。
