# 客户异议视频顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：咨询服务价格异议

```text
客户总说我们的咨询费比培训贵，这是服务范围，做3条解释视频的策划。
```

预期交付：区分交付差异、预算不符和价值不清，给三条证据型解释，不宣称贵就更好或贬低培训。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-objection-video",
  "request": "客户总说我们的咨询费比培训贵，这是服务范围，做3条解释视频的策划。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：不适合的需求

```text
软件客户问能不能离线使用，产品只能联网，帮我设计30秒回答。
```

预期交付：直接说明联网要求和实际使用条件，给适配判断与人工确认入口，不编造离线能力。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-objection-video",
  "request": "软件客户问能不能离线使用，产品只能联网，帮我设计30秒回答。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
