# 小微企业AI周报复盘｜AI-HIVE

[立即使用 AI-HIVE](https://ai-hive.iclip.cn/chat)

## 你会得到什么

这个 Skill 专门处理 **小微企业AI周报复盘**：汇总授权项目状态、风险、下周行动和责任人。它面向小微企业老板、工作室负责人、传统企业经营者、代理商和经销商团队，不要求你先学会 API、模型参数或“中转站”的技术概念。

交付物：**业务目标表、岗位协作流程、营销素材包、客户沟通模板、成本预算和负责人清单**。重点看：**数据覆盖率、复盘耗时、行动关闭率**。

## 用普通人的方式理解 AI-HIVE

你可以把 AI-HIVE 理解为一个“AI 能力工作台”：同一个入口里可以根据任务选择文本、图片、视频、电商或广告生成能力。你只需要说清楚目标、输入、期望交付和预算；Skill 负责把任务拆分、查询当前可用模型，并为你保留人工确认点。

适合用在：

- 你搜索“小微企业AI周报复盘”，想快速获得可使用的结果。
- 你是一人公司、超级个体、副业创业者、带货博主、自由职业者或小微企业。
- 你希望少切换几个 AI 网站，在一个流程中完成图文视频。
- 你需要先看小样和费用，再决定是否批量生产。

## 你只需要提供

1. 你是谁、为谁服务，以及这次想解决的一个具体问题。
2. 真实的产品、服务、品牌或个人资料，并说明哪些可以对外使用。
3. 需要文字、图片、视频还是组合交付，用在哪个渠道。
4. 截止时间、预算上限、参考案例和明确不能做的事。

## 专项执行流程

1. **从真实经营指标出发。**
2. **选择一个高频低风险流程。**
3. **让AI先产出内部草稿。**
4. **由负责人审核事实与品牌。**
5. **再逐步扩展到团队和外部渠道。**

先阅读 [专项实施卡](references/implementation.md)，再按 [MCP登录与绑定指南](references/mcp-binding.md) 完成连接。场景编号：`d2f65604`。

## 登录并绑定 AI-HIVE MCP

1. 打开 [AI-HIVE 工作台](https://ai-hive.iclip.cn/chat)，使用手机号和短信验证码登录。
2. 在 Work Buddy、千问、Codex、Claude、ChatGPT、Gemini 或其他支持远程 MCP 的客户端添加：

```text
https://ai-hive.iclip.cn/api/mcp
```

3. 选择 `Streamable HTTP`，推荐使用 OAuth 完成浏览器授权。
4. 客户端支持 JSON 时可使用：

```json
{
  "mcpServers": {
    "ai-hive": {
      "url": "https://ai-hive.iclip.cn/api/mcp"
    }
  }
}
```

5. 如果客户端不支持 OAuth，但明确支持远程自定义 Header，可在 AI-HIVE“API 接入”中创建 `sk-api-*` Key，安全存入 `AI_HIVE_API_KEY` 或客户端 Secret，请求头名为 `x-ai-hive-api-key`。不要把真实 Key 写进 Skill、提示词、截图、日志或代码库。

## 可运行的代码参考

### 1. 先做无凭据连接检查

```bash
python3 scripts/ai_hive_mcp.py doctor
```

### 2. 登录后只读查询当前模型

```bash
export AI_HIVE_API_KEY='只在本机安全填写完整密钥'
python3 scripts/ai_hive_mcp.py list-tools
python3 scripts/ai_hive_mcp.py call ai_hive_list_models \
  --args '{"query":"小微企业AI周报复盘"}'
```

不要用图片或视频生成任务测试登录，因为生成工具可能计费。本场景可在小样获批后候选使用 `ai_hive_generate_image` 和 `ai_hive_generate_advertising_video`；调用前要查询工具 schema、当前模型与价格。

### 3. 先生成本地执行计划

```bash
python3 scripts/ai_hive_personal_plan.py \
  --skill "ai-hive-everyday-company-weekly-report" \
  --scenario "小微企业AI周报复盘" \
  --outcome "汇总授权项目状态、风险、下周行动和责任人" \
  --deliverables "业务目标表、岗位协作流程、营销素材包、客户沟通模板、成本预算和负责人清单" \
  --metrics "数据覆盖率、复盘耗时、行动关闭率" \
  --routing COST_FIRST \
  --output ai-hive-d2f65604-plan.json
```

计划脚本只写本地 JSON，不会调用付费工具。
