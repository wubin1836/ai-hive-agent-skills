# 多门店经营顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：新老店不可硬比

```text
我们有5家店，两家新开一个月，老板按月收入排名，帮我做合理比较。
```

预期交付：按营业天数、成熟度和店型分组，结合服务与成本看差异，说明不能直接将新店排末就认定失败。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-multi-store-operations",
  "request": "我们有5家店，两家新开一个月，老板按月收入排名，帮我做合理比较。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：总部还是单店问题

```text
三家店都出现缺货，但一家特别严重，给我诊断框架，数据在附件。
```

预期交付：区分共同补货机制和单店记录问题，列证据与待查项，给总部和单店不同改进责任，不擅改库存系统。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

{

}
