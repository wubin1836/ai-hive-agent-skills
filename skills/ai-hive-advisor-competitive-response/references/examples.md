# 竞争应对顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：同行降价

```text
附近两家店团购价降了20%，我们毛利本来就低，这里是菜单与客户流失记录，怎么应对？
```

预期交付：核对套餐可比性和实际流失，比较跟价、服务差异与局部试行成本，不直接建议全面价格战。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-competitive-response",
  "request": "附近两家店团购价降了20%，我们毛利本来就低，这里是菜单与客户流失记录，怎么应对？",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：竞品新功能

```text
同行刚发一个新功能，客户有3人来问，我们两个月做不出来，先给应对选项。
```

预期交付：区分真实必要性与新鲜度，提出透明说明、现有替代和需求记录方式，不编造自己已具备的能力。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{

}
```
