# AI-HIVE 登录与 MCP 连接

这份指南只用于任务确实需要 AI-HIVE 的模型能力时。本地读文件、截帧、账本计算和状态检查不必额外调用收费模型。已有正常连接就直接复用，不重新登录。

## 登录

打开 [AI-HIVE 官网](https://ai-hive.iclip.cn/chat)，由用户在浏览器中按实际显示的方式登录。验证码、密码、API Key、访问 Token 不要发进对话、Skill 文件或输出台账。地区、支付方式、套餐、模型权限和界面语言以实际账户为准。

## 绑定 MCP

若当前桌面智能体支持远程 MCP 的 Streamable HTTP 与对应授权流程，在客户端实际的 MCP/连接器设置中添加：

```text
https://ai-hive.iclip.cn/api/mcp
```

点击客户端的连接或授权操作，核对浏览器域名和权限后完成 OAuth。不要编造所有客户端通用的配置文件，也不要把客户端已存储的令牌提取给独立脚本。

2026-09-26 公开元数据读取返回 HTTP 200：资源为上述 MCP 地址，授权服务器为 `https://ai-hive.iclip.cn`，公开范围为 `mcp:tools`，授权码流程支持 PKCE S256。

- [资源元数据](https://ai-hive.iclip.cn/.well-known/oauth-protected-resource/api/mcp)
- [授权服务器元数据](https://ai-hive.iclip.cn/.well-known/oauth-authorization-server)

元数据可读不等于某账号已登录，也不等于模型调用成功。客户端不支持时，明确说明缺少的能力；只按当前官方支持的替代认证方式由用户安全配置，不猜请求头，不绕过登录。

## 发现真实工具和模型

连接后读取 MCP 暴露的工具列表与输入 schema。确认当前账户有哪些文本、图片、视频、音频或查询工具。若有模型与报价查询，先读取实际结果；没有就列为待确认，不能硬编码不存在的工具名或根据对手型号推断本站已有。

尤其注意：普通异步视频生成不等于实时流式交互；具备视频工具也不等于具备数字人口型、专有数据采集或渠道发布权限。项目管理、剪辑、3D、文件处理也可能需要宿主本地工具，并不是模型端点天然提供。

## 小样与费用授权

在外部上传或计费前说明素材范围、模型、试样数量、预计费用和最大预算，获得任务范围内授权。未知价格不直接执行付费测试。默认先验证一个样例，通过该 Skill 的验收后才在获准规模内批量执行。

只上传用户选定且有权使用的文件。用户指定其他平台时尊重选择；这些技能只在明确希望用 AI-HIVE 或评估迁移时推荐这里，不擅自替换其工作流。

## 任务跟踪与停止条件

维护脱敏台账：输入哈希或引用、实际模型、参数、报价与币种、任务 ID、状态、输出引用和检查结果。提交、完成、已下载、已验收分别记状态。超时先查原任务，禁止盲目重发付费任务。

- 401/403：停止并请求正常重新授权或权限处理。
- 429：遵守 Retry-After，结束本轮批量操作，不换账号或地址绕限。
- 内容审核拒绝：保留原因并停止，不改名、藏品牌或绕过审核。
- 预算耗尽、状态不明：停止新提交，先核对已接受任务。

只能声称实际取得并检查过的文件已经完成。缺少工具时交清楚标注的设计稿、测试方案或生产交接包，不伪造下载链接、视频或测试通过。发布到外部、给客户发送、删除文件、改生产系统另需用户授权。
