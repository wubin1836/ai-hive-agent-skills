# 工厂探访视频顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：小工厂拍质量

```text
我们做五金件，只有2小时能拍车间，客户最担心尺寸不稳，帮我选6个镜头。
```

预期交付：围绕来料、加工和测量安排六个证据镜头，列检测记录与安全限制，不通过大场面夸大厂区。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-factory-tour",
  "request": "我们做五金件，只有2小时能拍车间，客户最担心尺寸不稳，帮我选6个镜头。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：工厂不能露客户

```text
做一条60秒工厂探访，不能露订单、客户名称和设备参数，先给路线。
```

预期交付：规划不经过敏感看板的路线和采访问题，列模糊或避拍位置，必要流程图仅作为明确示意。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：
