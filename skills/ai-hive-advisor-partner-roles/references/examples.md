# 合伙分工顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：一人出钱一人运营

```text
我和朋友开工作室，他出钱我运营，目前职责不清，先整理讨论表，不给股权比例。
```

预期交付：分别记录已确认投入与运营职责，列预算批准、客户承诺和僵局议题，不擅自折算股份或认定权益。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-partner-roles",
  "request": "我和朋友开工作室，他出钱我运营，目前职责不清，先整理讨论表，不给股权比例。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：投入时间发生变化

```text
三个合伙人原来都全职，现在一人只能每周做10小时，怎么重谈分工？
```

预期交付：对照现有约定和剩余职责给备选安排，提出投入变化和收益安排待协商议题，不替各方宣布结果。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
}
```
