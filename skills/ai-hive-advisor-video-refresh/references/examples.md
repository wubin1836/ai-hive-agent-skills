# 老视频翻新顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

```text
这条旧教程软件界面换了，按我提供的新录屏判断哪些保留、哪些必须重拍。
```

预期交付：真实界面对照、更新与补录清单。

```json
{
  "skill": "ai-hive-advisor-video-refresh",
  "request": "这条旧教程软件界面换了，按我提供的新录屏判断哪些保留、哪些必须重拍。",
  "external_actions": "未授权，不执行发布、群发或投放",

}
```
