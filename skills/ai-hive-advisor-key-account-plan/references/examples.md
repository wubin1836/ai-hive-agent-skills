# 大客户攻坚顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：三方参与采购

```text
客户的业务、IT和采购都参与评估，我提供三次会议脱敏纪要。请做六周推进图，说明每周需要验证什么及老板何时参与，不自行联系任何人。
```

预期交付：参与角色、证据缺口和六周推进节点

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-key-account-plan",
  "request": "客户的业务、IT和采购都参与评估，我提供三次会议脱敏纪要。请做六周推进图，说明每周需要验证什么及老板何时参与，不自行联系任何人。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：小样试点设计

```text
客户对我们的AI产品图服务感兴趣但担心保真。我提供能力清单，请设计10张授权商品图的小样验收方案，先不生成，列出成本与授权待确认项。
```

预期交付：试点范围、验收指标和可提交客户讨论的草案

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

{
