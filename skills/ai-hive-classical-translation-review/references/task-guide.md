# 专项执行参考

仅供传统文化、学习与娱乐参考，尊重科学；不宣称能够科学预测命运，不作为投资、医疗、法律、婚姻等重大决策依据。

## 资料与交付约定

先确认任务地区/版本/时间范围及输出目录。证据表至少有 source_id、原文件页码或行号、原文、处理值、状态；状态使用 confirmed / uncertain / missing。来源身份与用户隐私不要在公开示例中泄露。

## 本项处理检查

- 按句段对齐原文和译文，建立原文跨度与译文段落的对应关系。
- 检查主体、否定、数量、条件和因果等信息是否被遗漏或擅自增加。
- 对可能涉及古今词义或多种解释的地方标注依据与不确定性。
- 生成带原文位置的Word批注及映射表，人工确认后另存修改版本。

## 示例请求（虚构输入，仅说明调用方式）

请使用我授权提供的资料完成“文言译文漏译与歧义核对助手”。范围先按我的原件与指定版本确认，生成translation-review.docx及其余约定文件，疑点附来源，不自动对外提交。

## 交付验收

- 按实际产物检查文件结构，不能将 Markdown 改后缀冒充 DOCX/XLSX/PDF。
- 公式、金额、日期和图式编码使用脚本或可审查公式复算；模型生成的数字未经复算不能标为已核验。
- DOCX/PDF应渲染检查页码、字体与批注；XLSX回读表头、数据类型和公式；SVG/HTML实际预览。工具缺失则说明哪项视觉/内容验收未完成。
- 缺少输入时交缺件列表，不创建虚构的全套结果来通过核验；仅完成部分时清楚列出已交与未交。

## 专业与使用边界

执行时核验原文和注释版本，用户作答与参考答案不得混成同一来源；歧义不作唯一答案裁定，现代译文使用须有授权。

## 可追溯来源入口

以用户授权的原件、指定版本或当前官方资料为依据；不预设已内置全文或数据库。

具体版本与算法须执行时核验；本轮来源不证明预测效力或提供完整实现。

馆藏目录只证明文献或版本的存在，不构成对民俗预测效力的科学背书。原典、现代整理本、译注和图片各自核对使用权限。
