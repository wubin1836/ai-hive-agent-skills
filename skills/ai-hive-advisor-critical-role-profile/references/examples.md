# 关键岗位画像顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：是否需要运营负责人

```text
我想招运营负责人，用三个月任务和返工记录判断是否真需要专岗，先不写JD。
```

预期交付：瓶颈证据、替代选项和成果能力画像。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-critical-role-profile",
  "request": "我想招运营负责人，用三个月任务和返工记录判断是否真需要专岗，先不写JD。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：关键交付岗

```text
新业务需要交付经理，帮我定义前三个月该证明什么能力，不要列空泛性格词。
```

预期交付：成果、真实任务、行为证据和需要验证的设岗假设。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-critical-role-profile",

}
```
