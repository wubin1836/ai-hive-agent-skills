# 内容到咨询承接顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：咨询被反复问

```text
我们视频带来20次咨询，客户常被客服和顾问重复问行业与需求，帮我设计交接。
```

预期交付：用脱敏记录映射必要字段与负责人，设计一次收集后授权交接的流程，不接入CRM或转发客户资料。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-content-consult-handoff",
  "request": "我们视频带来20次咨询，客户常被客服和顾问重复问行业与需求，帮我设计交接。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：内容承诺跑偏

```text
视频教库存表，来的人却以为能免费做整套咨询，帮我检查开头和首次回复。
```

预期交付：识别免费教学与付费服务边界，修改承诺及回复草稿，明确可获得内容，不以强推课程替代解释。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-content-consult-handoff",
  "request": "视频教库存表，来的人却以为能免费做整套咨询，帮我检查开头和首次回复。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
