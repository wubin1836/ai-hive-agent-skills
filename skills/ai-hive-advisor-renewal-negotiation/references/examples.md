# 续约谈判顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：降价续约

```text
客户年约下月到期要求降20%，按这些真实交付记录准备两个范围调整选项，先别联系客户。
```

预期交付：价值证据、未完成项和两个可承接选项，不承诺折扣。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-renewal-negotiation",
  "request": "客户年约下月到期要求降20%，按这些真实交付记录准备两个范围调整选项，先别联系客户。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：使用不足

```text
客户购买一年但使用很少，续约前先判断该补交付、改套餐还是暂不推进。
```

预期交付：基于使用和合同证据的条件比较及需客户确认的问题。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-renewal-negotiation",
  "request": "客户购买一年但使用很少，续约前先判断该补交付、改套餐还是暂不推进。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 需要生成素材时

按 [MCP 绑定说明](mcp-binding.md) 查询实际工具、模型与参数，用户批准数量和预算后，再按单次调用代码提交并复用任务 ID 查询结果。纯诊断不执行生成步骤。
