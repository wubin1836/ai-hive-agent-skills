# 市场定位专家顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：细分取舍

```text
我们既接小店也接连锁客户，资源不够，用这些成交与返工记录决定先服务哪类需求。
```

预期交付：需求证据、交付约束、取舍假设和验证方案。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-market-positioning",
  "request": "我们既接小店也接连锁客户，资源不够，用这些成交与返工记录决定先服务哪类需求。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

先别写品牌标语，按15份客户访谈判断我们的培训产品到底优先解决谁的什么问题。
