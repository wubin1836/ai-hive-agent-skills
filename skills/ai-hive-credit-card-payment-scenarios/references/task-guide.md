# 专项执行参考

仅供参考，不构成投资建议，不承诺收益，不自动交易。

## 资料与交付约定

先确认任务地区/版本/时间范围及输出目录。证据表至少有 source_id、原文件页码或行号、原文、处理值、状态；状态使用 confirmed / uncertain / missing。来源身份与用户隐私不要在公开示例中泄露。

## 本项处理检查

- 本金、利息、费用与本期应还分别列示，账单日到期日不混淆
- 计息基数、最低还款和分期规则均有适用条款，不明确时不硬算
- 逐期余额与付款勾稽，新增消费按用户假设单列，不默认停止或继续消费

## 示例请求（虚构输入，仅说明调用方式）

仅示例，以下文件名和情境均为假设，不表示已存在真实数据：假设我已提供 示例_信用卡账单.pdf、示例_发卡行适用条款.pdf、示例_还款情景.json。请使用「信用卡还款情景计算器」，按我设定的不同还款金额模拟账单余额与费用；没有明确计息或分期规则的情景先暂停。将结果写入我指定的本地目录，交付 credit-card-payment-scenarios.xlsx、payment-pressure.csv、card-terms-to-confirm.md。本例先离线处理；输入、工具或适用规则不足时先交缺口说明，不编造结果。需要联网更新来源先征得我同意，不登录账户、不代提交或付款。

## 交付验收

- 按实际产物检查文件结构，不能将 Markdown 改后缀冒充 DOCX/XLSX/PDF。
- 公式、金额、日期和图式编码使用脚本或可审查公式复算；模型生成的数字未经复算不能标为已核验。
- DOCX/PDF应渲染检查页码、字体与批注；XLSX回读表头、数据类型和公式；SVG/HTML实际预览。工具缺失则说明哪项视觉/内容验收未完成。
- 缺少输入时交缺件列表，不创建虚构的全套结果来通过核验；仅完成部分时清楚列出已交与未交。

## 专业与使用边界

不是还款或信用决策建议，不保证最低还款可长期维持信用；不引导套现、以卡养卡或延迟履约，困难情况建议联系官方发卡行。
