# 试片审批与正式片复核：交付合同

## 最小交付

1. result.csv 专用结果表，逐条对应输入，不漏失败项。
2. review.md 复核说明：目标、材料范围、实际执行与未执行、证据、结果、返工、下一步。
3. 实际生成/修改的文件与可打开路径；没有工具时明确“仅任务方案，尚未生成”。

| 字段 | 填写约定 |
| --- | --- |
| shot_id | 对应实际的 shot_id 记录；未知写unknown，不编造。 |
| draft_task_id | 对应实际的 draft_task_id 记录；未知写unknown，不编造。 |
| draft_accepted | 对应实际的 draft_accepted 记录；未知写unknown，不编造。 |
| locked_version | 对应实际的 locked_version 记录；未知写unknown，不编造。 |
| final_task_id | 对应实际的 final_task_id 记录；未知写unknown，不编造。 |
| review | 对应实际的 review 记录；未知写unknown，不编造。 |

模板见 assets/result-template.csv。用户自由文本若以等号、加号、减号或@开头，供表格软件导入前按文本处理，避免公式注入；不得因此篡改真正数值含义。

## 专用执行与证据

- 核对当前工具是否提供样片/正式片或可选清晰度；不可用则标为手工两阶段流程
- 用最低满足验收的规格检查动作构图，不承诺按同seed可完美重现
- 通过后冻结提示、参考和参数，再确认正式生成的独立费用
- 比对正式片与批准样片，输出偏离点、版本回执与最终验收记录

## 验收门槛

- 样片批准不等于成片通过
- 两阶段费用分别确认
- 失败先查任务状态不重复下单

每条记录pass/fail/unknown及证据。关键项为fail或unknown，整体标review_required。不存在证据时不补造截图、时间码、回执、评价。

## 验收练习

- 正常路径（虚构）：低清样片通过但高清Logo变形，正式片仍需返工，不可仅做分辨率升级结案。 按步骤记录，再逐条验收，不将示例当真实结果。
- 缺能力：目标模型或外部软件不可用，报告缺项及可先做的本地步骤，不冒用名称称实测。
- 失败：超时、限流、待审，保存任务ID、原因和已完成项；不重建任务、不遗漏失败费用。

## 报告顺序

结论与状态 → 材料和授权 → 参数与执行记录 → 专用结果表 → 证据和未通过项 → 成本耗时（未知说明）→ 需确认的下一步。

创作保留素材授权与生成标记；数据记录来源、时间、口径，不从示例推导真实客户或商业结论。
