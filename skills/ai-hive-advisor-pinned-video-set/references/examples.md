# 视频置顶组合顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：三条置顶怎么选

```text
我能置顶3条，这里有12条库存咨询视频，选一个让老板快速理解服务的组合。
```

预期交付：从身份、案例证据和适配条件挑选互补三条，解释排序与过期风险，不只按播放量选择。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-pinned-video-set",
  "request": "我能置顶3条，这里有12条库存咨询视频，选一个让老板快速理解服务的组合。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：只有一个位置

```text
平台现在只给我1个优先展示位置，个人IP刚起步，5条现有视频该放哪条？
```

预期交付：依据访客首要问题选择一条并说明未覆盖信息如何补充，不强制设计三条置顶或改动账号。
