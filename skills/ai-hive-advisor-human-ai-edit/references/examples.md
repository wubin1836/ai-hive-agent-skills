# 真人与AI混剪顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：知识口播加示意

```text
我有90秒库存口播，想加3段AI仓库示意，不要让人以为是客户仓库，先给混剪方案。
```

预期交付：依语义安排三处示意及标识，保留真人结论和条件，列风格衔接要求，不创建生成任务。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-human-ai-edit",
  "request": "我有90秒库存口播，想加3段AI仓库示意，不要让人以为是客户仓库，先给混剪方案。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：实拍证据不能换

```text
产品视频里有真实承重测试，想用AI画面替换不好看的测试部分，可以怎么处理？
```

预期交付：指出真实测试证据不能由合成效果替代，建议保留关键实拍、重拍或另加明确解释图，不伪造测试画面。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-human-ai-edit",
  "request": "产品视频里有真实承重测试，想用AI画面替换不好看的测试部分，可以怎么处理？",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
