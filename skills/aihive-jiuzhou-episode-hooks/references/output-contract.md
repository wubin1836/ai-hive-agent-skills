# 输出契约

本项：九州文化短剧制作参考｜分集钩子与制片助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `hook-payoff.csv` | episode,opening_question,progress,turn,cliffhanger,payoff_episode |
| `production-needs.csv` | episode,scene,cast,prop,cost_risk,resource_status |
| `schedule-draft.md` | 资源约束、合并机会、未定档期、需要决策 |

## 最小走读示例（纯虚构）

虚构第1集丢失钥匙，第3集必须解释去向；若删除第3集场景，要提示悬念未兑现。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 每个核心悬念有兑现或明确未定
- [ ] 不能凭观看公开剧集照搬情节
- [ ] 不承诺九州发行
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
