# 输出契约

本项：短剧招商方案助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `sponsor-deck-outline.md` | 项目、原创亮点、真实证据、合作方案、限制 |
| `rights-inventory.csv` | right_id,deliverable,quantity,exclusivity,owner,available |
| `scenario-model.csv` | scenario,assumption,source,estimated_range,uncertainty |

## 最小走读示例（纯虚构）

虚构无上线数据的新剧只能展示样片和制作资源，招商页不能写预计播放量为真实流量。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 曝光预测不能称已实现数据
- [ ] 权益不得重复出售冲突排他范围
- [ ] 不承诺保底回报
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
