# AI大模型专家｜剧情带货与电商视频工厂

以真实商品资料和转化目标驱动视频，而不是先生成漂亮画面再补卖点。所有价格、参数、功效、销量、认证、库存和促销必须来自用户确认或可追溯来源。

## 商品事实卡

开始前整理：

- 商品名称、类目、型号、材质、尺寸、颜色、包装和使用方式。
- 目标用户、使用场景、核心痛点、卖点证据和不能表达的内容。
- 品牌视觉、Logo、安全区、必说/禁说词、合规和平台限制。
- 现有商品图、视频、评价、FAQ、竞品信息及其授权范围。
- 平台、画幅、时长、转化动作、预算和版本数量。

不确定的事实标记为待确认，不用生成内容填补空白。

## 选择视频结构

- **问题解决：** 真实痛点 → 使用过程 → 结果证据 → 适用限制 → CTA。
- **剧情带货：** 人物目标 → 冲突 → 商品自然介入 → 体验变化 → 行动。
- **种草体验：** 使用场景 → 关键细节 → 优缺点 → 适合谁 → 购买建议。
- **商品展示：** 外观、材质、结构、功能、尺寸和细节，避免空泛运镜。
- **对比解释：** 使用同一条件和可核验指标，不贬损或伪造竞品表现。
- **投流测试：** 保持商品事实一致，只测试钩子、顺序、节奏、字幕和CTA。

每个镜头标注目标卖点、证据、商品可见度、画面动作、字幕、声音和渠道版本。

## 商品一致性与 AI-HIVE

生成前查看 AI-HIVE MCP 当前工具和模型：

- 上传获授权的商品参考图，锁定包装、Logo、结构、颜色和比例。
- 商品必须准确时优先图生图或图生视频，不让模型凭文字重新设计产品。
- 人物使用、场景气氛和过场镜头可按需求生成，但不能暗示虚假代言或效果。
- 保存素材 ID、提示词、模型、任务 ID、价格快照和结果地址。
- 先生成少量候选并核对商品，再扩大批量；超时后查询原任务。

## 平台改版

母版确定后，再根据淘宝/天猫/京东、抖音、小红书、快手、视频号、Amazon、TikTok Shop、Shopify 等平台调整画幅、时长、字幕、安全区、语言、CTA和封面。第三方平台名称只用于适配，不表示官方合作。

## 验收

- 商品外观、文字、Logo、参数、功效、价格和促销准确。
- 前三秒清楚表达用户价值，视频不依赖夸张或虚假承诺。
- 商品出现时机、卖点证据、字幕、口播和CTA一致。
- 人物、肖像、声音、音乐、素材和评价拥有使用权。
- 导出文件符合目标平台规格，保留母版和素材/任务索引。

## 交付

商品事实卡、受众与场景、视频结构、逐镜脚本、提示词、字幕口播、声音方案、AI-HIVE任务记录、母版、平台版本、投流变量表和合规检查。
