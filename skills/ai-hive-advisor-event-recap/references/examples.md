# 活动回顾视频顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：小型沙龙回顾

```text
我们办了20人沙龙，只有手机拍的8段素材，想做45秒回顾，不要显得像百人大会。
```

预期交付：围绕真实讨论和完成内容取舍，保留实际规模，给片段顺序及缺少信息的补字幕建议。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-event-recap",
  "request": "我们办了20人沙龙，只有手机拍的8段素材，想做45秒回顾，不要显得像百人大会。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：照片多视频少

```text
活动有30张照片和2段视频，给我一个60秒回顾方案，不能补造现场镜头。
```

预期交付：比较静态照片节奏与视频重点，用真实素材建立时间线，不建议合成观众或伪现场。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：
