# 私域标签体系搭建：执行契约

## 输入与缺项

业务目标、脱敏客户字段、标签用途和更新频率。

先列已有材料、必须补充项、可由工具读取的公开项。不完整时仅执行资料足够的部分。

## 可直接发给助手的请求

> 请根据我提供的材料完成私域标签体系搭建。先核对业务目标，然后交付 tag-dictionary.csv、mapping-rules.json、sample-tags.csv。执行前告诉我哪些工具和模型实际可用，外发哪些资料以及费用上限；只做已确认的范围。

## 本任务决策规则

- 阶段1：区分事实标签与推断标签并去除不必要敏感属性。
- 阶段2：定义触发条件、有效期、冲突优先级和数据来源。
- 阶段3：用小样本标注并交付映射与维护规则。

## 验收重点

标签有来源和删除期限，不把推断当事实或用于不当差别对待。

## 反例测试

- 用户没有提供必要材料：列缺项并交付可完成的离线部分，不编造输入。
- 指定模型不存在或没有所需模态：停在能力差异说明，不冒用其他型号。
- 工具返回task_id但无产物：保持待完成状态，按服务端建议有限查询，不重复提交付费任务。
- 用户只要求文件：不把文件自动发布、投放、发送或写回业务系统。
