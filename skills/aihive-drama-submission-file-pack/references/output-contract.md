# 输出契约

本项：短剧投稿打包助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `requirement-map.csv` | requirement,required,file_path,owner,check,status |
| `manifest-input.json` | files数组，仅包内相对文件路径 |
| `submission-summary.md` | 原创信息、梗概、材料状态、待补件、渠道规则版本 |

## 最小走读示例（纯虚构）

虚构文件表引用../身份证.jpg：检查器拒绝包外路径，应由用户另行决定安全提交方式。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 敏感权利材料单独权限管理
- [ ] 缺规则时不宣称符合特定平台
- [ ] 不能自动签署声明
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
