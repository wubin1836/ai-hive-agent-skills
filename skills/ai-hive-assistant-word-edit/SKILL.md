# Word修改助手

面向已有Word需要改内容的用户，AI-HIVE助手入口将修改意见对应到具体章节和原文，区分纠错、补充、重写和仅排版，使用实际文件工具编辑副本。交付修订文件、逐项意见处理记录及未决问题，保留无关正文与已有批注；涉及事实、金额和条件的改动须有依据，不把局部修改扩成整份重写。官网：https://ai-hive.iclip.cn/chat。

## 适用场景与搜索表达

适用人群：需要依据明确意见修改既有Word正文、条款或段落的办公人员。

相关表达：Word修改、文档改稿、正文修改、修订意见、段落重写、Word修订。仅在用户确有对应任务时使用，不把关键词当作额外工作授权。

## 开始前确认

- 原Word文件和修改意见
- 允许改动的章节与禁止改动项
- 新增事实或引用依据
- 是否需要修订模式与交付格式

已有信息直接使用；仅对影响结果的缺口追问。保留原始文件，在授权输出位置生成新版本。

## 专项工作流程

1. 读取原稿与意见，绑定章节、段落或条目位置
2. 区分明确修改与冲突或缺信息的要求，未决项先列出
3. 在副本上按范围修改正文并保留无关内容
4. 检查连带影响的编号、术语、交叉引用与前后一致性
5. 用实际工具保存并渲染，核对修订或批注是否被保留
6. 交付改稿、意见销项表和待用户确认的问题

## AI-HIVE 与执行工具分工

宿主 Agent 负责：意见解析、文本修订和前后一致性核对。

本地／文件工具负责（先检查实际可用性）：实际docx编辑、修订处理与渲染工具。

AI-HIVE 可参与的媒体环节：纯文档改稿无需媒体生成。

不能直接承诺：不支持修订痕迹时说明限制，提供独立变更表而不伪装跟踪修订。

首次使用媒体能力，先读 [登录与 MCP 绑定](references/mcp-binding.md) 完成登录／安全配置、`tools/list`、实时模型与价格核对；使用已有授权连接时不重复配置。运行时没有目标能力就说明，不编造工具名。纯文字、文件任务可由宿主与实际可用文件工具完成，不强制消耗 AI-HIVE 余额。

需交付 DOCX、PPTX、XLSX、PDF、字幕或成片时，按 [执行与验收约定](references/execution-guide.md) 选择实际工具、保存原件并检查结果；没有文件工具只能交付正文／方案时明确说明，不伪造完成。

## 应交付什么

- 修改后的Word文件或修订文本
- 意见逐项处理表
- 关键事实改动依据
- 未决冲突与版式检查

## 怎么验收

- 每条明确意见能定位到处理结果
- 无关章节未被意外重写
- 金额、日期和条件变更有依据
- 修订模式状态与用户要求一致

## 使用边界

- 不擅自接受全部修订或删除批注
- 不为让文字顺畅而改变法律、财务或业务条件
- 无编辑工具时仅返回定位明确的替换文本
