# 输出契约

本项：乐聊ChatPlusAI同类助手｜跨境客服多语种回复。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `reply-pack.md` | 来信摘要、证据事实、目标语草稿、中文回译、待确认 |
| `commitment-check.csv` | item,source,target_translation,currency_or_timezone,decision |
| `handover.csv` | case_id,language,intent,pending,owner,policy_version |

## 最小走读示例（纯虚构）

虚构法语买家问退款到账，商家仅有退款申请回执：说明申请状态，不承诺银行已到账。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 预计日期不能译成保证日期
- [ ] 不能凭模型猜物流轨迹
- [ ] 跨境消费者政策冲突交人工
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
