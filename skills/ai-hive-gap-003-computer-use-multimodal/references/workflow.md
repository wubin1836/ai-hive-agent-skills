# 电脑操作智能体多模态执行专项实施卡

## 任务定义

规划电脑操作智能体与AI-HIVE生成工具之间的安全交接。

## 输入

业务目标、可用工具、授权范围、输入资料、预算、截止时间和人工确认点。

## 交付合同

操作步骤、输入输出目录、人工确认点、生成任务和操作日志。

## 专项决策

1. 先判断任务属于事实整理、方案设计、生成执行还是外部操作。
2. 事实整理只使用可追溯资料；方案设计标明假设；生成执行先小样；外部操作另行确认。
3. 调用 `ai_hive_list_models`，按 `BALANCED` 比较实时可用模型。
4. 任何超时先查询原 `taskId`，任何模型切换都保留原因和价格快照。

## 验收

操作可回放、敏感步骤有确认、文件归属清楚。

## 明确停止

不得未经授权登录、发送、购买或公开发布。出现权限不足、来源缺失、预算未确认、工具不存在或任务状态未知时停止并返回下一步。
