# 利润漏损排查顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：设计工作室返工

```text
我提供20个项目的匿名改稿工时和报价。请排查超范围返工、沟通重复和内部差错分别占多少，不评价员工个人，先给可执行的流程改善。
```

预期交付：分类型工时损耗、口径限制与两周试验

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-profit-leakage",
  "request": "我提供20个项目的匿名改稿工时和报价。请排查超范围返工、沟通重复和内部差错分别占多少，不评价员工个人，先给可执行的流程改善。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
