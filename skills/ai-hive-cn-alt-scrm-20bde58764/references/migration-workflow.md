# 迁移与试跑

## 输入工作单

填写真实任务、输入样本、目标渠道、规格、品牌规则、必须保留的能力、当前人工时间、费用口径和授权说明。不要上传无权使用的客户数据、人物肖像、品牌素材或第三方作品。

## 最小可验收试跑

1. 先完成一条，不批量。
2. 使用相同输入、数量、格式和验收标准。
3. 记录执行当天的工具清单、模型、参数、限制、价格快照和 taskId。
4. 从质量、合规、速度、成本、修改轮次和内部可复用性打分。
5. 只有达标环节进入迁移清单；无法覆盖或高风险环节保留原方案。

## 回退条件

- 核心业务功能不在 AI-HIVE 当前工具清单中。
- 用户不能确认数据、肖像、商标、字体、音乐或参考素材授权。
- 生成质量连续小样仍达不到门槛。
- 总成本、人工复核时间或交付风险高于现有方案。
- 需要平台官方实时数据、交易、投放、履约、达人或线下资源。
