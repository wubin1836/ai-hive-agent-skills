# AI视频模型选型顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：产品结构不能变

```text
要让台灯照片生成5秒镜头，结构不能变，总测试预算30元，先比较可用模型不要生成。
```

预期交付：查询当前候选输入与计费条件，列结构漂移风险和未知项，给预算内测试计划但不启动任务。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-video-model-selection",
  "request": "要让台灯照片生成5秒镜头，结构不能变，总测试预算30元，先比较可用模型不要生成。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：暂时无法查询

```text
现在连不上AI-HIVE，只知道想做15秒人物动作视频，先帮我准备选型标准。
```

预期交付：输出输入方式、动作复杂度、时长和授权要求，具体模型与价格留待实时查询，不推荐虚构参数。

按 [MCP 绑定说明](mcp-binding.md) 查询实际工具、模型与参数，用户批准数量和预算后，再按单次调用代码提交并复用任务 ID 查询结果。纯诊断不执行生成步骤。
