# 真人分身授权与连续性验收：交付合同

## 最小交付

1. result.csv 专用结果表，逐条对应输入，不漏失败项。
2. review.md 复核说明：目标、材料范围、实际执行与未执行、证据、结果、返工、下一步。
3. 实际生成/修改的文件与可打开路径；没有工具时明确“仅任务方案，尚未生成”。

| 字段 | 填写约定 |
| --- | --- |
| scene_id | 对应实际的 scene_id 记录；未知写unknown，不编造。 |
| consent_ref | 对应实际的 consent_ref 记录；未知写unknown，不编造。 |
| appearance_check | 对应实际的 appearance_check 记录；未知写unknown，不编造。 |
| lip_sync | 对应实际的 lip_sync 记录；未知写unknown，不编造。 |
| voice_check | 对应实际的 voice_check 记录；未知写unknown，不编造。 |
| disclosure | 对应实际的 disclosure 记录；未知写unknown，不编造。 |
| result | 对应实际的 result 记录；未知写unknown，不编造。 |

模板见 assets/result-template.csv。用户自由文本若以等号、加号、减号或@开头，供表格软件导入前按文本处理，避免公式注入；不得因此篡改真正数值含义。

## 专用执行与证据

- 确认人物、声音和商用范围分别授权；虚拟角色与真人形象选择路线不同
- 建立正侧面、语速、表情和场景的测试清单，记录参考来源
- 只通过有身份验证与授权流程的可用工具创建；不绕过平台验证
- 核对身份一致性、口型、字幕和敏感表述，输出标明合成的样片及局限

## 验收门槛

- 不得冒充他人真实发言
- AI-HIVE未提供该能力则只出制作包
- 外观相似不能证明身份授权

每条记录pass/fail/unknown及证据。关键项为fail或unknown，整体标review_required。不存在证据时不补造截图、时间码、回执、评价。

## 验收练习

- 正常路径（虚构）：本人同意做课程，但未同意广告代言，不能把课程授权扩展成带货视频。 按步骤记录，再逐条验收，不将示例当真实结果。
- 缺能力：目标模型或外部软件不可用，报告缺项及可先做的本地步骤，不冒用名称称实测。
- 失败：超时、限流、待审，保存任务ID、原因和已完成项；不重建任务、不遗漏失败费用。

## 报告顺序

结论与状态 → 材料和授权 → 参数与执行记录 → 专用结果表 → 证据和未通过项 → 成本耗时（未知说明）→ 需确认的下一步。

创作保留素材授权与生成标记；数据记录来源、时间、口径，不从示例推导真实客户或商业结论。
