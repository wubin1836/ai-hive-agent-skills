# 高速试镜筛选报告：交付合同

## 最小交付

1. result.csv 专用结果表，逐条对应输入，不漏失败项。
2. review.md 复核说明：目标、材料范围、实际执行与未执行、证据、结果、返工、下一步。
3. 实际生成/修改的文件与可打开路径；没有工具时明确“仅任务方案，尚未生成”。

| 字段 | 填写约定 |
| --- | --- |
| variant_id | 对应实际的 variant_id 记录；未知写unknown，不编造。 |
| changed_variable | 对应实际的 changed_variable 记录；未知写unknown，不编造。 |
| visual_review | 对应实际的 visual_review 记录；未知写unknown，不编造。 |
| audio_review | 对应实际的 audio_review 记录；未知写unknown，不编造。 |
| action_review | 对应实际的 action_review 记录；未知写unknown，不编造。 |
| cost | 对应实际的 cost 记录；未知写unknown，不编造。 |
| selected | 对应实际的 selected 记录；未知写unknown，不编造。 |

模板见 assets/result-template.csv。用户自由文本若以等号、加号、减号或@开头，供表格软件导入前按文本处理，避免公式注入；不得因此篡改真正数值含义。

## 专用执行与证据

- 确认工具里的Max与普通H3差别，按当前时长规格限制任务
- 固定创意方向，仅改变一个镜头变量生成获准候选
- 分别评画面、声音和动作，淘汰项说明原因，不只选最好看一条
- 输出入选片、落选清单及转入下一制作环节的规格缺口

## 验收门槛

- 不把高速档当高分辨率档
- 声音与口型需实际听看
- 普通H3旧素材不能称Max实测

每条记录pass/fail/unknown及证据。关键项为fail或unknown，整体标review_required。不存在证据时不补造截图、时间码、回执、评价。

## 验收练习

- 正常路径（虚构）：镜头B画面好但音效错位，应保留为返工候选而非最终选片。 按步骤记录，再逐条验收，不将示例当真实结果。
- 缺能力：目标模型或外部软件不可用，报告缺项及可先做的本地步骤，不冒用名称称实测。
- 失败：超时、限流、待审，保存任务ID、原因和已完成项；不重建任务、不遗漏失败费用。

## 报告顺序

结论与状态 → 材料和授权 → 参数与执行记录 → 专用结果表 → 证据和未通过项 → 成本耗时（未知说明）→ 需确认的下一步。

创作保留素材授权与生成标记；数据记录来源、时间、口径，不从示例推导真实客户或商业结论。
