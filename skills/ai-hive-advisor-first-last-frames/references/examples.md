# 首尾帧设计顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：台灯展开

```text
首帧是折叠台灯，尾帧完全展开，想做5秒视频，帮我检查能否作为同一镜头。
```

预期交付：查看两帧后核对结构和关节变化，检验模型首尾能力，提出拆动作或改帧建议，不保证生成命中。

```json
  "external_actions": "未授权，不执行发布、群发或投放",

}
```

## 场景 2：变化太大

```text
首帧是杯子特写，尾帧是整间咖啡馆，3秒完成，先判断风险不生成。
```
