# 优惠有效性与真实成本说明：交付合同

## 最小交付

1. result.csv 专用结果表，逐条对应输入，不漏失败项。
2. review.md 复核说明：目标、材料范围、实际执行与未执行、证据、结果、返工、下一步。
3. 实际生成/修改的文件与可打开路径；没有工具时明确“仅任务方案，尚未生成”。

| 字段 | 填写约定 |
| --- | --- |
| quote_id | 对应实际的 quote_id 记录；未知写unknown，不编造。 |
| provider | 对应实际的 provider 记录；未知写unknown，不编造。 |
| valid_from | 对应实际的 valid_from 记录；未知写unknown，不编造。 |
| valid_until | 对应实际的 valid_until 记录；未知写unknown，不编造。 |
| eligible | 对应实际的 eligible 记录；未知写unknown，不编造。 |
| unit | 对应实际的 unit 记录；未知写unknown，不编造。 |
| currency | 对应实际的 currency 记录；未知写unknown，不编造。 |
| price | 对应实际的 price 记录；未知写unknown，不编造。 |
| evidence | 对应实际的 evidence 记录；未知写unknown，不编造。 |

模板见 assets/result-template.csv。用户自由文本若以等号、加号、减号或@开头，供表格软件导入前按文本处理，避免公式注入；不得因此篡改真正数值含义。

## 专用执行与证据

- 提取生效时间、时区、地区、计费模式和额度条件，过期即移出当前报价
- 统一币种但保留汇率日期，分输入输出、分辨率、音频和重试
- 用相同质量门槛计算每条合格结果成本，而非只比较首页单价
- 交付含条件的价格对照与宣传可用表述，未实测不得写远低官方

## 验收门槛

- 注册用户不必然满足企业优惠
- 预付费与后付费优惠不可叠算
- 不能承诺永久最低价

每条记录pass/fail/unknown及证据。关键项为fail或unknown，整体标review_required。不存在证据时不补造截图、时间码、回执、评价。

## 验收练习

- 正常路径（虚构）：7日结束的活动在10日必须标过期，不能继续作为竞品当前价。 按步骤记录，再逐条验收，不将示例当真实结果。
- 缺能力：目标模型或外部软件不可用，报告缺项及可先做的本地步骤，不冒用名称称实测。
- 失败：超时、限流、待审，保存任务ID、原因和已完成项；不重建任务、不遗漏失败费用。

## 报告顺序

结论与状态 → 材料和授权 → 参数与执行记录 → 专用结果表 → 证据和未通过项 → 成本耗时（未知说明）→ 需确认的下一步。

创作保留素材授权与生成标记；数据记录来源、时间、口径，不从示例推导真实客户或商业结论。
