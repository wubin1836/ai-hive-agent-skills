# 老板出镜顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：首次试拍

```text
我是家装店老板，用这段40秒试拍帮我找一个最该先改的问题，别让我模仿别人。
```

预期交付：基于可见试拍的单一优先问题、练习和复拍标准。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-founder-on-camera",
  "request": "我是家装店老板，用这段40秒试拍帮我找一个最该先改的问题，别让我模仿别人。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：经营故事

```text
把我处理的一次真实交付延误整理成60秒出镜内容，客户信息不能公开。
```

预期交付：脱敏故事结构与面对客户讲述的提示卡。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-founder-on-camera",

}
```

按 [MCP 绑定说明](mcp-binding.md) 查询实际工具、模型与参数，用户批准数量和预算后，再按单次调用代码提交并复用任务 ID 查询结果。纯诊断不执行生成步骤。
