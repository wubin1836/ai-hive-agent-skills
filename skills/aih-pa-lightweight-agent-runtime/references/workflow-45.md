# 个人Agent接入AI-HIVE助手：执行与验收

## 何时进入此流程

用户实际要完成AI-HIVE个人助理相关任务，且目标包含可核对产物；仅咨询概念时直接解释，不要求连接账户。

## 所需输入

目标客户端、模型用途、数据范围、费用上限。先检查现有材料，非关键缺项可保留unknown；阻断执行的缺项才询问。

## 专用判断规则

只有实际工具发现才算可用；用户网页登录授权，模型ID不得从竞品名字推断。

## 操作逻辑

1. 核验客户端MCP/OAuth支持。

2. 由用户官方登录。

3. 发现实际工具。

4. 选择最小可用任务验证。

## 结果字段与交付

最低交付：接入核对表、能力矩阵、脱敏调用回执。
本流程的领域字段：client, mcp_supported, auth_state, discovered_tool, test_receipt。每个字段附来源；真实未知保持unknown，不为凑齐表格编造数据。可导出为CSV/JSON，但用户只要求一项产物时不额外强制制作无用文件。

对CSV输出，来自用户或网页的文本若以 =、+、-、@ 开头，应按文本安全写出；不要把真正数值转成错误文本或执行公式。

## 工具前提与降级

AI-HIVE网页登录或受支持的远程MCP客户端。有工具才执行对应动作；缺工具可完成本地整理并明确未执行部分。用户只要求方案时不自动开后台任务。
AI-HIVE负责实际可用的模型任务，客户端的文件、浏览器、调度和第三方账号权限单独核验。

## 完成条件

不索要Token，不假设特定模型可用；MCP不自带调度和电脑控制。检查实际输出和来源；关键字段未知或关键验收未过，标review_required，不写“全部完成”。

## 本流程练习（虚构）

输入：客户端不支持远程OAuth MCP。
应有结果：给AI-HIVE网页登录流程，不编造命令或让用户泄露Token。
这个练习用于检查决策边界，不是产品效果实测、真实用户资料或可照抄的任务回执。

## 停止与接管

遇权限不足、身份错配、验证码、额度耗尽或内容审核阻断，保存已完成项并交接；不得改名、换账户或换端点绕过。
对超时的写入或扣费，先查询同一请求是否已经发生，不盲重试。
