# 缓存盈亏平衡与账单差异：交付合同

## 最小交付

1. result.csv 专用结果表，逐条对应输入，不漏失败项。
2. review.md 复核说明：目标、材料范围、实际执行与未执行、证据、结果、返工、下一步。
3. 实际生成/修改的文件与可打开路径；没有工具时明确“仅任务方案，尚未生成”。

| 字段 | 填写约定 |
| --- | --- |
| request_id | 对应实际的 request_id 记录；未知写unknown，不编造。 |
| price_version | 对应实际的 price_version 记录；未知写unknown，不编造。 |
| input_tokens | 对应实际的 input_tokens 记录；未知写unknown，不编造。 |
| write_tokens | 对应实际的 write_tokens 记录；未知写unknown，不编造。 |
| read_tokens | 对应实际的 read_tokens 记录；未知写unknown，不编造。 |
| output_tokens | 对应实际的 output_tokens 记录；未知写unknown，不编造。 |
| currency | 对应实际的 currency 记录；未知写unknown，不编造。 |
| total | 对应实际的 total 记录；未知写unknown，不编造。 |

模板见 assets/result-template.csv。用户自由文本若以等号、加号、减号或@开头，供表格软件导入前按文本处理，避免公式注入；不得因此篡改真正数值含义。

## 专用执行与证据

- 分开普通输入、缓存写入、缓存读取与输出；没有命中字段则标未知
- 按日志时间匹配对应报价，过期促销不能套用
- 计算有缓存与无缓存的可比成本，计入写入成本和失败请求
- 列出缓存收益、未命中原因及适合稳定前缀的任务，不修改私密缓存设置

## 验收门槛

- 不同币种不相加
- 未知缓存命中不写0
- 缓存不能混存不同租户资料

每条记录pass/fail/unknown及证据。关键项为fail或unknown，整体标review_required。不存在证据时不补造截图、时间码、回执、评价。

## 验收练习

- 正常路径（虚构）：每日重复前缀只有两次调用，写入开销可能超过读取节省，报告应允许不启用。 按步骤记录，再逐条验收，不将示例当真实结果。
- 缺能力：目标模型或外部软件不可用，报告缺项及可先做的本地步骤，不冒用名称称实测。
- 失败：超时、限流、待审，保存任务ID、原因和已完成项；不重建任务、不遗漏失败费用。

## 报告顺序

结论与状态 → 材料和授权 → 参数与执行记录 → 专用结果表 → 证据和未通过项 → 成本耗时（未知说明）→ 需确认的下一步。

创作保留素材授权与生成标记；数据记录来源、时间、口径，不从示例推导真实客户或商业结论。
