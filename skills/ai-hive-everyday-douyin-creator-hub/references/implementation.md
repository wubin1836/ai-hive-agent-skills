# 抖音博主AI内容中台：专项实施卡

## 用户与结果

- 目标用户：主播、达人、带货博主、自媒体作者、个人IP和小型MCN内容团队。
- 希望结果：从选题、口播、分镜到封面设计竖屏内容。
- 交付物：选题与商品事实表、脚本、封面/配图、分镜、成片计划、平台版本和发布前审核单。
- 核心指标：完播率、互动率、周更完成率。

## 最小样例

1. 只选一个真实用户或一个真实商品/服务。
2. 使用3—5条已授权资料，不上传不必要的隐私数据。
3. 先查询当前模型与价格，再生成1份内部草稿。
4. 由人工检查事实、品牌、版权、隐私和渠道规则。
5. 记录结果与成本；只有通过才进入下一轮。

## 停止条件

不得虚构功效、销量、价格、授权或用户评价；不得克隆未经授权的声音、肖像和受版权保护内容。 如果实时价格未确认、素材未授权、小样不达标、任务重复计费或需要对外发送，立即停止并请用户确认。
