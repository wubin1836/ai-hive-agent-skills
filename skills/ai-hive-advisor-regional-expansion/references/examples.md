# 区域扩张顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：服务跨城

```text
我们在杭州做设备维护，想比较宁波和绍兴扩张，只有现有客户请求与服务成本数据。
```

预期交付：对比可验证需求和服务距离，列当地支持与管理缺口，给阶段门槛，不补造城市市场规模。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-regional-expansion",
  "request": "我们在杭州做设备维护，想比较宁波和绍兴扩张，只有现有客户请求与服务成本数据。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：暂时不租店

```text
品牌想进入第二个城市，先判断条件，不看店、不联系中介，总投入上限明确。
```

预期交付：梳理复制条件和验证路径，提出投入前证据要求与暂缓信号，不推荐已核实租金或擅自联系资源。
