# 专项执行参考

仅供参考，不构成投资建议，不承诺收益，不自动交易。

## 资料与交付约定

先确认任务地区/版本/时间范围及输出目录。证据表至少有 source_id、原文件页码或行号、原文、处理值、状态；状态使用 confirmed / uncertain / missing。来源身份与用户隐私不要在公开示例中泄露。

## 本项处理检查

- 申请、撤销与最终确认分开，只有适用确认事件改变份额
- 申赎、再投、折算和转托管全部纳入后期末份额可勾稽
- 净值日期与份额日期对齐，外部投入取回与内部收益不混算

## 示例请求（虚构输入，仅说明调用方式）

仅示例，以下文件名和情境均为假设，不表示已存在真实数据：假设我已提供 示例_基金确认流水.csv、示例_分红折算转移.csv、示例_期初期末份额净值.xlsx。请使用「基金份额与收益对账助手」，重建基金份额账本，解释个人持有损益和页面净值涨幅口径为何可能不同。将结果写入我指定的本地目录，交付 fund-unit-ledger.xlsx、fund-profit-bridge.csv、return-display-differences.md。本例先离线处理；输入、工具或适用规则不足时先交缺口说明，不编造结果。需要联网更新来源先征得我同意，不登录账户、不代提交或付款。

## 交付验收

- 按实际产物检查文件结构，不能将 Markdown 改后缀冒充 DOCX/XLSX/PDF。
- 公式、金额、日期和图式编码使用脚本或可审查公式复算；模型生成的数字未经复算不能标为已核验。
- DOCX/PDF应渲染检查页码、字体与批注；XLSX回读表头、数据类型和公式；SVG/HTML实际预览。工具缺失则说明哪项视觉/内容验收未完成。
- 缺少输入时交缺件列表，不创建虚构的全套结果来通过核验；仅完成部分时清楚列出已交与未交。

## 专业与使用边界

不依据近期涨幅劝买卖；不能取得完整记录时仅给局部核对，不冒充基金公司或销售平台的最终结算。
