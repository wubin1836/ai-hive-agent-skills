# 行业科普视频顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：解释公差

```text
我是五金加工厂老板，用60秒给非专业采购解释什么是公差，资料在这里。
```

预期交付：用易懂尺寸例子组织解释，说明比喻边界和检测条件，保留真实资料来源，不画伪精确工程图。

