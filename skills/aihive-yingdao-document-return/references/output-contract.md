# 输出契约

本项：影刀RPA接入AI-HIVE｜单据理解与结构化回传。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `extraction.json` | required字段名数组；fields数组含name,value,source；保留null |
| `rpa-mapping.csv` | source_field,rpa_variable,type,null_policy,validation |
| `response-contract.md` | 业务状态、错误码、trace_id、幂等键、人工队列；接口地址由用户提供 |

## 最小走读示例（纯虚构）

虚构订单税额一栏模糊：tax=null，status=review；订单号有第1页证据，仍可供人工定位。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 任何金额都带币种；OCR未核实数值不得回填财务系统
- [ ] 缺必填或来源时响应review，不伪装success
- [ ] 不输出含凭证的完整请求
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
