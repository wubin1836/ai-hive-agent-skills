# 输出契约

本项：万兴超媒Agent同类｜多媒体短片任务编排助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `task-graph.json` | 分镜、图像、视频、音频、剪辑节点的依赖 |
| `media-index.csv` | asset_id,type,segment_id,task_id,status,path,rights |
| `edit-sheet.csv` | segment_id,start,end,video_asset,audio_asset,caption,transition |

## 最小走读示例（纯虚构）

虚构30秒产品介绍：旁白只有22秒，先调整停顿和镜头，不复制音频补满。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 声音图片视频分别核实工具可用性
- [ ] 任何付费任务先预算确认
- [ ] 计划与已下载素材不能混表称成片
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
