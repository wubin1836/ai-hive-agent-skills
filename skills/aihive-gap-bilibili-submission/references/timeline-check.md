# 时间区间检查

需要检查章节、脚本段落或补录片段时运行。脚本不生成语音、不试听，也不验证媒体真实性。

JSON数组每项包含 `id` 或 `segment_id` 或 `chapter_id`、`start_s`、`end_s`。单位为秒；`source_ref` 指向原字幕行、视频或试读记录。配音补录可加 `actual_duration_s`。

```bash
python3 scripts/cue_check.py assets/cue-demo.json --total 8 --tolerance 0.1 --output cue-review.json
```

输出文件已有时拒绝覆盖。返回0表示时间数值检查通过，1表示存在区间问题，2表示输入／文件错误。检查非负有限时刻、起止顺序、唯一ID、重叠、总时长以及补录是否超出时间槽；允许空隙，默认不允许同轨重叠。若业务需要交叉淡化或多轨，分别检查各轨，再由剪辑工具检查混音。

用户指定时长容差优先。源时码、计划时码和实测时码必须分开标，脚本无法代替这项判断。不要把纯数学通过写成发音、语义、声线授权或成片质量通过。
