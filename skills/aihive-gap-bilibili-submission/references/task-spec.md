# B站投稿文案与章节助手：交付契约

## 任务示例

把我这个8分钟咖啡教程的字幕做成B站投稿包：标题、简介、章节、标签和置顶评论，别替我发布。

## 人工测试场景（不是实际客户案例）

人工测试：00:00开场、00:40研磨、03:20注水、07:10总结，成片共08:00；各章节时码必须落在480秒内，不能编造未出现的拉花章节。

## 反例与停止点

无真实时码时交章节大纲，不用估算时间冒充成片时间。

## 交付字段

### submission-copy.md

标题候选、简介、主题标签、来源致谢与披露。

### chapters.csv

chapter_id,start_s,end_s,title,source_ref。

### publish-checklist.md

内容对应、章节时码、链接、安全隐私与待平台核验项。

字段名是文件契约，不是AI-HIVE工具参数。具体调用仍读实时schema。缺失项保留空值和原因，不把未知填0；CSV供表格打开时防止以 =、+、-、@ 开头的非数值来源文字变成公式。

## 执行证据

交付时附本次输入范围、实际处理工具、输出位置及已检查／未检查项。说明资料来自用户、官方网页还是模型分析。不得把人工示例、待填模板、模型推断写成已发生事实。

如果需要Word／Excel／PPT／音视频成品，检查宿主是否真有对应制作和检查工具；没有就交付当前可完成的中间文件，并列明尚缺的工具。对外发布、发送或系统写入另需对应授权。
