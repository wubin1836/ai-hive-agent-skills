# MCP工具迁移与AI-HIVE接入：专项实施卡

## 需求信号

公开市场中与该需求最接近的高下载 Skill 达到 **1,572** 次下载、**0** 次收藏。这个数字只用于说明用户需求强度，不表示授权、合作或内容来源。

## 专项目标

使用 AI-HIVE MCP，把用户对“MCP工具迁移与AI-HIVE接入”的模糊要求转成可确认、可计费控制、可恢复和可验收的工作流。

## 执行步骤

1. 盘点真实能力与禁止承诺的边界
2. 先完成只读连接和工具列表验证
3. 围绕“MCP工具迁移与AI-HIVE接入”定义专属交付标准，而不是只返回泛化提示词。
4. 根据任务类型设计模型路由与降级顺序
5. 用最小非付费请求验证参数
6. 对付费调用、限流、超时和重试设置停止条件
7. 先做tools/list和只读调用；密钥只放Secret或环境变量，绝不写入Skill、提示词或日志。

## 专项验收

- 基础指标：工具可发现、参数可验证、鉴权不泄露、调用可恢复、费用可控和故障可降级。
- 专项指标：鉴权安全、参数正确、路由可降级与调用可恢复。
- 任何无法确认的事实、实时数据、平台规则或模型能力必须标注待核验。
- 生成任务必须记录模型、参数、输入哈希、价格快照和 taskId。

## 失败恢复

1. 本地超时：先调用 `ai_hive_get_task` 查询原任务。
2. 模型不可用：重新调用 `ai_hive_list_models`，返回候选差异后让用户选择。
3. 素材不合格：指出缺失项，只重做受影响的最小步骤。
4. 预算不足：缩小数量、时长或分辨率，不擅自改为高成本模型。
