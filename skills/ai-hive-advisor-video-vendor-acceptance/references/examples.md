# 视频外包验收顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：格式与字幕验收

```text
外包约定30秒1080×1920含SRT，交了35秒视频和烧录字幕，帮我按约定检查。
```

预期交付：核对实际文件后列时长和SRT缺项，区分格式问题与审美意见，提供明确反馈但不代决定退款。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-video-vendor-acceptance",
  "request": "外包约定30秒1080×1920含SRT，交了35秒视频和烧录字幕，帮我按约定检查。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：只有预览链接打不开

```text
供应商给的预览我打不开，合同和截图在这里，能先做验收意见吗？
```

预期交付：只审核约定与截图可见事项，列待获取原片和文件检查项，不声称已看全片或发现音画错误。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-video-vendor-acceptance",

}
```
