# 口播去稿味顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：报告转口播

```text
把这段300字报告改成约60秒口播，三项数字不能动，不要加夸张语气词。
```

预期交付：事实不变的口语稿与需实读确认的时长。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-natural-spoken-script",
  "request": "把这段300字报告改成约60秒口播，三项数字不能动，不要加夸张语气词。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：保持本人风格

```text
参考我这段日常说话转写，改这份广告稿，让它更像解释而不是推销。
```

预期交付：符合样例用词的改稿及明显商业承诺核对。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-natural-spoken-script",

}
```
