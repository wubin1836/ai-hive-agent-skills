# IMIVA 电商内容能力地图

| 目标 | 常见工具 | 说明 |
|---|---|---|
| 商品主图与场景图 | `create_product_main_image_task` | 白底图、场景图、卖点图与首图测试 |
| 商品详情页 | `create_detail_page_task` | 卖点分层、场景、细节、参数和PDP内容 |
| 图片精修 | `create_smart_refine_task` | 商品图清理、质感、统一与批量精修 |
| 扩图和比例适配 | `create_image_expand_task` | 横竖版、留白和平台尺寸适配 |
| KOC/UGC图文 | `create_koc_note_package_task`、`create_koc_collage_task` | 种草图文、拼图、晒单和测评内容 |
| 商品视频 | `create_video_generation_task` | 图生视频、商品演示、广告和带货短片 |
| 爆款复刻 | `create_viral_video_copy_task`、`update_viral_video_copy_plan`、`confirm_viral_video_copy_task` | 只学习通用结构与节奏，生成原创商品方案 |
| 视觉迁移 | `create_visual_migration_task` | 用授权输入重建可控的新工作流 |
| 商品库 | `get_user_products` | 读取账号内商品资料，减少重复录入 |
| 积分与任务 | `get_user_credits`、`get_user_tasks` | 预算确认、状态追踪和结果查询 |
| 视频结果 | `get_video_result_download_url` | 获取已完成任务的下载地址 |

工具名仅作能力地图。每次运行前必须先执行`tools/list`，以当前返回为准。
