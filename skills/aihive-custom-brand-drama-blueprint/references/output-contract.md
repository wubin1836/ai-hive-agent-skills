# 输出契约

本项：品牌定制短剧助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `brand-drama-brief.md` | 目标、客群、主矛盾、人物变化、制作限制 |
| `integration.csv` | episode,scene,brand_fact,story_reason,exposure,risk |
| `review-gates.md` | 故事、功效、商标、肖像、样片、批准人 |

## 最小走读示例（纯虚构）

虚构旅行箱品牌以搬家故事表达收纳：承重数字必须有检测依据，人物情节可以原创。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 品牌事实和剧情虚构分开
- [ ] 不能暗示明星代言
- [ ] 不把品牌出镜时长当转化保证
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
