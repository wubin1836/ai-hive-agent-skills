# 标题优化助手：具体任务示例

这些是可交给宿主 Agent 的任务请求，不是伪造的 AI-HIVE API。所有示例均需按当前用户范围执行；媒体生成需要另行明确数量和预算。

## 示例 1：知识文章标题

```text
这是讲Excel透视表的文章，原题《提高效率的方法》太空泛，给我8个标题。
```

期望交付：根据正文具体操作给出8个有区别的候选，推荐最匹配的3个，避免编出未测量的十倍效率。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-assistant-title-optimization",
  "request": "这是讲Excel透视表的文章，原题《提高效率的方法》太空泛，给我8个标题。",
  "external_actions": "未授权，不执行发布/投递/群发",
  "media_budget": "未授权，先给方案或询问预算"
}
```

## 示例 2：视频标题不过度承诺

```text
视频教如何整理10平方米出租屋，标题别出现零成本和立刻变大，控制在20字。
```

期望交付：给出场景、问题和步骤导向的短标题，逐一核对字数和正文信息，不使用被排除的夸张表达。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-assistant-title-optimization",
  "request": "视频教如何整理10平方米出租屋，标题别出现零成本和立刻变大，控制在20字。",
  "external_actions": "未授权，不执行发布/投递/群发",
  "media_budget": "未授权，先给方案或询问预算"
}
```

## 有媒体需求时怎么接入

先读 [MCP 绑定说明](mcp-binding.md)。根据任务找到当前真实工具，查询模型与 schema 后创建本地参数文件；不要将上面的任务描述对象误当作工具参数。已授权生成时再执行该说明的单次调用命令，并查询任务状态。纯文字和文件任务不执行这一步。
