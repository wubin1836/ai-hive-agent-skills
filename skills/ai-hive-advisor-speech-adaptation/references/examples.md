# 演讲转短视频顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：只有逐字稿

```text
我有一场40分钟演讲的逐字稿，没有时间码，想做5条60秒视频，可以补录。
```

预期交付：比较每题直接截取与重讲方案，给五个独立论点和补录需求，仅引用稿件位置，不虚构剪点。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-speech-adaptation",
  "request": "我有一场40分钟演讲的逐字稿，没有时间码，想做5条60秒视频，可以补录。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：依赖现场案例

```text
这段演讲只有看PPT才懂，想做两条短视频，不想重新拍整段。
```

预期交付：识别缺失背景，提出补录连接或授权图示方案，列出需要原PPT的证据，不假称已导出视频。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-speech-adaptation",
  "request": "这段演讲只有看PPT才懂，想做两条短视频，不想重新拍整段。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
