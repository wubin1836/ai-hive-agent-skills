# 招聘视频顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：招售后工程师

```text
我们招2名售后工程师，需要出差，薪资含补贴，想做60秒视频让候选人提前了解。
```

预期交付：突出真实出差频率、任务和薪酬构成，列现场镜头及待确认信息，不把补贴包装成无条件底薪。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-hiring-video",
  "request": "我们招2名售后工程师，需要出差，薪资含补贴，想做60秒视频让候选人提前了解。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：办公室不能公开

```text
创业团队招产品经理，不能拍客户看板，也没有员工愿意出镜，给视频结构。
```

预期交付：采用授权工作物件、任务说明和负责人讲解方案，避开客户看板，不生成假员工采访。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-hiring-video",

  "paid_generation": "未授权，先给方案与预算"
}
```
