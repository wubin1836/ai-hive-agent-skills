# 专项执行参考

仅供参考，不构成投资建议，不承诺收益，不自动交易。

## 资料与交付约定

先确认任务地区/版本/时间范围及输出目录。证据表至少有 source_id、原文件页码或行号、原文、处理值、状态；状态使用 confirmed / uncertain / missing。来源身份与用户隐私不要在公开示例中泄露。

## 本项处理检查

- 公告每股或每若干股口径正确换算，登记相关数量有持仓证据
- 送转等数量变动与现金分红分列，到账和税费按同一事项关联
- 税费缺乏持有记录或适用规则时保留未知，不预设统一税率

## 示例请求（虚构输入，仅说明调用方式）

仅示例，以下文件名和情境均为假设，不表示已存在真实数据：假设我已提供 示例_权益实施公告.pdf、示例_登记持仓.csv、示例_分红税费流水.csv。请使用「股票分红到账核对助手」，核对某次股票分红的应计口径与实际到账，分别保留现金和税费记录。将结果写入我指定的本地目录，交付 dividend-receipts.xlsx、dividend-timeline.csv、broker-questions.md。本例先离线处理；输入、工具或适用规则不足时先交缺口说明，不编造结果。需要联网更新来源先征得我同意，不登录账户、不代提交或付款。

## 交付验收

- 按实际产物检查文件结构，不能将 Markdown 改后缀冒充 DOCX/XLSX/PDF。
- 公式、金额、日期和图式编码使用脚本或可审查公式复算；模型生成的数字未经复算不能标为已核验。
- DOCX/PDF应渲染检查页码、字体与批注；XLSX回读表头、数据类型和公式；SVG/HTML实际预览。工具缺失则说明哪项视觉/内容验收未完成。
- 缺少输入时交缺件列表，不创建虚构的全套结果来通过核验；仅完成部分时清楚列出已交与未交。

## 专业与使用边界

不提供抢分红交易策略，不把分红当无风险额外收益；税费依据具体持有记录及当期规则另核验，不预填统一税率。
