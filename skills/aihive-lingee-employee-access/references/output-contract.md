# 输出契约

本项：金蝶灵基同类方案｜企业AI员工权限与交接助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `access-matrix.csv` | role,system,object,read,suggest,execute,approve,expiry |
| `segregation-review.md` | 职责冲突、风险、人工审批人、替代控制 |
| `audit-contract.md` | task_id、操作者、授权依据、对象、时间、回执、保留期 |

## 最小走读示例（纯虚构）

虚构销售AI可读自己客户的报价，只能发起折扣申请；审批由经理完成，不授全客户导出权限。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 默认未授权而非全开
- [ ] 财务敏感动作保持职责分离
- [ ] 旧凭证不随交接包分发
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
