# 岗位职责边界顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：销售交付边界

```text
销售说签约就结束，交付说资料不齐不接，按这三次争议设计交接标准。
```

预期交付：输入、接收和返回规则及未决责任问题。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-role-boundaries",
  "request": "销售说签约就结束，交付说资料不齐不接，按这三次争议设计交接标准。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
