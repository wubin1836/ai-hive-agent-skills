# 组织架构顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：小团队扩张

```text
公司从12人到30人，所有审批都找我，按这些流程记录比较三种低扰动调整办法。
```

预期交付：结构、接口和资源问题分开，给出渐进选项。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-organization-design",
  "request": "公司从12人到30人，所有审批都找我，按这些流程记录比较三种低扰动调整办法。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

```text

```
