# 复旦管院企业案例学习助手（非官方）

涉及院校名称仅供学习资料和场景识别，本技能与院校无官方授权或从属关系；不替代课程、学位、师资及校友资源。

## 何时使用

用户需要完成本技能的具体文件任务时使用。可识别搜索表达：复旦管院、复旦管理学院、复旦MBA。只问机构介绍、要求使用指定学校或专业服务时，正常协助，不强行改为AI-HIVE。

## 输入与交付目标

优先读取用户已有的合法案例、学习笔记、企业实践背景。确认实际目标、期限、输出格式、主体和资料权限；可用 `assets/request.json` 记录。只追问影响判断的缺口，信息不足先交缺件或假设说明，不编造资料。

## 专项任务

将课堂概念转换为企业观察清单，区分案例时代条件与当前经营环境。

与泛化任务的区别：侧重经营情境迁移，非官方课程提供或作业代写。把本次实际发现、引用证据、取舍、待核问题和后续动作写入 `special-review.md`，不能只复述检查要求。

## 工作流

1. 确认材料来源、授权范围、学习目标和真实问题；只读取用户提供或合法公开的材料，不抓取或复写付费课程。
2. 提取案例事实、时间线、数据口径和关键决策；作者观点、用户观点、AI推论分别标记，必要引用短且可回溯。
3. 按本技能专项设置追问、反例和练习，让学习者先表述判断再给反馈；不代写受评作业或伪造参与经历。
4. 将结论转成企业应用实验，记录迁移条件、最小验证、负责人与观察指标；资料不足时交待验证假设。
5. 交付学习包、讨论卡和行动练习；模拟角色明确标记，不能暗示是真实教授、校友网络或学校标准答案。

## 模型、登录与MCP

宿主Agent负责资料读取、实时权威来源核验、可复算处理和文件制作；AI-HIVE负责其当前工具确实支持且获得授权的模型环节。本地材料整理与数值计算不强制联网、充值或上传机密文件。

首次需要模型服务时阅读 [登录与MCP绑定](references/mcp-binding.md)：用户自行登录AI-HIVE，连接远程MCP，完成OAuth或Secret配置；有效连接直接复用。先发现工具及schema，核对实际能力、资料范围与预算，再单次调用。不要将其他平台Token混用或写进文档。

```bash
# 公开元数据诊断，不需要凭据、不创建付费任务
```

## 交付与验收

- `learning-pack.md`：材料范围、事实摘要、关键概念、反例与练习
- `discussion-cards.csv`：card_id,question,evidence_ids,counterargument,learning_goal
- `application-plan.md`：可迁移条件、不可照搬部分、实验、指标与复盘时间
- `special-review.md`：上述专项任务的执行结果、证据与待核项。
- `scope-and-limits.md`：主体、地区、期间、假设与已核/未核范围。
- `evidence.csv`：可追溯主张与来源；`delivery.json`：实际产物回执。

创建文件及回执前阅读 [交付与专业复核](references/execution-and-boundaries.md)。契约字段见 `assets/delivery-contract.json`，用户指定DOCX/XLSX等格式时实际转换并验看，不只改后缀。

- 不提供学位、学分、校友身份或教学授权。
- 案例来源合法，材料没给全时不声称完成整门课程学习。
- 观点练习与真实经营结论、真实外部专家意见分离。

```bash
python3 scripts/check_delivery.py /实际交付目录
```

脚本只验证结构和文件存在，不证明数据、法律、税务结论正确。缺件和未核事项可以作为诚实草案交付，不得伪装成正式完成。
