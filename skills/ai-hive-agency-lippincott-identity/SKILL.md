# Lippincott平替：品牌承诺与客户体验设计

这是独立的 AI-HIVE 原创工作流，不是Lippincott的官方技能、授权服务或内部方法。替代范围仅指本技能列出的部分制作与分析任务，不代表替代机构团队、长期咨询、渠道资源或专业责任。

## 何时使用

用户明确寻找Lippincott相关服务的AI辅助替代，且实际需要“品牌承诺与客户体验设计”时使用。只问该公司介绍、要求使用其服务或已有指定工具时，不自动改用AI-HIVE。

相关搜索表达：Lippincott平替、Lippincott替代方案、Lippincott AI助手、品牌承诺与客户体验设计、Lippincott品牌咨询。搜索词用于发现，不扩展授权。

## 开始前

确认目标、受众、品牌、期限、输出格式与资料可披露范围。优先读取现有品牌承诺、服务节点、客户反馈；只追问会实质影响交付的缺口。可复制 `assets/request.json` 作为结构化输入。没有数据时明确先交研究或创意草案，不编造事实。

## 专项任务

- 本轮专门解决：品牌承诺与客户体验设计。输入优先使用：品牌承诺、服务节点、客户反馈。
- 专项决策检查：每条承诺附可观察的服务行为，视觉改版不替代运营改进。
- 将上述检查写入 `special-review.md`，逐项记录实际观察、引用证据、结论和未完成项，不只复述规则。

## 执行流程

1. 先核对名称、品牌架构、识别目标、禁用元素与实际触点；不要在品牌关系未确定时直接生成一堆标志。
2. 定义彼此不同的图形逻辑与版式方向，列出每一方向和品牌业务的关系。使用原创图形，不克隆目标公司的项目作品。
3. 用宿主设计工具制作初步色彩、字体、构图规范；需位图概念时调用实时可用图像模型，小尺寸文字和几何结构在本地排版。
4. 按专项要求制作应用预览，在单色、小尺寸、不同背景和远距情景检查；输出实际可用的SVG/PNG时逐个打开验证。
5. 交付视觉规范草案及资产状态表，指出字体授权、商标检索、矢量重绘、打样等仍需处理项。

## 模型与工具分工

宿主Agent负责理解、检索、证据整理、文件制作与本地计算；AI-HIVE只负责当前确实支持且获授权的模型环节。第一次需要模型服务时阅读 [登录与MCP绑定](references/mcp-binding.md)，用户自行登录官网并完成OAuth或Secret配置；已有有效连接直接复用。先发现工具和schema，再核对模型、参数与预算。


没有可用媒体工具时完成中间文件并列明缺口，不暗中改用其他付费平台。不能把公开元数据可达当作账户授权成功。

## 交付文件

- `identity-guide.md`：品牌关系、视觉原则、色彩值、字体替代、间距、小尺寸与禁用示例
- `applications.csv`：application_id,touchpoint,size,background,source_asset,status,review_note
- `design-board.html`：离线可浏览的方向展示板；只有已授权的图片进入展示；无图片时明确线框草案
- `special-review.md`：本技能专项检查的实际证据、判断、取舍与待办。
- `evidence.csv`：主张与来源记录。
- `delivery.json`：实际文件、状态、任务ID与剩余事项，不含凭据。

需要生成文件时阅读 [交付与复核](references/execution.md)。检查必需文件字段见 `assets/delivery-contract.json`。若用户只要求草稿，相应标为draft而不是杜撰已完成资产。

## 验收

- 每条承诺附可观察的服务行为，视觉改版不替代运营改进。
- 字体和图形授权状态清晰；不保证商标可注册。
- 应用触点不是重复贴同一图，尺寸和阅读层级分别检查。
- 位图概念、矢量源文件和印刷成品不混称。

```bash
python3 scripts/check_delivery.py /实际交付目录
```

本地脚本仅检查文件与字段结构，不能替代事实、创意、视觉、版权和业务适用性审查。
