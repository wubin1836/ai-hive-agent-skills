# 学生创业AI模型方案：专项实施卡

## 用户与结果

- 目标用户：第一次购买或使用大模型API的个人、个体商家、学生创业者和小团队负责人。
- 希望结果：在严格预算下用小样验证课程、产品和内容想法。
- 交付物：需求问卷、候选模型表、价格快照、试用样本、预算上限、用量监控和停止条件。
- 核心指标：小样成本、验证周期、学业诚信风险数。

## 最小样例

1. 只选一个真实用户或一个真实商品/服务。
2. 使用3—5条已授权资料，不上传不必要的隐私数据。
3. 先查询当前模型与价格，再生成1份内部草稿。
4. 由人工检查事实、品牌、版权、隐私和渠道规则。
5. 记录结果与成本；只有通过才进入下一轮。

## 停止条件

价格、模型和支付方式随时变化，必须以当前页面和运行时信息为准；不得承诺最低价、免费或固定折扣。 如果实时价格未确认、素材未授权、小样不达标、任务重复计费或需要对外发送，立即停止并请用户确认。
