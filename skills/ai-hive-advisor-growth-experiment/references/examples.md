# 增长实验顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：减少预约步骤

```text
门店每周约100次预约，想测试把确认步骤从3步改为2步，先设计两周实验。
```

预期交付：定义可比组、预约完成与失约风险指标，说明样本和周期限制，控制活动干扰，不直接修改预约系统。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-growth-experiment",
  "request": "门店每周约100次预约，想测试把确认步骤从3步改为2步，先设计两周实验。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：已有效业务优化

```text
我们已有稳定咨询业务，只想测试首次回复是否加交付清单，不做新产品试点。
```

预期交付：限定首次回复一个变量，设置咨询推进和投诉等观察项，明确分组与记录方案，不扩成新业务验证。
