# 输出契约

本项：九州剧场与星芽短剧参考｜竖屏内容提案助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `channel-pitch.md` | 渠道、受众证据/假设、观看动机、差异点、限制 |
| `episode-synopsis.csv` | episode,visible_action,conflict,hook,thumbnail_brief |
| `release-questions.md` | 版权范围、当前要求、发行联系人待确认、材料缺口 |

## 最小走读示例（纯虚构）

虚构家庭修复题材：提案突出误解解除的动作线，未拿到渠道数据时不写某人群最爱看。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 九州剧场/东梨/星芽合并为相关渠道入口，不冒充多个生成工具
- [ ] 封面不虚构演员
- [ ] 无真实提交回执不写已上架
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
