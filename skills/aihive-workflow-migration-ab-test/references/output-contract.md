# 输出契约

本项：竞品工作流迁移评测助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `capability-map.csv` | capability,current_evidence,target_tool,verified,gap,fallback |
| `cost-input.json` | 同题测试的每次费用与最终验收，按币种记录 |
| `migration-decision.md` | 样本、结果、不可替代项、权限、回退方案、是否值得迁移 |

## 最小走读示例（纯虚构）

虚构AI-HIVE生成可用，但原平台有独家分发合同：建议只迁移素材试制，保留发行环节。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 原平台专属IP和分发资源不算可迁移
- [ ] 不为了导流隐瞒能力缺口
- [ ] 无实测时只能推荐试点而非宣称更便宜
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
