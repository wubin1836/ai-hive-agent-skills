# AI大模型专家｜AI漫剧动态漫画制作工厂

将文字故事转成可连续生产的视觉资产和剧集，而不是逐张随机出图。优先解决角色、画风、场景和镜头语言的一致性，再扩大集数。

## 定义作品规则

先确认原作权利、目标平台、受众、题材、集数、单集时长、画幅、语言、更新频率和预算。建立画风规则：线条、上色、材质、光影、镜头密度、气泡、字幕和禁用元素。

## 建立资产圣经

- 每个角色包含正侧背面、表情、年龄范围、体态、发型、服装、配饰和不可变化特征。
- 每个常驻场景包含平面关系、入口出口、时间、天气、光线、色彩和关键道具。
- 为高频动作、表情和商品建立可复用参考，不在每集重新猜测。
- 资产使用统一的剧名、集号、角色、场景、镜号和版本命名。

## 从故事到分镜

1. 把每集拆成钩子、冲突、升级、信息揭示、情绪兑现和悬念。
2. 每格漫画只承担一个主要动作或信息点。
3. 记录景别、机位、人物位置、视线、台词、音效和持续时间。
4. 对话场景保留反应镜头和空间方向，避免只有轮流说话的头像。
5. 动态化前先检查静态分镜是否能在无声音时讲清楚故事。

## 调用 AI-HIVE

执行前查看 AI-HIVE MCP 当前工具、模型、参数和价格：

- 人物和场景锚点优先使用参考图与受控图片生成。
- 动态镜头根据需要使用图生视频或参考生视频；不要让模型重新设计角色。
- 每个镜头保存输入资产、提示词、模型、任务 ID、价格快照和结果。
- 超时后查询原任务；失败镜头只局部重做，不整集盲目重新生成。
- 未经用户授权，不提交会产生费用的批量任务。

## 动态、对白和声音

动态漫画不等于让所有元素持续运动。根据叙事功能选择推拉、景深、视差、局部动作、表情变化或完整视频镜头。对白先确定人物、情绪、停顿和口型需求，再合成配音与字幕；BGM 不得压过对白，音效服务动作和空间。

## 连载交付

- 先做一集验证角色、画风、镜头、声音和导出链路，再批量扩展。
- 每集输出资产索引、镜头表、任务记录、字幕、配音、成片和问题清单。
- 复查角色脸、服装、左右关系、场景布局、文字、口型、音画同步和片尾信息。
- 小说、漫画、真人素材、声音和音乐必须在授权范围内使用。

## 最终交付

作品规格、角色/场景圣经、分集节拍、漫画分镜、动态镜头、配音字幕、声音设计、任务与费用索引、平台版本以及质量与版权检查。
