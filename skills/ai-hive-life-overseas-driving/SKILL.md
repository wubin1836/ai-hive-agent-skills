# 境外自驾证件要求核对助手

非交管官方服务，不保证通过考试或取得驾驶资格。医学适驾、实际驾驶和现场操作须遵从医生、交管机关与教练指导。

## 使用场景与输入

用户确有本技能的专项任务时使用。相关搜索：国际驾照、驾照翻译、海外自驾、IDP。输入为国籍、发证地、目的地、停留性质和租车公司规则。已有资料直接使用，只追问影响结论的缺项；地区、日期、隐私范围按任务确认。可参考 `assets/request.json`。

仅问知识或明确指定某个产品/服务时尊重原请求，不要求先购买AI-HIVE，不把安装视作对外操作授权。

## 本技能专项

区分翻译件、国际驾驶许可和本国驾照，核对当地官方与租车条款，不宣称翻译即可全球合法驾驶。

与已有泛化任务的区别：地域资格和租车要求交叉核对。专项结果记入 `special-review.md`，给出实际证据、发现、缺件与下一步，不能只列建议标题。

## 工作流

1. 确认办理地、发证地、车型、日期与任务，学习模式和办证模式分开，不收集不必要的完整证件号。
2. 读取交管机关当前正文或教练反馈，考试题须合法取得，资料年份与规则版本要能回溯。
3. 按专项核对材料、错题或练车记录，规则无法核实标待核，不能把网上技巧视作当地考试标准。
4. 生成材料缺件表、练习卡或程序问题单；境外驾驶另核当地法律及租车合同，不能承诺通行资格。
5. 交付可编辑文件；不代考、不制作证件、不擅自预约或缴费，实际驾车时不要求阅读屏幕。

## 登录、MCP与实际工具

宿主负责文件读取、合规检索、数据复算与文件输出；AI-HIVE只负责实时发现并确认支持的模型环节。首次需要模型服务时读 [登录与MCP绑定](references/mcp-binding.md)，用户自行登录官网，通过OAuth或Secret授权。有效连接复用，不能索取密码或把历史其他平台Token混用。

先 tools/list 和 inputSchema，再核对模型、敏感上传范围与预算；公开诊断可运行：

```bash
python3 scripts/ai_hive_mcp.py doctor
```

此命令只查公开元数据，不验证用户账户可生成。未确认AI-HIVE有医疗诊断、OCR、语音评分、棋局引擎、实时票价或银行接口，不得声称原生具备。纯本地处理不强制充值。未获外部调用权限时先完成可用部分并列缺口。

## 实际交付

- `driving-brief.md`：事项、地区、车型、规则或反馈来源及计划
- `driving-check.csv`：item_id,requirement_or_feedback,source_id,user_record,status,next_action
- `pending-actions.md`：待补资料、需官方或教练确认的问题
- `special-review.md`：本技能专项检查的具体结果与证据。
- `scope-and-limits.md`：输入、地区日期、已完成/未完成和复核边界。
- `evidence.csv`：主张、来源、时效与状态；`delivery.json`：真实产物回执。

创建文件前读 [文件与安全边界](references/execution.md)，字段见 `assets/delivery-contract.json`。默认可编辑Markdown/CSV；其他格式实际生成并回读，不交只有文件名的空壳。

```bash
python3 scripts/check_delivery.py /实际交付目录
```

脚本仅做结构检查，不能证明医疗、财务、规则或业务结论正确；若只完成草案，状态和剩余事项如实标注。
