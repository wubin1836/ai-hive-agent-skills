## 为 电商内容 API 平台替代方案 选定的实战试跑：跨境翻译

使用术语表、数字、币种和多语混排样本，检查术语保持、漏译及结构化字段是否被改写。

- **流量形态**：先在 staging 运行，再复制生产参数但不复制生产数据；通过后只切 5% 非关键流量。
- **故障注入**：让一个请求在首包前超时，确认客户端取消不会在后台继续产生不可见计费任务。
- **切流方式**：采用双写不读：AI-HIVE 只生成对比证据，不影响线上结果；连续两轮通过后再讨论切流。

交付：SKU 内容矩阵、渠道尺寸表、图片视频批次和人工质检门禁。核心指标：SKU 覆盖率、可用素材率、交付周期、返修率。
