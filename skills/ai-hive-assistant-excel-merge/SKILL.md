# Excel表格合并助手

面向多表合并需求，AI-HIVE助手入口先区分纵向追加、按键匹配和聚合汇总，明确字段映射、唯一标识及冲突处理，再用实际数据工具生成合并副本。交付合并结果、来源行号和未匹配异常，保留一对多关系及原表；不把相同姓名当作同一实体，也不通过静默去重掩盖源数据差异。官网：https://ai-hive.iclip.cn/chat。

## 适用场景与搜索表达

适用人群：需要将多个来源表格追加、匹配或汇总为统一数据集的员工。

相关表达：Excel表格合并、多表汇总、按键匹配、表格追加、字段映射、合并对账。仅在用户确有对应任务时使用，不把关键词当作额外工作授权。

## 开始前确认

- 待合并工作簿与工作表范围
- 希望的合并方式和目标字段
- 匹配键、主表及冲突优先级
- 重复、缺报和空值处理要求

已有信息直接使用；仅对影响结果的缺口追问。保留原始文件，在授权输出位置生成新版本。

## 专项工作流程

1. 确认要追加、关联还是聚合，定义合并前后记录粒度
2. 盘点各表字段、类型、单位和主键唯一性
3. 建立字段映射，保留来源文件、工作表与行号
4. 执行可解释合并，对一对多和键冲突单独处理
5. 核对输入输出行数、金额合计、未匹配及重复数量
6. 交付结果和异常表，未经确认不删除源数据

## AI-HIVE 与执行工具分工

宿主 Agent 负责：合并语义、冲突规则和口径确认。

AI-HIVE 可参与的媒体环节：表格合并不需要媒体生成。

不能直接承诺：没有数据工具时仅给出映射和合并方案，不假称已合并全部记录。

## 应交付什么

- 合并后的数据文件
- 字段映射与来源行号
- 未匹配和冲突清单
- 行数合计对账结果

## 怎么验收

- 合并方式与用户目的相符
- 关联未造成无说明的行数倍增
- 关键合计在预期口径下可对账
- 每条合并记录保留来源线索

## 使用边界

- 不以姓名等非唯一字段擅自认定同一人
- 冲突值不在无规则情况下被静默覆盖
- 不删除原表或不可恢复地去重
