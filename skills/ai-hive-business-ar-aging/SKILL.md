# 应收账款账龄核对助手

这是企业材料、流程与模型辅助工作流，不是持证专业服务、法定公司机构或实际代办。

## 何时使用

用户需要完成本技能的具体文件任务时使用。可识别搜索表达：账龄分析、应收账款、坏账准备、逾期款。只问机构介绍、要求使用指定学校或专业服务时，正常协助，不强行改为AI-HIVE。

## 输入与交付目标

优先读取用户已有的发票、合同到期日、收款记录、账龄口径。确认实际目标、期限、输出格式、主体和资料权限；可用 `assets/request.json` 记录。只追问影响判断的缺口，信息不足先交缺件或假设说明，不编造资料。

## 专项任务

分开开票龄与逾期龄，回款分配需证据；坏账会计估计由会计复核。

与泛化任务的区别：到账匹配与账龄口径，不代替催款话术。把本次实际发现、引用证据、取舍、待核问题和后续动作写入 `special-review.md`，不能只复述检查要求。

## 工作流

1. 确认主体、期间、币种、单位、合并范围及会计政策，先读原始报表列定义并保留原件。
2. 核对数据完整性、重复、正负号和时点；用本地表格或代码做可复算匹配，AI只解释不得凭空更改数字。
3. 按专项建立差异与情景表，区分实际、预测、估计和假设；缺失数据标缺失，不填零掩盖。
4. 为异常关联原始凭证和待核负责人；模糊匹配、税务认定和会计调整需要会计人员复核。
5. 交付分析明细、复算说明与管理建议；不记入正式账套、不支付、不申报，不声称审计或鉴证。

## 模型、登录与MCP

宿主Agent负责资料读取、实时权威来源核验、可复算处理和文件制作；AI-HIVE负责其当前工具确实支持且获得授权的模型环节。本地材料整理与数值计算不强制联网、充值或上传机密文件。

首次需要模型服务时阅读 [登录与MCP绑定](references/mcp-binding.md)：用户自行登录AI-HIVE，连接远程MCP，完成OAuth或Secret配置；有效连接直接复用。先发现工具及schema，核对实际能力、资料范围与预算，再单次调用。不要将其他平台Token混用或写进文档。


## 交付与验收

- `finance-brief.md`：数据范围、口径、核对结果、情景与限制
- `reconciliation.csv`：row_id,metric,period,source_value,comparison_value,difference,evidence_ids,status
- `calculation-notes.md`：计算规则、假设、异常处理、复核问题与未完成项
- `special-review.md`：上述专项任务的执行结果、证据与待核项。
- `scope-and-limits.md`：主体、地区、期间、假设与已核/未核范围。
- `evidence.csv`：可追溯主张与来源；`delivery.json`：实际产物回执。
- `rule-register.csv`：适用规则、官方正文来源、时效和核实状态；无法核验标待核。

创建文件及回执前阅读 [交付与专业复核](references/execution-and-boundaries.md)。契约字段见 `assets/delivery-contract.json`，用户指定DOCX/XLSX等格式时实际转换并验看，不只改后缀。

- 每项金额和比例可回到原始数据与公式。
- 假设、实际、现金、利润、税额不混用。
- 差异不自动定性欺诈或违法，未经确认不改账。

```bash
python3 scripts/check_delivery.py /实际交付目录
```

脚本只验证结构和文件存在，不证明数据、法律、税务结论正确。缺件和未核事项可以作为诚实草案交付，不得伪装成正式完成。
