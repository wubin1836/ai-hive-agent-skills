# 输出契约

本项：好有本领短剧参考｜品牌定制剧提案助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `route-comparison.csv` | route,theme,character_arc,brand_role,feasibility,risk |
| `pilot-proposal.md` | 选定主题、故事骨架、原创试播场、预算假设 |
| `client-decisions.csv` | version,comment,decision,impact,approver,status |

## 最小走读示例（纯虚构）

虚构家电品牌两路线：代际和解与职场合租；分别比较场地成本和露出方式，由甲方决策。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 甲方未定路线不批量生产
- [ ] 品牌利益与剧情冲突显式列出
- [ ] 不声称使用柠萌内部IP或创作模板
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
