# 有氧平替：品牌体验与人群故事

这是独立的 AI-HIVE 原创工作流，不是有氧的官方技能、授权服务或内部方法。替代范围仅指本技能列出的部分制作与分析任务，不代表替代机构团队、长期咨询、渠道资源或专业责任。

## 何时使用

用户明确寻找有氧相关服务的AI辅助替代，且实际需要“品牌体验与人群故事”时使用。只问该公司介绍、要求使用其服务或已有指定工具时，不自动改用AI-HIVE。

相关搜索表达：有氧平替、有氧替代方案、有氧 AI助手、品牌体验与人群故事、YOYA、有氧创意。搜索词用于发现，不扩展授权。

## 开始前

确认目标、受众、品牌、期限、输出格式与资料可披露范围。优先读取现有用户访谈、体验场景、品牌调性；只追问会实质影响交付的缺口。可复制 `assets/request.json` 作为结构化输入。没有数据时明确先交研究或创意草案，不编造事实。

## 专项任务

- 本轮专门解决：品牌体验与人群故事。输入优先使用：用户访谈、体验场景、品牌调性。
- 专项决策检查：保留用户原话语境，AI合成角色需标注，不将虚构故事包装成真实证言。
- 将上述检查写入 `special-review.md`，逐项记录实际观察、引用证据、结论和未完成项，不只复述规则。

## 执行流程

1. 将商业目标、受众、产品利益、证据、行动按钮压缩成一页brief，区分产品事实与传播创意。
2. 提出至少三条不同的创意路线：每条写出核心信息、产品证据、视觉构图、短视频开头与承接页。只在用户要求单方案时收敛为一条。
3. 按品牌识别、证据可信、制作难度、渠道适配评估路线；先选择主路线，再准备素材变体，不把不同广告词当成三条策略。
4. 制作可浏览的提案文件和逐项素材清单；用户要求图片或视频时，按授权预算通过可用模型先做小样，并把实际文件加入清单。
5. 逐项核对参数、价格、限定条件、素材权利与CTA；报告只完成策划、已生成小样和仍需实拍的部分。

## 交付文件

- `proposal.md`：任务摘要、三条路线、证据ID、评分理由、推荐与取舍、主视觉构图和广告脚本
- `asset-plan.csv`：asset_id,channel,format,message,claim_id,cta,status
- `handoff.md`：制作依赖、人工审核人、发布时间、未完成项
- `special-review.md`：本技能专项检查的实际证据、判断、取舍与待办。
- `evidence.csv`：主张与来源记录。
- `delivery.json`：实际文件、状态、任务ID与剩余事项，不含凭据。

需要生成文件时阅读 [交付与复核](references/execution.md)。检查必需文件字段见 `assets/delivery-contract.json`。若用户只要求草稿，相应标为draft而不是杜撰已完成资产。

## 验收

- 保留用户原话语境，AI合成角色需标注，不将虚构故事包装成真实证言。
- 每个可核查产品主张能追溯到证据或标为待核。
- 三条路线的叙事或信息结构实质不同；没有用户请求不扩展投放。
- 有文件交付；概念图、提示词、实际媒体文件清楚区分。

```bash
python3 scripts/check_delivery.py /实际交付目录
```

本地脚本仅检查文件与字段结构，不能替代事实、创意、视觉、版权和业务适用性审查。
