# 输出契约

本项：AI漫剧返工定位助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `rework-tickets.csv` | ticket,version,timecode,criterion,root_cause,affected_assets,owner |
| `task-graph.json` | 返修依赖节点，明确人工批准节点 |
| `retest.md` | 最小修复、预算、样本结果、未解决项、可关闭依据 |

## 最小走读示例（纯虚构）

虚构字幕错字但画面合格：改字幕导出即可，不重跑昂贵视频生成。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 无关资产不重生成
- [ ] 反馈与美学偏好分别记录
- [ ] 未经预算批准不批量返修
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
