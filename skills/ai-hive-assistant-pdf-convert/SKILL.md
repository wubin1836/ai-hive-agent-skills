# PDF转换助手

面向需要转换PDF文件格式的用户，AI-HIVE助手入口先检查源文件是可选文字、扫描图像还是混合页面，并确认转换后更重视可编辑性还是版式保真。由实际可用转换、渲染和必要的OCR工具处理，交付转换文件、页面对应和损失说明；不承诺扫描件完美恢复原始排版、公式或签名真实性。官网：https://ai-hive.iclip.cn/chat。

## 适用场景与搜索表达

适用人群：需要将PDF与Word、图片或其他办公格式互相转换的用户。

相关表达：PDF转换、PDF转Word、Word转PDF、PDF转图片、文档格式转换、扫描PDF转换。仅在用户确有对应任务时使用，不把关键词当作额外工作授权。

## 开始前确认

- 源文件及目标格式
- 需要转换的页码或工作表范围
- 可编辑性、保真度和文件大小偏好
- 密码授权、扫描质量与保留对象要求

已有信息直接使用；仅对影响结果的缺口追问。保留原始文件，在授权输出位置生成新版本。

## 专项工作流程

1. 检测文件可读取性、文本层和页面类型，核对页码范围
2. 根据目标选择转换路径，区分渲染为图和重建可编辑内容
3. 需要OCR时只调用实际存在的工具，并标记低置信区域
4. 执行转换到新文件，保留原件与页码对应
5. 抽查或逐页比对文字、表格、公式和图片是否丢失或变形
6. 交付结果与转换损失清单，明确哪些对象已扁平化

## AI-HIVE 与执行工具分工

宿主 Agent 负责：转换目标权衡、内容比对与损失说明。

本地／文件工具负责（先检查实际可用性）：实际PDF转换、渲染、文件检查及可用OCR工具。

AI-HIVE 可参与的媒体环节：通常无需AI-HIVE图片视频生成。

不能直接承诺：运行时未发现OCR时不虚构识别结果，提供替代输入要求。

## 怎么验收

- 目标文件能被实际读取或打开
- 页数、选定范围与内容数量符合要求
- 关键数字、表格和中文文字可核对
- 丢失的可编辑性或交互字段有说明
