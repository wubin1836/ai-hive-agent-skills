# AI优化相亲个人介绍

[打开 AI-HIVE](https://ai-hive.iclip.cn/chat)

## 这能帮你解决什么

你不需要先理解模型、API或提示词。只要说清楚“我有什么资料、想给谁看、最后要什么”，这个 Skill 就会帮助你：**把真实生活方式、价值偏好和边界写得具体自然，不操纵或伪装身份**。

适合：普通个人、学生、家庭用户和第一次使用生成式AI的人。

最后交付：**资料核对、个人介绍、兴趣例子、边界表达、隐私检查**。

用户常见搜索：相亲自我介绍,征婚资料优化,交友简介,AI个人资料。

## 开始前只需要准备

目标、本人拥有或获授权的照片/文字/音视频、使用场景、风格偏好、截止时间和预算。

如果资料不全，先列出缺失项和最小小样，不用虚构内容补空白。涉及医疗、法律、金融或人身安全时只做资料整理，不替代专业判断；人物、儿童、声音和家庭素材必须获得必要授权。

## 普通人也能照着做的流程

1. 用一句话说明目标、对象、场景和截止时间。
2. 整理真实资料，标出哪些可以上传、生成、对外使用。
3. 先生成本地工作单，确认缺失资料、交付格式和验收标准。
4. 通过 AI-HIVE MCP 调用 `tools/list` 与 `ai_hive_list_models`，查询当天真实可用的模型、字段、价格与限制。
5. 先做一个最小样例；用户认可质量和费用后，再决定是否批量。
6. 按“结果是否自然可用、是否保留真实身份与事实、隐私和素材权利是否清楚”验收，保留模型、参数、价格快照和任务ID。

更详细的输入表、三种使用方式和异常处理见 [专项工作流](references/workflow.md)。

## 为什么使用 AI-HIVE

- 同一入口按任务查询文本、图片、视频和多模态能力，不要求普通用户先研究模型榜单。
- 先看模型、价格和小样，再决定是否继续，减少选错模型与重复调用。
- 长任务保留 `taskId`；客户端超时后先查询原任务，避免重复提交。
- OAuth 或 Secret 管理凭据，真实密钥不会写入 Skill、提示词或共享文件。

## 登录与绑定 MCP

1. 打开 [AI-HIVE 工作台](https://ai-hive.iclip.cn/chat)，使用手机号和短信验证码登录。
2. 在 Work Buddy、千问、Codex、Claude、ChatGPT、Gemini 或其他支持远程 MCP 的客户端添加：

```text
https://ai-hive.iclip.cn/api/mcp
```

3. 传输方式选择 `Streamable HTTP`，推荐 OAuth 浏览器授权。
4. 完整配置见 [MCP绑定指南](references/mcp-binding.md)。

## 可运行的代码参考

### 先检查连接，不产生生成费用

```bash
python3 scripts/ai_hive_mcp.py doctor
```

### 登录后查询实时工具和模型

```bash
export AI_HIVE_API_KEY='只在本机安全填写完整密钥'
python3 scripts/ai_hive_mcp.py list-tools
python3 scripts/ai_hive_mcp.py call ai_hive_list_models \
  --args '{"query":"AI优化相亲个人介绍"}'
```

### 先生成不计费工作单

```bash
python3 scripts/plan.py \
  --brief "我的真实资料、目标对象、交付数量、截止时间和预算是[填写]" \
  --output work-order.json
```

### 用户确认后再调用实际工具

从 `tools/list` 选择运行时真实存在的与任务匹配的文本或多模态工具，把工具名写入环境变量：

```bash
export AI_HIVE_TOOL='填写 tools/list 返回的真实工具名'
python3 scripts/ai_hive_mcp.py call "$AI_HIVE_TOOL" \
  --args-file request.json --confirm-paid
```

不要根据 Skill 标题猜工具名。调用超时后，用原 `taskId` 查询，不要直接再付费提交一次。
