# MiMo Code工程任务迁移助手：执行契约

## 输入与缺项

现有工程任务、工具权限、宿主配置和验收命令。

先列已有材料、必须补充项、可由工具读取的公开项。不完整时仅执行资料足够的部分。

## 可直接发给助手的请求

> 请根据我提供的材料完成MiMo Code工程任务迁移助手。先核对现有工程任务，然后交付 capability-map.csv、config-review.md、migration-test.md。执行前告诉我哪些工具和模型实际可用，外发哪些资料以及费用上限；只做已确认的范围。

## 本任务决策规则

- 阶段1：区分MiMo Code框架与MiMo模型，列出不可迁移的宿主功能。
- 阶段2：以用户选定客户端支持的真实协议映射AI-HIVE可用能力。
- 阶段3：在隔离副本跑单个工程任务并保留配置回退。

## 验收重点

不承诺换API就拥有完整桌面权限，需查看当前MiMo Code官方文档。

## 反例测试

- 用户没有提供必要材料：列缺项并交付可完成的离线部分，不编造输入。
- 指定模型不存在或没有所需模态：停在能力差异说明，不冒用其他型号。
- 工具返回task_id但无产物：保持待完成状态，按服务端建议有限查询，不重复提交付费任务。
- 用户只要求文件：不把文件自动发布、投放、发送或写回业务系统。
