# 客户分层顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：服务工时差异很大

```text
假设我有80位客户，附表含近6个月金额和服务工时。请设计3层客户管理规则，不能削减已购买的服务。
```

预期交付：综合贡献与服务成本分层，单列缺数据客户并解释边界个案。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-customer-tiering",
  "request": "假设我有80位客户，附表含近6个月金额和服务工时。请设计3层客户管理规则，不能削减已购买的服务。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：新客户资料不足

```text
假设20位新客户只有首次订单，不清楚复购潜力。请设计临时分层与30天复核规则，不把他们全放最低层。
```

预期交付：以可观察行为设暂定层和补证步骤，不推断未知消费能力。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

}
