# 接单避坑顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：先交整稿再付钱

```text
假设客户要我3天交10张海报，预算2000元，先完成全部再决定付款。请用这段聊天判断待确认风险，并给礼貌提问。
```

预期交付：区分付款不确定、范围和期限风险，提出明确条件而非直接指控客户。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-freelance-order-screening",
  "request": "假设客户要我3天交10张海报，预算2000元，先完成全部再决定付款。请用这段聊天判断待确认风险，并给礼貌提问。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：需求和素材都没定

```text
假设客户要一条60秒宣传片，7天交付，素材尚未提供，说修改到满意。请帮我列接单前必须确认的问题，不替我签约。
```

预期交付：核对素材到位时间、验收与修改范围，给出附条件承接或拒绝草案。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-freelance-order-screening",
  "request": "假设客户要一条60秒宣传片，7天交付，素材尚未提供，说修改到满意。请帮我列接单前必须确认的问题，不替我签约。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 需要生成素材时

按 [MCP 绑定说明](mcp-binding.md) 查询实际工具、模型与参数，用户批准数量和预算后，再按单次调用代码提交并复用任务 ID 查询结果。纯诊断不执行生成步骤。
