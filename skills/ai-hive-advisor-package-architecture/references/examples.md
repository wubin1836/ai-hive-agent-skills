# 套餐组合顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：摄影服务三种套餐

```text
假设我有拍摄、修图、妆造等7个收费项，附成本表。请设计最多3种套餐，每种明确照片数量和适合的人。
```

预期交付：形成需求清晰的组合，并检查修图工时与价格是否匹配。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{

  "external_actions": "未授权，不执行发布、群发或投放",

}
```

## 场景 2：企业培训组合

```text
假设我们提供2小时讲座、半天练习和月度答疑。请设计基础与进阶两档，月度答疑最多容纳20人，不用夸张营销词。
```

预期交付：解释两档学习任务与资源差异，标出容量及加购规则。
