# 分镜一致性顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：外套颜色跳变

```text
这4个关键帧里主人公外套颜色不同，故事设定同一天，帮我排修改优先级。
```

预期交付：实际查看后建立服饰基准，区分色温偏差与衣服变化，给修帧或改分镜建议，不自动重新生成。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-shot-continuity",
  "request": "这4个关键帧里主人公外套颜色不同，故事设定同一天，帮我排修改优先级。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：产品位置不连续

```text
三个镜头拍同一盏灯，但按钮和电线位置不一致，先做连续性检查。
```

预期交付：对照真实产品参考标出关键结构冲突，优先修商品准确性，说明未提供原片时只能检查关键帧。
