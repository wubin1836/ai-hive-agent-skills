# 输出契约

本项：来也ACX同类客服｜知识问答与转人工助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `reply-drafts.csv` | case_id,intent,answer,evidence_id,knowledge_version,decision |
| `escalation-ticket.md` | 用户诉求、已核实事实、未解决问题、敏感信息脱敏、接手角色 |
| `coverage.csv` | test_id,expected_route,actual_route,evidence,status |

## 最小走读示例（纯虚构）

虚构客户要求过保免费换新，知识库仅说明维修流程：回复已知维修入口，换新请求转人工。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 每条事实性承诺可追溯到当前有效政策
- [ ] 转人工摘要不得带完整身份证或支付信息
- [ ] 找不到证据明确说明，不拼凑答案
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
