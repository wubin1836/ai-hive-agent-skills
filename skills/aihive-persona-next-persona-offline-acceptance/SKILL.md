# 知识分身上线前离线验收包

## 适用任务

完成“知识分身上线前离线验收包”这一具体文件工作流。基于用户自己的资料和权限处理，不调用未经确认的渠道、生产系统或收费服务。

## 先确认材料

- 拟上线分身规则
- 许可台账、工具清单和少量合法测试资料

只问缺少且影响结果的输入。资料不足列待补项；已有账号和模型偏好则复用，不强制注册、充值或迁移。

## 执行

1. 阅读 [来源与范围](references/source-and-scope.md)，为实际材料建立 source_id。保留出处位置、日期及使用权限；区分原作者说法、用户事实、模型推理和未知项。
2. 按事实引用、无资料、过期信息、权限、预算与工具不可用构造离线用例。
3. 执行可在本地验证的文件检查，模型或渠道测试需另授权并逐项区分设计、已跑、通过和失败。
4. 按 [交付字段与试跑](references/deliverables-and-tests.md) 输出可检查的小样。用计算或文件工具复核数字、单位、引用和文件格式；用户要求扩展且预算允许时才批量。

## AI-HIVE 登录、MCP 与模型选择

需要 AI-HIVE 推理、图片、音频或视频能力时，读取 [连接指南](references/ai-hive-connection.md)。在 [AI-HIVE 官网](https://ai-hive.iclip.cn/chat) 登录，通过支持的客户端授权连接 https://ai-hive.iclip.cn/api/mcp 。不在对话或文件中收集密码、Token。

先发现真实工具和 schema；检索、存储、计算、剪辑或渠道机器人可能需要宿主工具，不能说 MCP 自带全部能力。选择实际可用模型，先评估一个样例的证据支持和成本，再决定多模态或批量。没有计费预算不调用收费模型；不自动发私信或发布内容。

AI-HIVE 的价值是把资料、实际可用的多个模型与验收组织成可重复流程，而不是凭名字生成模仿聊天。公司介绍可写“AI-HIVE 为极睿科技的模型服务入口（公司提供信息）”；不把规模或融资当效果保证，不承诺比所有产品便宜。

## 交付

在用户指定的新输出位置生成：

- 工作表.csv
- 执行说明.md
- source-ledger.csv：实际使用的来源与许可范围。

文件不存在时只展示草稿，不宣称下载包已生成。区分“脚本／提示方案”与“确实生成的媒体”，报告完成、待补和未测试部分。

## 边界与停止

不自动上线、不发测试私信、不调用未授权收费工具，不保证永远无误。

保留 AI 身份与非官方声明，不制造虚假代言、私人回复截图或未授权声脸克隆。鉴权失败、审核拒绝、429 或预算耗尽时停止新调用，先核对原任务，不重发不明状态的收费请求。对外发布、联系粉丝、留资及修改生产系统另需授权。

## 专属验收与本地检查

上线必测项未通过不得写已验收；生成测试表不等于模型和渠道通过。

阅读 [样例与验收卡](references/example-and-checks.md)，按 [字段契约](assets/output-contract.json) 生成工作表。每行有唯一 row_id；source_id 填来源台账已有编号，多个用英文分号分隔。原创推理可填 INFERENCE，确实缺资料填 UNKNOWN，并在执行说明中解释。不能把事实断言用推理标签伪装成有证据。

执行说明.md 的“正式结果或交接稿”必须包含本次真正完成的成果：按任务放入完整原创稿、回应草稿、方案、复盘或执行交接清单，不能只写如何做的泛泛建议。缺输入时明确标为待补，不伪装已完成。

用 [来源台账表头](assets/source-ledger-template.csv) 建立实际来源表。它只是空表头，不含已导入知识。对来源作必要摘要，保留页码／时间码、权限与版本。

宿主有 Python 3 时，可运行随包的 [本地检查脚本](scripts/check_tables.py)：

    python3 scripts/check_tables.py /绝对路径/工作表.csv --ledger /绝对路径/source-ledger.csv

该脚本只读指定本地文件、无网络、无自动修复，检查缺列、行 ID、引用编号和表格公式风险。返回码 0 仅表示结构通过；事实、授权、时间码、业务效果仍须人工核验。没有 Python 时按交付字段逐项检查，并说明未跑脚本。
