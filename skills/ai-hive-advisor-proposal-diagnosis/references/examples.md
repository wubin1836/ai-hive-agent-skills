# 合作提案诊断顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：长提案找关键缺口

```text
假设我写了8页联合活动提案，目标让对方提供场地和2名工作人员。请指出最影响批准的5处问题，引用原文位置。
```

预期交付：聚焦决策请求、双方投入、证据与验收缺口，给出优先修改项。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-proposal-diagnosis",
  "request": "假设我写了8页联合活动提案，目标让对方提供场地和2名工作人员。请指出最影响批准的5处问题，引用原文位置。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：缺案例时怎么改

```text
假设这份3页品牌合作提案没有历史案例，只做过一次内部试验。请检查夸大表述，改写价值主张，不编成功成绩。
```

预期交付：区分已验证事实与待验证假设，提出能补足依据的小范围试行建议。
