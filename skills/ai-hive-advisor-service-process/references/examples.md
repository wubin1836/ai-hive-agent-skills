# 服务过程视频顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：整理服务展示

```text
我做家庭整理，客户只允许拍柜子，想做60秒过程片，不能露地址和人脸。
```

预期交付：安排柜内前后记录、分类与交接镜头，保持对照条件，列出镜面反射及文件隐私检查。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-service-process",
  "request": "我做家庭整理，客户只允许拍柜子，想做60秒过程片，不能露地址和人脸。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：设备维修价值

```text
我们修咖啡机，想展示检测价值，客户机器序列号不能公开，先给拍摄建议。
```

预期交付：以检测、维修确认和交接为主线，避开序列号，说明检修不能保证所有故障都一次解决。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-service-process",

  "paid_generation": "未授权，先给方案与预算"
}
```
