# 现金流预警顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：回款延迟压力检查

```text
虚构案例：可用现金30万元，每周固定支出6万元，第3周预计收20万元、第6周收25万元。请做13周现金流表，比较回款各延迟两周的情况，最低余额要求10万元，不执行任何付款。
```

预期交付：两种到账时点下的逐周余额、首次缺口与需要补充的后续收支资料

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-cash-runway",
  "request": "虚构案例：可用现金30万元，每周固定支出6万元，第3周预计收20万元、第6周收25万元。请做13周现金流表，比较回款各延迟两周的情况，最低余额要求10万元，不执行任何付款。",
  "external_actions": "未授权，不执行发布、群发或投放",

}
```

## 场景 2：旺季备货资金讨论

```text
我会提供脱敏的13周收支表。拟在第4周追加15万元采购，但收款时间未定，请比较分批采购与一次采购，列出老板必须确认的三项假设。
```

预期交付：情景对比、关键假设和待确认事项，不把假设当作实际收款
