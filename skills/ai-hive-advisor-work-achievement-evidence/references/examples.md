# 职场成果举证顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：团队项目写个人贡献

```text
假设团队把处理时间从5天降到3天，我负责表单改造而非全部流程。请根据分工记录做一张成果证据卡，不写成我独立完成。
```

预期交付：保留统一指标基线，明确个人动作、团队结果与贡献限制。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-work-achievement-evidence",
  "request": "假设团队把处理时间从5天降到3天，我负责表单改造而非全部流程。请根据分工记录做一张成果证据卡，不写成我独立完成。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```

## 场景 2：没有业务数据的行政成果

```text
假设我组织了6场内部培训，有签到、满意度和流程版本，没有收入数据。请整理述职证据，不推算不存在的营收贡献。
```

预期交付：用可核实的组织和质量证据呈现成果，列出不能支持的影响主张。
