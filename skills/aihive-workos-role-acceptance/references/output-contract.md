# 输出契约

本项：影刀 AI WorkOS 同类搭建｜AI员工岗位与验收助手。下列文件是应生成的业务产物，未运行时明确标记草稿，不用虚构数据填满。

| 文件 | 必需内容或字段 |
|---|---|
| `role-card.md` | 岗位目标、触发、输入、责任人、不负责事项、完成证据 |
| `task-graph.json` | tasks数组，每项id、depends_on、approval_required、approver；依赖必须存在 |
| `acceptance.csv` | case_id,scenario,expected_decision,evidence,owner,result |

## 最小走读示例（纯虚构）

虚构采购助理收到缺供应商税号的申请：输出补件队列；即使金额很低也不自批采购单。

这是演示决策边界，不是真实客户数据、测评、平台回执或生成结果。运行任务时替换为用户实际素材与核验记录。

## 验收逐项记录

- [ ] 每个任务至少一个可观察的验收条件
- [ ] 越权样例必须拒绝并转人工，不能自动扩权
- [ ] 把未运行用例标not_run，不填通过
- [ ] 每个文件有任务ID、来源引用/版本和生成或计算日期；未知数据保留null/待确认，不能写0冒充已知。
- [ ] 计算给出公式、单位、时间范围；语言/图像判断附实际证据。
- [ ] 未做付费调用、未上传或未发布的环节如实标记，不把草稿当执行结果。

## 交付回复格式

已交付：文件与路径。核验：哪些静态/本地/人工检查通过。未完成：缺工具、缺资料或待批准事项。下一步：一项最小可执行动作。
