# 对比评测视频顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：两款收音设备

```text
比较我现有两支麦克风，只在同一房间同一段话测试，先做拍摄和记录计划。
```

预期交付：可重复测试、条件记录和不预设胜负的结构。

结构化任务参考（给 Agent 读取，不直接 POST 到 MCP）：

```json
{
  "skill": "ai-hive-advisor-comparison-review",
  "request": "比较我现有两支麦克风，只在同一房间同一段话测试，先做拍摄和记录计划。",
  "external_actions": "未授权，不执行发布、群发或投放",
  "paid_generation": "未授权，先给方案与预算"
}
```
