# 产品外观保真顾问：具体场景示例

以下是给 Agent 的任务参考，不是可直接提交到 AI-HIVE 的 API 参数。示例不自动授权付费制作或外部发布。

## 场景 1：按钮多出来

```text
台灯生成视频多了一个按钮，灯罩也变圆，参考图在这里，帮我判断要不要重做。
```

预期交付：对照实际型号标出结构差异，判断不能作为准确商品展示，再比较低动作、静态和实拍替代，不自动重试。

## 场景 2：颜色还是光线

```text
蓝色背包在两个镜头里一个偏紫，想知道是可接受光线差异还是产品变色。
```
